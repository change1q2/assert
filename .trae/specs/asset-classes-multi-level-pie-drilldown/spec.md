# 资产分类多层级 & 饼图穿透 - Product Requirement Document

## Overview
- **Summary**: 对资产分类模块进行深度增强，实现分类列表的多层级结构（一级分类 → 二级资产类型），与理财模块数据联动，并新增海内外资产占比饼图和资产分类饼图的穿透下钻功能。
- **Purpose**: 让用户能够更细粒度地管理和查看资产配置，从大类到具体资产类型逐层深入，直观了解海内外分布和分类占比结构。
- **Target Users**: 使用资产分类模块进行资产配置管理的个人投资者。

## Goals
- 资产分类列表实现多层级结构，一级卡片点击展开进入二级资产类型列表
- 一级分类名称改为下拉选择，与理财模块的一级资产分类（categoryL1）联动
- 二级资产类型支持选择市场（仅国内市场/海外市场）和资产类型，数据从理财模块自动聚合
- 资产分类页面新增"海内外资产占比"饼图
- 资产分类占比饼图支持点击穿透，进入该分类下的资产类型占比饼图

## Non-Goals (Out of Scope)
- 不涉及三级及更深层级的分类
- 不修改理财模块的数据结构和核心逻辑
- 不涉及后端 API 变更（数据全部从现有 state 中计算）
- 不修改账户管理、债务模块等其他模块

## Background & Context
- 当前资产分类模块（AssetClasses.jsx）已有简单的二级分类（children），但仅为文本名称，无市场、资产类型等维度
- 理财模块（Finance.jsx）已有完整的资产数据结构，包含 market（市场）、assetType（资产类型）、categoryL1（一级分类）等字段
- 当前资产分类饼图仅展示一级分类占比，无法下钻查看详情
- 现有数据通过 `fetchState()` / `saveState()` 从后端获取，数据存储在 `state` 中

## Functional Requirements

### FR-1: 资产分类多层级结构
- 一级分类卡片保持现有卡片式布局（权益类、商品类、债权类、现金类等）
- 点击一级分类卡片或展开按钮，进入该分类的二级资产类型列表视图
- 二级列表展示该一级分类下的所有资产类型，数据从理财模块按 categoryL1 匹配自动聚合
- 二级列表支持手动添加资产类型项

### FR-2: 一级分类下拉联动
- 添加/编辑一级分类时，分类名称从文本输入改为下拉选择
- 下拉选项与理财模块的一级资产分类（CATEGORY_L1_OPTIONS）保持一致：权益类、固收类、现金类、另类投资、商品
- 选择分类后自动同步颜色和默认配置

### FR-3: 二级资产类型添加联动
- 在二级层级添加资产类型时，支持两个下拉字段：
  - **市场**：仅保留「国内市场」和「海外市场」两个选项（从理财模块的 MARKET_OPTIONS 中简化）
  - **资产类型**：下拉选项与理财模块的资产类型（ASSET_TYPE_OPTIONS）联动：股票、基金、债券、期货、期权、外汇、数字货币、银行理财、保险、房产、其他
- 添加后数据自动从理财模块按 categoryL1 + assetType + market 匹配聚合计算价值

### FR-4: 海内外资产占比饼图
- 在资产分类页面的图表区域新增"海内外资产占比"饼图
- 数据来源：理财模块所有资产按 market 字段分组（国内市场归为国内，港股市场/美股市场/其他市场归为海外）
- 饼图样式与现有资产分类占比饼图一致

### FR-5: 资产分类饼图穿透下钻
- 点击"资产分类占比"饼图的某一分类扇区，穿透进入该分类的资产类型占比饼图
- 穿透后的饼图展示该一级分类下各资产类型（股票、基金、债券等）的占比
- 提供返回按钮，可回到一级分类饼图视图
- 支持多级面包屑导航

### FR-6: 数据自动同步
- 资产分类模块的数据从理财模块自动计算，无需手动输入价值
- 当理财模块数据变化时，资产分类模块的数据自动更新
- 计算公式：某分类价值 = 理财模块中 categoryL1 匹配的所有资产的 currentValue 之和

## Non-Functional Requirements
- **NFR-1**: 页面切换和饼图穿透响应时间 < 300ms（纯前端计算）
- **NFR-2**: 保持现有视觉风格一致，使用 TailwindCSS + 现有配色体系
- **NFR-3**: 移动端适配，小屏幕下图饼图和列表正常显示
- **NFR-4**: 所有交互操作有明确的视觉反馈（hover、点击态、过渡动画）

## Constraints
- **Technical**: React 18 + Vite + TailwindCSS + Recharts，不引入新的图表库
- **Business**: 数据完全从理财模块聚合，不新增后端接口
- **Dependencies**: 依赖理财模块的 accounts 数据结构（market、assetType、categoryL1、currentValue 等字段）

## Assumptions
- 理财模块的 accounts 数据中 `categoryL1` 字段与资产分类的 `name` 字段一一对应
- 海外市场 = 港股市场 + 美股市场 + 其他市场（MARKET_OPTIONS 中除"国内市场"外的所有选项）
- 资产类型穿透时按 `assetType` 字段分组聚合
- 用户已在理财模块录入了资产数据，资产分类模块才有数据可展示

## Acceptance Criteria

### AC-1: 一级分类下拉选择
- **Given**: 用户在资产分类页面点击"添加分类"按钮
- **When**: 弹窗打开，分类名称字段显示为下拉选择框
- **Then**: 下拉选项包含「权益类、固收类、现金类、另类投资、商品」，与理财模块一级分类一致
- **Verification**: `programmatic`

### AC-2: 二级资产类型市场下拉简化
- **Given**: 用户在某一级分类下点击添加二级资产类型
- **When**: 市场下拉框展开
- **Then**: 仅显示「国内市场」和「海外市场」两个选项
- **Verification**: `programmatic`

### AC-3: 二级资产类型下拉联动
- **Given**: 用户在二级层级添加资产类型
- **When**: 资产类型下拉框展开
- **Then**: 选项与理财模块的 ASSET_TYPE_OPTIONS 一致（股票、基金、债券等）
- **Verification**: `programmatic`

### AC-4: 海内外占比饼图展示
- **Given**: 理财模块有资产数据且分布在不同市场
- **When**: 用户进入资产分类页面
- **Then**: 页面图表区域显示"海内外资产占比"饼图，国内和海外占比正确计算
- **Verification**: `human-judgment`
- **Notes**: 需验证国内=国内市场，海外=港股+美股+其他市场

### AC-5: 饼图穿透下钻
- **Given**: 资产分类占比饼图有数据
- **When**: 用户点击饼图中某一分类扇区（如"权益类"）
- **Then**: 饼图切换为该分类下的资产类型占比（股票、基金、债券等各自占比），并显示返回按钮
- **Verification**: `human-judgment`

### AC-6: 数据联动计算正确
- **Given**: 理财模块有若干资产，分别属于不同分类和市场
- **When**: 用户进入资产分类页面
- **Then**: 各分类的价值 = 理财模块中对应 categoryL1 资产的 currentValue 之和，数值准确
- **Verification**: `programmatic`

### AC-7: 二级列表数据聚合正确
- **Given**: 权益类下有股票（国内）、ETF（国内）、美股（海外）等资产
- **When**: 用户展开权益类查看二级列表
- **Then**: 二级列表按资产类型+市场分组显示，各分组价值计算正确
- **Verification**: `programmatic`

### AC-8: 饼图穿透返回功能
- **Given**: 用户已穿透到某分类的资产类型饼图
- **When**: 用户点击返回按钮或面包屑
- **Then**: 回到一级分类占比饼图视图
- **Verification**: `human-judgment`
