# 债务模块卡片样式优化 - 产品需求文档

## Overview
- **Summary**: 优化债务模块的卡片展示样式，让每个债务记录以独立卡片形式展示完整信息，包括所有字段和分期还款详情，并支持手动标记已还款/未还款状态。
- **Purpose**: 提升债务管理的可视化体验，使用户能清晰查看每笔债务的完整信息和还款进度。
- **Target Users**: 使用债务模块管理个人债务的用户

## Goals
- 每个债务记录显示为独立卡片，包含所有字段信息
- 按还款方式计算并展示每期还款明细（本金、利息、总还款额）
- 支持手动点击标记每期还款为已还/未还状态
- 卡片布局清晰，信息层次分明

## Non-Goals (Out of Scope)
- 不修改后端数据存储结构
- 不改变债务新增/编辑表单
- 不调整分类标签样式（该需求已在之前完成）

## Background & Context
- 当前债务模块使用分类卡片形式，展开后显示简单表格，仅包含名称、金额、本金、还款日期和操作列
- 需要展示更完整的债务信息，包括债权人、债务人、利率、还款方式、备注等所有字段
- 需要按还款方式（等额本息、等额本金、先息后本、到期一次性）计算每期还款计划

## Functional Requirements
- **FR-1**: 每个债务记录显示为独立卡片，包含所有字段（债权人、债务人、本金、利率、总金额、已还金额、借入日期、还款日期、还款方式、备注）
- **FR-2**: 根据还款方式计算并展示每期还款明细，包括期数、还款日期、本金、利息、总还款额
- **FR-3**: 每期还款项显示已还/未还状态，支持点击切换
- **FR-4**: 已还款金额实时更新，剩余金额自动计算
- **FR-5**: 保存还款状态到后端数据库

## Non-Functional Requirements
- **NFR-1**: 卡片布局美观，层次分明，信息易于阅读
- **NFR-2**: 还款状态切换响应迅速，无明显延迟
- **NFR-3**: 支持深色/浅色主题

## Constraints
- **Technical**: React + TailwindCSS，现有代码结构
- **Business**: 保持与现有数据结构兼容
- **Dependencies**: 基于现有的 `calculateRepayment` 函数扩展分期计算

## Assumptions
- 债务记录已包含所有必要字段（principal, annualRate, amount, startDate, dueDate, repaymentMethod, paidAmount）
- 用户需要手动标记每期还款状态，系统不自动计算还款进度

## Acceptance Criteria

### AC-1: 债务卡片显示所有字段
- **Given**: 用户进入债务模块页面
- **When**: 查看债务列表
- **Then**: 每个债务记录以独立卡片展示，包含债权人、债务人、本金、利率、总金额、已还金额、借入日期、还款日期、还款方式、备注等所有字段
- **Verification**: `human-judgment`
- **Notes**: 字段布局清晰，使用适当的标签和样式区分

### AC-2: 分期还款明细展示
- **Given**: 用户查看一笔债务卡片
- **When**: 该债务有分期还款计划（非到期一次性）
- **Then**: 卡片中显示每期还款明细，包括期数、还款日期、本金、利息、总还款额
- **Verification**: `human-judgment`
- **Notes**: 不同还款方式计算逻辑正确

### AC-3: 还款状态标记
- **Given**: 用户查看分期还款明细
- **When**: 点击某期还款项的状态标记
- **Then**: 该期还款状态在已还和未还之间切换，已还显示绿色标记，未还显示灰色标记
- **Verification**: `human-judgment`

### AC-4: 还款金额自动更新
- **Given**: 用户标记某期还款为已还
- **When**: 状态切换成功
- **Then**: 债务的已还金额自动累加该期还款额，剩余金额相应减少
- **Verification**: `programmatic`
- **Notes**: 需验证金额计算准确性

### AC-5: 还款状态持久化
- **Given**: 用户标记还款状态后保存
- **When**: 页面刷新或重新加载
- **Then**: 还款状态保持不变，数据从后端正确加载
- **Verification**: `programmatic`
