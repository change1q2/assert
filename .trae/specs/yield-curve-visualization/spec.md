# 收益率曲线可视化 - 产品需求文档

## Overview
- **Summary**: 参考同花顺收益率曲线设计，实现资产穿透页面的收益率曲线图，包含用户收益和指数两条曲线对比
- **Purpose**: 让用户直观对比自己的收益走势与所选指数的走势，支持多时间区间切换
- **Target Users**: 理财模块用户

## Goals
- 实现参考图片中的收益率曲线图设计风格
- X轴按时间区间自动适配刻度（当日/本月/近三月/今年/全部/自定义）
- Y轴显示收益率百分比，支持正负值，根据数据范围自动调整间隔
- 两条曲线对比：用户收益（红色）和指数（蓝色）

## Non-Goals (Out of Scope)
- 非可视化相关的功能变更
- 后端数据接口变更（仅前端展示优化）

## Background & Context
- 当前收益率曲线已实现基本功能，但样式和刻度需要按参考图片优化
- 参考图片来自同花顺收益率曲线界面

## Functional Requirements
- **FR-1**: X轴时间刻度按时间区间自动适配
  - 当日：显示 9:30、10:30、11:30、13:00、14:00、15:00
  - 本月：每7天显示一个刻度，格式 MM-DD（如 07-06、07-13）
  - 近三月：每月1日显示一个刻度，格式 MM-DD（如 05-01、06-01）
  - 今年：每月1日显示一个刻度，格式 MM-DD（如 01-01、03-01）
  - 全部：每月1日显示一个刻度
- **FR-2**: Y轴收益率刻度根据数据范围自动调整
  - 范围 ≤ 10%：1% 间隔
  - 范围 ≤ 20%：5% 间隔
  - 范围 ≤ 40%：10% 间隔
  - 范围 ≤ 100%：20% 间隔
  - 范围 > 100%：50% 间隔
- **FR-3**: 两条曲线对比显示
  - 用户收益曲线：红色
  - 指数曲线：蓝色
  - 支持鼠标悬停显示具体数值
- **FR-4**: 样式优化
  - Y轴收益率刻度显示在图表右侧
  - 网格线为浅灰色虚线样式
  - 曲线下方有渐变填充效果

## Non-Functional Requirements
- **NFR-1**: 图表响应式布局，适配不同屏幕宽度
- **NFR-2**: 加载性能优化，大数据量时流畅显示

## Constraints
- **Technical**: React + Tailwind CSS，SVG 绑定实现图表
- **Dependencies**: 现有数据接口不变

## Assumptions
- 后端已提供指数历史数据接口
- 用户收益率数据可通过现有逻辑计算得出

## Acceptance Criteria

### AC-1: 当日模式时间刻度
- **Given**: 用户选择「当日」时间区间
- **When**: 查看收益率曲线图
- **Then**: X轴显示 9:30、10:30、11:30、13:00、14:00、15:00 六个时间点
- **Verification**: `human-judgment`

### AC-2: 本月模式时间刻度
- **Given**: 用户选择「本月」时间区间
- **When**: 查看收益率曲线图
- **Then**: X轴按每7天显示一个刻度，格式 MM-DD
- **Verification**: `human-judgment`

### AC-3: 近三月模式时间刻度
- **Given**: 用户选择「近三月」时间区间
- **When**: 查看收益率曲线图
- **Then**: X轴每月1日显示一个刻度，格式 MM-DD
- **Verification**: `human-judgment`

### AC-4: 今年模式时间刻度
- **Given**: 用户选择「今年」时间区间
- **When**: 查看收益率曲线图
- **Then**: X轴从今年1月到当前月每月1日显示一个刻度，格式 MM-DD
- **Verification**: `human-judgment`

### AC-5: Y轴自适应刻度
- **Given**: 数据范围在不同区间
- **When**: 查看收益率曲线图
- **Then**: Y轴刻度间隔根据数据范围自动调整（1%/5%/10%/20%/50%）
- **Verification**: `human-judgment`

### AC-6: 双曲线对比
- **Given**: 用户收益和指数数据均有值
- **When**: 查看收益率曲线图
- **Then**: 红色曲线显示用户收益，蓝色曲线显示指数走势
- **Verification**: `human-judgment`
