# 理财分析按一级分类聚合与术语统一 Spec

## Why
当前统计分析页面的理财分析组件展示的是每个理财产品的 IRR 明细，数据过于细粒度，用户希望按一级分类（权益类、债权类、商品类等）聚合展示汇总数据。同时，顶部卡片与理财模块的术语需要统一，确保"总市值"、"总成本"、"总盈亏"、"总收益率"等概念在两处一致。

## What Changes
- **FinanceAnalysis.jsx**：
  - 资产 IRR 明细列表从"每个产品一行"改为"按一级分类聚合，每个分类一行"
  - 聚合维度：按 `categoryL1` 字段（如权益类、债权类、商品类等）
  - 展示字段调整为：一级分类名称、当前总市值、总成本、持仓收益、收益率、收益额、IRR
  - 顶部卡片术语调整：
    - "持仓收益" → "总盈亏"
    - "持仓收益率" → "总收益率"
  - 新增"资产分类对比"区域，左侧显示统计分析理财模块数据，右侧显示理财模块数据，便于对比验证

## Impact
- Affected specs: analysis-finance-analysis-page
- Affected code: `assert_WEB/src/components/FinanceAnalysis.jsx`

## ADDED Requirements

### Requirement: 一级分类聚合展示
系统 SHALL 在理财分析页面的"资产 IRR 明细"区域，按一级分类聚合展示汇总数据，而非每个产品一行。

#### Scenario: 按一级分类聚合
- **WHEN** 理财分析页面加载且 financeAssets 有数据
- **THEN** 按 `categoryL1` 字段将资产分组（如：权益类、债权类、商品类、现金类等）
- **AND** 每个一级分类显示一行汇总数据
- **AND** 对于未设置 categoryL1 的资产，归类为"其他"类

#### Scenario: 计算分类汇总指标
- **WHEN** 对每个一级分类计算汇总数据时
- **THEN** 计算并显示以下字段：
  - 一级分类名称
  - 当前总市值 = 该分类下所有资产的 currentValue 之和
  - 总成本 = 该分类下所有资产的 cost 之和
  - 收益额 = 当前总市值 - 总成本
  - 收益率 = 收益额 / 总成本 × 100%
  - IRR = 基于该分类下所有资产的现金流计算 XIRR

#### Scenario: 分类 IRR 计算
- **WHEN** 计算某个一级分类的 IRR
- **THEN** 收集该分类下所有资产的交易现金流（买入为负、卖出/分红为正）
- **AND** 追加当前总市值作为终值
- **AND** 使用 Newton-Raphson 迭代法计算年化收益率
- **AND** 若现金流不足或无法收敛，IRR 显示为"—"

### Requirement: 顶部卡片术语统一
系统 SHALL 将理财分析页面顶部统计卡片的术语与理财模块统一。

#### Scenario: 术语对照
- **WHEN** 顶部卡片渲染时
- **THEN** 卡片标题遵循以下映射：
  - "总市值" 保持不变
  - "总成本" 保持不变
  - "持仓收益" 改为 "总盈亏"
  - "持仓收益率" 改为 "总收益率"
  - "组合年化 IRR" 保持不变

### Requirement: 数据对比区域
系统 SHALL 在理财分析页面提供数据对比功能，便于用户验证统计分析与理财模块的数据一致性。

#### Scenario: 左右对比布局
- **WHEN** 用户查看理财分析页面顶部区域
- **THEN** 左侧显示"统计分析（理财分析）"的汇总数据
- **AND** 右侧显示"理财模块"的汇总数据
- **AND** 两边显示相同的指标项：总市值、总成本、总盈亏、总收益率

#### Scenario: 数据一致性
- **WHEN** 对比区域显示时
- **THEN** 左侧"总市值"等于右侧"总市值"
- **AND** 左侧"总成本"等于右侧"总成本"
- **AND** 左侧"总盈亏"等于右侧"总盈亏"
- **AND** 左侧"总收益率"等于右侧"总收益率"

## MODIFIED Requirements

### Requirement: 资产 IRR 明细展示方式
原需求：每个理财产品显示一行，包含资产名称、代码、当前市值、总成本、持仓收益、收益率、分红总额、IRR。
现修改为：按一级分类聚合，每个分类显示一行，包含分类名称、当前总市值、总成本、收益额、收益率、IRR。
