# 资产穿透页面功能增强 - Product Requirement Document

## Overview
- **Summary**: 对资产穿透页面进行多项功能增强，包括交易记录表单校验、收益率曲线负数显示与实时指数数据、指数对比实时数据、收益数据实时计算以及资产分类层级钻取功能
- **Purpose**: 提升资产穿透页面的数据准确性和交互体验，确保数据来源于真实的理财模块数据而非模拟数据
- **Target Users**: 使用资产穿透功能的投资者用户

## Goals
- 实现交易记录表单中金额、价格、数量的双向校验逻辑
- 确保收益率曲线支持负数显示，并获取网络实时指数数据进行双曲线对比
- 指数对比模块显示实时指数数据
- 收益数据根据理财模块金额数据实时计算，无数据部分按0显示
- 资产分类模块支持四级层级钻取（股票→A股/港股→场内/场外→四级分类）

## Non-Goals (Out of Scope)
- 不涉及新的页面或模块开发
- 不修改现有的数据存储结构
- 不添加新的第三方图表库

## Background & Context
- 当前资产穿透页面已实现基本的资产展示、收益分析、指数对比等功能
- 交易记录表单中金额和数量的计算是单向的，修改金额不会反推数量
- 收益率曲线和收益数据部分使用了模拟数据，而非真实的理财模块数据
- 资产分类模块已有基本的层级数据结构，但需要确保四级钻取功能正常工作

## Functional Requirements

### FR-1: 交易记录表单双向校验
- 修改 Finance.jsx 中的交易记录表单，实现金额、价格、数量三者之间的双向校验
- 当修改价格时，自动计算金额（金额=价格*数量）
- 当修改数量时，自动计算金额（金额=价格*数量）
- 当修改金额时，自动计算数量（数量=金额/价格）

### FR-2: 收益率曲线负数显示与实时指数
- 确保收益率曲线能正确显示负数收益率
- 获取网络实时指数数据（上证、深证、纳斯达克、标普500等）
- 显示两条对比曲线：用户收益曲线 vs 指数收益曲线

### FR-3: 指数对比实时数据
- 指数对比模块显示各指数的实时数据（价格、涨跌幅）
- 数据来源于网络API，而非模拟数据

### FR-4: 收益数据实时计算
- 日历收益、月度收益、年度收益、阶段收益等数据根据理财模块的实际金额数据计算
- 无数据的部分按0显示，而非生成随机模拟数据

### FR-5: 资产分类四级层级钻取
- 资产分类模块支持点击钻取：一级分类（股票）→二级分类（A股/港股）→三级分类（场内/场外）→四级分类
- 当某层级无数据或无下一级子分类时，该分类不可点击
- 支持返回上级分类

## Non-Functional Requirements
- **NFR-1**: 网络请求超时时间不超过10秒
- **NFR-2**: 页面响应时间不超过2秒
- **NFR-3**: 数据更新频率不低于每30分钟刷新一次

## Constraints
- **Technical**: 前端使用 React + JavaScript，后端使用 Node.js，使用新浪财经、东方财富等公开API获取指数数据
- **Dependencies**: 依赖现有的 finance-service.js 中的指数数据获取方法

## Assumptions
- 理财模块已存储用户的资产数据（financeAssets）
- 公开的指数API可以正常访问
- 用户已登录并有权限访问资产数据

## Acceptance Criteria

### AC-1: 交易记录表单双向校验
- **Given**: 用户在交易记录表单中输入价格和数量
- **When**: 用户修改价格或数量
- **Then**: 金额自动更新为价格乘以数量
- **Verification**: `human-judgment`

- **Given**: 用户在交易记录表单中输入金额和价格
- **When**: 用户修改金额
- **Then**: 数量自动更新为金额除以价格
- **Verification**: `human-judgment`

### AC-2: 收益率曲线负数显示
- **Given**: 用户收益或指数收益为负数
- **When**: 页面加载收益率曲线
- **Then**: 曲线正确显示在0轴下方，Y轴刻度包含负数
- **Verification**: `human-judgment`

### AC-3: 实时指数数据
- **Given**: 页面加载
- **When**: 获取指数数据
- **Then**: 显示的指数价格和涨跌幅为实时数据
- **Verification**: `human-judgment`

### AC-4: 双曲线对比
- **Given**: 用户选择了一个对比指数
- **When**: 查看收益率曲线
- **Then**: 同时显示用户收益曲线（红色）和指数收益曲线（蓝色）
- **Verification**: `human-judgment`

### AC-5: 指数对比实时数据
- **Given**: 页面加载
- **When**: 查看指数对比模块
- **Then**: 各指数显示实时价格和涨跌幅
- **Verification**: `human-judgment`

### AC-6: 收益数据实时计算
- **Given**: 理财模块有资产数据
- **When**: 查看日历收益、月度收益、年度收益、阶段收益
- **Then**: 显示的数据基于实际资产数据计算，无数据部分显示0
- **Verification**: `human-judgment`

### AC-7: 资产分类层级钻取
- **Given**: 用户在资产分类模块点击一个分类
- **When**: 该分类有下一级子分类
- **Then**: 显示下一级分类的饼图和列表
- **Verification**: `human-judgment`

- **Given**: 用户在资产分类模块点击一个分类
- **When**: 该分类无下一级子分类
- **Then**: 该分类不可点击，鼠标悬停无指针变化
- **Verification**: `human-judgment`

- **Given**: 用户处于非一级分类
- **When**: 点击返回上级按钮
- **Then**: 返回上一级分类视图
- **Verification**: `human-judgment`
