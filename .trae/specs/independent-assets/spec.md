# 独立资产模块 - Product Requirement Document

## Overview
- **Summary**: 在理财模块下新增独立资产模块，包含保险、固定资产（房产/车辆）、固定投资、股权、定期存等非金融交易类资产的管理功能
- **Purpose**: 提供完整的资产全景视图，支持用户管理保险、房产、车辆等独立资产，统计汇总数据和账户本信息
- **Target Users**: 所有使用理财模块的用户，需要管理保险、房产、车辆等非证券类资产

## Goals
- 创建独立资产模块页面，位于理财模块下
- 实现汇总数据展示（总价值、收益等）
- 实现账户本数据同步（与账户管理模块数据一致）
- 实现保险资产表单管理（含演示收益和实际收益字段）
- 实现固定资产管理（房产和车辆）
- 实现固定投资管理
- 实现股权管理（参考理财持仓明细）
- 实现定期存款管理

## Non-Goals (Out of Scope)
- 不修改现有理财模块的证券持仓逻辑
- 不新增后端API，使用 localStorage 存储数据
- 不实现资产市场数据自动获取（如房产价格、车辆估值等）

## Background & Context
- 当前系统已有理财模块（Finance.jsx）用于管理证券类资产
- 账户管理模块（Accounts.jsx）管理银行账户等现金类资产
- 用户需要管理保险、房产、车辆等独立资产，这些不属于证券交易范畴
- 参考项目中已有的数据结构和UI风格

## Functional Requirements
- **FR-1**: 独立资产模块页面包含汇总数据卡片（总价值、演示收益、实际收益）
- **FR-2**: 账户本数据同步显示（来自账户管理模块数据）
- **FR-3**: 保险资产管理表单，包含字段：保单年度、缴付保费总额、保证金额、非保证金额、演示收益额、演示收益率、演示年化收益率、实际收益额、实际收益率、实际年化收益率
- **FR-4**: 房产资产管理，包含字段：国家、省份、市区、地区、类型、地区平均价格、二手价、新房平均价
- **FR-5**: 车辆资产管理，包含字段：类型（小轿车/电动车）、厂商、型号、购买价格、二手价格、新车价
- **FR-6**: 固定投资管理，包含字段：国家、省份、地区、类型、投入成本、分红时间、分红金额
- **FR-7**: 股权管理，列表字段参考理财模块持仓明细（名称、代码、成本、数量、当前价格、市值、盈亏等）
- **FR-8**: 定期存款管理，包含字段：市场、地点、类型、货币种类、金额、利息、期间、预期收益、实际收益
- **FR-9**: 每个资产类型独立表格展示，支持增删改操作

## Non-Functional Requirements
- **NFR-1**: UI风格与现有理财模块保持一致（Tailwind CSS）
- **NFR-2**: 表格支持分页、滚动、列宽调整
- **NFR-3**: 表单包含必填字段验证、提交状态反馈、错误提示
- **NFR-4**: 数据自动保存到 localStorage，刷新后数据不丢失

## Constraints
- **Technical**: React + Vite + Tailwind CSS 前端架构
- **Dependencies**: 使用现有数据结构（stateData）和 API（fetchState/saveState）
- **Storage**: 数据存储在 localStorage 的 state 对象中

## Assumptions
- 用户已登录，有有效 token
- 账户管理数据已存在于 stateData.accounts 中
- 资产数据结构可以扩展到 stateData 中

## Acceptance Criteria

### AC-1: 独立资产模块页面正常显示
- **Given**: 用户登录系统并进入理财模块
- **When**: 点击独立资产子模块
- **Then**: 页面显示汇总数据、账户本、各资产类型表格
- **Verification**: `human-judgment`

### AC-2: 汇总数据展示
- **Given**: 用户进入独立资产模块
- **When**: 查看页面顶部
- **Then**: 显示总价值、演示收益总额、实际收益总额等汇总数据
- **Verification**: `human-judgment`

### AC-3: 账户本数据同步
- **Given**: 用户在账户管理中添加了账户
- **When**: 进入独立资产模块的账户本
- **Then**: 显示与账户管理模块相同的账户数据
- **Verification**: `human-judgment`

### AC-4: 保险资产表单功能
- **Given**: 用户在独立资产模块
- **When**: 点击保险资产的新增/编辑按钮
- **Then**: 弹出表单，包含所有要求字段，支持保存
- **Verification**: `human-judgment`

### AC-5: 房产资产管理
- **Given**: 用户在独立资产模块
- **When**: 点击房产资产的新增/编辑按钮
- **Then**: 弹出表单，包含国家、省份、市区、地区、类型、价格等字段
- **Verification**: `human-judgment`

### AC-6: 车辆资产管理
- **Given**: 用户在独立资产模块
- **When**: 点击车辆资产的新增/编辑按钮
- **Then**: 弹出表单，包含类型、厂商、型号、价格等字段
- **Verification**: `human-judgment`

### AC-7: 固定投资管理
- **Given**: 用户在独立资产模块
- **When**: 点击固定投资的新增/编辑按钮
- **Then**: 弹出表单，包含投入成本、分红时间、分红金额等字段
- **Verification**: `human-judgment`

### AC-8: 股权管理
- **Given**: 用户在独立资产模块
- **When**: 查看股权列表
- **Then**: 列表字段与理财模块持仓明细一致，支持增删改
- **Verification**: `human-judgment`

### AC-9: 定期存款管理
- **Given**: 用户在独立资产模块
- **When**: 点击定期存款的新增/编辑按钮
- **Then**: 弹出表单，包含金额、利息、期间、预期收益、实际收益等字段
- **Verification**: `human-judgment`

### AC-10: 数据持久化
- **Given**: 用户添加或修改了资产数据
- **When**: 刷新页面
- **Then**: 数据保持不变，已保存到 localStorage
- **Verification**: `human-judgment`
