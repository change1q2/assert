# 收支分析页面筛选增强 - 产品需求文档

## Overview
- **Summary**: 全面增强收支分析页面的筛选功能，包括删除设置功能、标签下拉化、筛选布局优化、日期视图切换、数据同步过滤等
- **Purpose**: 提升用户体验，优化筛选操作流程，确保数据显示与筛选条件一致
- **Target Users**: 使用收支分析功能的所有用户

## Goals
- 删除新增弹窗中的设置功能区域
- 将标签改为下拉选项，支持自由编辑和删除
- 优化筛选区域布局，添加筛选提示，日期/分类使用下拉选择
- 将金额、标签、备注筛选折叠进高级筛选
- 完善日期视图切换功能（全部/日常/月统计/年统计/自定义）
- 根据选中的日期范围动态更新统计标题（当日/当月/当年/总计）
- 确保所有数据（收入占比、支出占比、收支记录）都跟随筛选条件同步过滤

## Non-Goals (Out of Scope)
- 修改数据库表结构
- 新增其他页面的功能
- 修改后端 API 接口

## Background & Context
- 当前新增弹窗包含设置区域，但用户希望简化弹窗
- 标签当前是输入框，用户希望改为下拉选择并支持管理
- 筛选区域布局需要优化，添加提示文字
- 日期视图切换需要更加完善，支持"全部"视图
- 数据统计标题需要根据筛选条件动态变化

## Functional Requirements
- **FR-1**: 删除新增弹窗中的设置功能区域
- **FR-2**: 将标签改为下拉选项，支持从标签列表中选择，添加标签管理功能
- **FR-3**: 筛选区域添加提示文字（如"日期："、"账本："等），日期使用下拉选择，一级/二级分类使用下拉筛选
- **FR-4**: 将金额、标签、备注的筛选折叠进高级筛选功能
- **FR-5**: 在"日常"左侧添加"全部"标签，默认选中"全部"，点击不同标签显示对应视图
- **FR-6**: 根据选中的日期范围动态更新统计卡片标题（当日收入/当月收入/当年收入/总收入）
- **FR-7**: 所有数据（收入占比、支出占比、收支记录）根据日期筛选条件同步过滤

## Non-Functional Requirements
- **NFR-1**: 页面响应时间 < 2秒
- **NFR-2**: 筛选操作流畅，无卡顿
- **NFR-3**: 界面美观，符合现有设计风格

## Constraints
- **Technical**: React + Vite + TailwindCSS，使用 recharts 图表库
- **Dependencies**: 后端 MySQL 数据库

## Assumptions
- 用户已登录，能正常访问 API
- MySQL 数据库已配置运行

## Acceptance Criteria

### AC-1: 删除设置功能
- **Given**: 用户打开新增收支记录弹窗
- **When**: 观察弹窗内容
- **Then**: 弹窗中无"设置"区域
- **Verification**: `human-judgment`

### AC-2: 标签下拉选择
- **Given**: 用户打开新增收支记录弹窗
- **When**: 点击标签字段
- **Then**: 显示标签下拉列表，支持选择和管理
- **Verification**: `human-judgment`

### AC-3: 筛选区域优化
- **Given**: 用户查看收支记录列表
- **When**: 观察筛选区域
- **Then**: 每个筛选前面有提示文字，日期和分类使用下拉选择
- **Verification**: `human-judgment`

### AC-4: 高级筛选折叠
- **Given**: 用户查看收支记录列表
- **When**: 观察筛选区域
- **Then**: 金额、标签、备注筛选不在主筛选区域显示
- **Verification**: `human-judgment`

### AC-5: 日期视图切换
- **Given**: 用户查看日期筛选区域
- **When**: 点击不同标签（全部/日常/月统计/年统计/自定义）
- **Then**: 显示对应视图（全部显示总体统计，日常显示日历等）
- **Verification**: `human-judgment`

### AC-6: 动态统计标题
- **Given**: 用户切换日期视图
- **When**: 观察统计卡片
- **Then**: 标题根据选择动态变化（当日/当月/当年/总计）
- **Verification**: `human-judgment`

### AC-7: 数据同步过滤
- **Given**: 用户选择日期筛选条件
- **When**: 观察收入占比、支出占比和收支记录
- **Then**: 所有数据根据筛选条件同步更新
- **Verification**: `human-judgment`
