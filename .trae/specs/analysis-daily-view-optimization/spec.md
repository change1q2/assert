# 统计分析页面日常视图优化 - 产品需求文档

## Overview
- **Summary**: 优化统计分析页面的日常视图，按照参考图片重新组织布局，显示本日收支、本周统计、预算占比和标签数据
- **Purpose**: 提供更简洁、聚焦的日常视图，方便用户快速了解当天和本周的财务状况
- **Target Users**: 所有使用个人资产管理平台的用户

## Goals
- 日常视图第一行显示本日支出、本日收入、本日结余三个卡片
- 第二行显示本周统计柱状图，支持支出/收入切换
- 第三行显示预算占比环形图
- 第四行显示标签数据列表
- 日常视图隐藏其他卡片（资产走势、收支对比、支出占比、报表统计、本月总结）

## Non-Goals (Out of Scope)
- 月统计和年统计视图保持不变
- 预算功能的后端实现（仅前端展示）

## Background & Context
- 当前日常视图显示的是月度数据卡片和多种图表
- 用户参考图片显示了更简洁的日常视图布局
- 预算功能目前不存在，需要在前端实现基础展示

## Functional Requirements
- **FR-1**: 日常视图第一行显示本日支出、本日收入、本日结余三个统计卡片
- **FR-2**: 第二行显示本周统计柱状图，支持支出/收入切换按钮
- **FR-3**: 第三行显示预算占比环形图，展示各预算类别的使用情况
- **FR-4**: 第四行显示标签数据列表，展示各标签的收支情况
- **FR-5**: 日常视图隐藏资产走势、收支对比、支出占比饼图、报表统计、本月总结等模块

## Non-Functional Requirements
- **NFR-1**: 日常视图的数据计算要准确，基于当日和本周的实际记录
- **NFR-2**: 布局响应式，在移动端和桌面端都能正常显示

## Constraints
- **Technical**: React 函数组件、Recharts 图表库、Tailwind CSS
- **Dependencies**: 需要从 records 数据中计算当日和本周的统计数据

## Assumptions
- 预算数据需要在前端模拟，后续可接入后端
- 标签数据已存在于 records 中

## Acceptance Criteria

### AC-1: 日常视图显示本日统计卡片
- **Given**: 用户在统计分析页面，时间模式为"日常"
- **When**: 页面加载完成
- **Then**: 第一行显示"本日支出"、"本日收入"、"本日结余"三个卡片，数据为当日实际金额
- **Verification**: `human-judgment`

### AC-2: 本周统计柱状图支持切换
- **Given**: 用户在日常视图的本周统计模块
- **When**: 点击"支出"或"收入"按钮
- **Then**: 柱状图切换显示对应的数据，图表下方显示总支出/总收入和日均支出/日均收入
- **Verification**: `human-judgment`

### AC-3: 预算占比环形图显示
- **Given**: 用户在日常视图
- **When**: 页面加载完成
- **Then**: 第三行显示预算占比环形图，展示各预算类别的金额和占比
- **Verification**: `human-judgment`

### AC-4: 标签数据列表显示
- **Given**: 用户在日常视图
- **When**: 页面加载完成
- **Then**: 第四行显示标签数据列表，包含标签名称、支出金额、收入金额和笔数
- **Verification**: `human-judgment`

### AC-5: 非日常模块隐藏
- **Given**: 用户在日常视图
- **When**: 页面加载完成
- **Then**: 资产走势、收支对比、支出占比饼图、报表统计、本月总结等模块不显示
- **Verification**: `human-judgment`
