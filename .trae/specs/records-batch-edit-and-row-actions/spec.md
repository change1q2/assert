# 收支记录批量编辑与行操作功能 Spec

## Why
当前收支记录列表仅支持单条新增和导入，用户需要能够批量选择记录进行编辑（如批量修改类别、账本、标签等），同时也需要每行独立的编辑/删除操作按钮，提升数据管理效率。

## What Changes
- 在新增按钮旁边增加"编辑"按钮，点击进入批量编辑模式
- 表格最左侧增加序号列
- 表格最右侧增加"操作"列，每行包含编辑和删除按钮
- 批量编辑模式下，每行显示复选框供多选
- 多选后显示批量操作栏，支持批量修改类别、二级分类、账本、标签、收支类型
- 单行编辑弹出编辑弹窗，可修改该记录的所有字段
- 单行删除需要确认弹窗

## Impact
- 受影响文件：assert_WEB/src/pages/Records.jsx
- 受影响状态：批量编辑模式状态、选中记录状态

## ADDED Requirements

### Requirement: 批量编辑模式切换
The system SHALL 在新增按钮旁提供"编辑"按钮，点击后进入批量编辑模式。

#### Scenario: 进入批量编辑模式
- **WHEN** 用户点击"编辑"按钮
- **THEN** 表格每行左侧显示复选框，顶部出现批量操作栏
- **AND** "编辑"按钮变为"取消"，点击可退出批量编辑模式

### Requirement: 序号列
The system SHALL 在表格最左侧显示序号列。

#### Scenario: 显示序号
- **WHEN** 用户查看收支记录列表
- **THEN** 每行最左侧显示当前页内的序号（1, 2, 3...）
- **AND** 分页切换后序号重新从1开始

### Requirement: 行操作列
The system SHALL 在表格最右侧显示操作列，包含编辑和删除按钮。

#### Scenario: 单行编辑
- **WHEN** 用户点击某行的"编辑"按钮
- **THEN** 弹出编辑弹窗，预填充该行数据
- **AND** 用户修改后点击保存，更新该记录

#### Scenario: 单行删除
- **WHEN** 用户点击某行的"删除"按钮
- **THEN** 弹出确认弹窗
- **AND** 用户确认后删除该记录

### Requirement: 批量选择
The system SHALL 支持通过复选框多选记录。

#### Scenario: 多选记录
- **WHEN** 用户点击多行复选框
- **THEN** 批量操作栏显示已选数量
- **AND** 顶部复选框可选中/取消选中当前页全部记录

### Requirement: 批量修改
The system SHALL 支持对选中的多条记录批量修改指定字段。

#### Scenario: 批量修改字段
- **WHEN** 用户选中多条记录并选择批量修改项（如类别）
- **THEN** 弹出选择器供用户选择新值
- **AND** 用户确认后，所有选中记录的该字段被更新
- **AND** 未被修改的字段保持原值不变
