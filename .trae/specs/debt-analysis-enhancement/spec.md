# 债务模块统计分析增强 Spec

## Why
统计分析中的债务模块切换页缺少关键指标（总借出金额）、图表信息不完整（环比趋势缺少年月显示）、图表类型需要优化（类别分布改为饼图）、以及近期待还债务需要更实用的还款计划汇总功能。

## What Changes
- 债务环比趋势图X轴显示完整年月格式（如"2026-01"）
- 债务同比对比删除环比增长指标，只保留同比增长
- 新增"总借出"卡片，显示应收/借出类型的债务总额
- 债务类型分布改用饼图展示
- 近期待还债务改为"本月待还账单"，汇总所有类型的还款计划并显示待还总额

## Impact
- Affected specs: 债务模块统计分析页面
- Affected code: `assert_WEB/src/components/DebtAnalysis.jsx`

## ADDED Requirements

### Requirement: 债务环比趋势X轴年月显示
系统应在债务环比趋势折线图的X轴显示完整年月格式（如"2026-01"），而非仅显示月份（如"1月"）。

#### Scenario: 显示年月格式
- **WHEN** 用户查看债务环比趋势图
- **THEN** X轴应显示格式为"YYYY-MM"的年月标签

### Requirement: 删除债务同比对比的环比增长
系统应在债务同比对比区域删除环比增长指标，只保留同比增长指标。

#### Scenario: 只显示同比增长
- **WHEN** 用户查看债务同比对比
- **THEN** 只显示同比增长百分比，不显示环比增长

### Requirement: 新增总借出卡片
系统应在债务总本金卡片后面增加一个"总借出"卡片，显示债务模块中type为"借出"或"应收"的债务总金额。

#### Scenario: 计算总借出金额
- **WHEN** 存在借出或应收类型的债务记录
- **THEN** 总借出卡片应显示这些债务的金额总和

#### Scenario: 无借出债务时显示零
- **WHEN** 不存在借出或应收类型的债务记录
- **THEN** 总借出卡片应显示"¥0"

### Requirement: 债务类型分布改用饼图
系统应将债务类型分布图表从柱状图改为饼图，更直观地展示各类别占比。

#### Scenario: 显示饼图
- **WHEN** 用户查看债务类型分布
- **THEN** 应显示饼图形式的数据可视化

#### Scenario: 无数据时显示提示
- **WHEN** 没有债务数据
- **THEN** 显示"暂无数据"提示

### Requirement: 本月待还账单汇总
系统应将近期待还债务改为"本月待还账单"，提取所有债务类型的还款计划，筛选出本月需要还款的账单，并在底部显示待还总额。

#### Scenario: 显示本月待还账单
- **WHEN** 存在本月待还的还款计划
- **THEN** 列表应显示每笔待还账单的债权人、类型、还款金额、还款日期
- **AND** 底部应显示本月待还总额

#### Scenario: 无本月待还账单
- **WHEN** 本月没有待还的还款计划
- **THEN** 显示"本月无待还账单"提示

## MODIFIED Requirements

### Requirement: 债务核心指标卡片
原有的四个卡片（债务总额、债务总本金、债务总利息、已还金额）保持不变，在"债务总本金"后新增"总借出"卡片，形成五个卡片的布局。

### Requirement: 近期待还债务改为本月待还账单
原有的"近期待还债务"（显示未来90天内到期的债务）改为"本月待还账单"，基于还款计划计算本月实际需要还款的金额。
