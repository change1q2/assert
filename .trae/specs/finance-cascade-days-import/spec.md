# 资产分类联动与天数自动计算 - Product Requirement Document

## Overview
- **Summary**: 为资产管理系统新增资产分类四级联动逻辑（国内市场）、持仓天数自动递增功能，以及修复图片识别导入弹窗的确认按钮问题。
- **Purpose**: 提升资产录入效率和准确性，通过分类联动减少用户选择成本，自动计算持仓天数降低维护成本，修复导入流程中的交互缺失。
- **Target Users**: 个人资产管理者（财管爱好者、投资者）

## Goals
- 根据市场、资产类型自动联动资产分类一至四级的可选值与默认值
- 持仓天数从录入日起每日自动递增
- 图片识别结果校验区域底部显示"确认导入"按钮

## Non-Goals (Out of Scope)
- 不涉及海外市场（港股、美股）的分类联动规则
- 不涉及后端数据库表结构变更
- 不涉及用户权限管理
- 不改变现有资产分类的存储结构

## Background & Context
- 当前系统支持资产分类四级（categoryL1~categoryL4），但分类选项逻辑较为简单，未与市场、资产类型强联动
- 持仓天数目前是用户手动录入的静态值，不会自动递增
- 图片识别导入功能已实现识别结果校验弹窗（在 DetailModal 中），但新增资产弹窗中的图片识别后缺少确认导入按钮
- 用户最新版本将"黄金"类型拆分为独立的"黄金"、"白银"、"原油"三种资产类型

## Functional Requirements

### FR-1: 资产分类四级联动（国内市场）
根据市场=国内市场时，资产类型与资产分类一至四级的联动规则：

| 资产类型 | 一级分类 | 二级分类（默认） | 三级分类 | 四级分类选项 |
|---------|---------|----------------|---------|-------------|
| 股票 | 权益类、分红类（用户选择，默认权益类） | A股 | 场内（默认） | 权益类→长期、短期；分红类→吃息 |
| 基金 | 权益类（默认） | A股 | 场内、场外（可选） | 场内→长期、短期；场外→长期、短期 |
| 债券 | 债权类（默认） | A股 | 场内、场外（可选） | 场内→国债、可转债；场外→纯债、混合债、地方债、企业债、固收+ |
| 现金 | 现金类（默认） | 活期存款、定期存款（可选） | 场内、场外（可选） | 活期+场内→货币基金、短融；定期+场外→货币基金、银行理财、定期存款、短期存款 |
| 期货 | 权益类（默认） | A股 | 场内（默认） | 博弈、对冲 |
| 期权 | 权益类（默认） | A股 | 场内（默认） | 博弈、对冲 |
| 外汇 | 现金类（默认） | 欧元、美元、日元、人民币（可选） | 场内（默认） | 超期、短期 |
| 保险 | 分红类（默认） | A股 | 分红险、储蓄险（可选，非场内/场外） | - |
| 房产 | 分红类（默认） | 固定投资（默认） | 房租（默认） | - |
| 实体投资 | 分红类（默认） | 固定投资（默认） | 营业收益（默认） | - |
| 黄金 | 商品类（默认） | A股 | 场内、场外（可选） | 场内→黄金股、黄金ETF/LOF；场外→实物黄金、银行积存金、纸黄金 |
| 白银 | 商品类（默认） | A股 | 场内（默认） | 白银股、白银ETF/LOF |
| 原油 | 商品类（默认） | A股 | 场内（默认） | 原油股、原油ETF/LOF |

**说明**：
- 用户选择市场和资产类型后，一级分类自动填充默认值（部分类型支持用户切换）
- 二级分类根据一级分类和资产类型联动，有默认值
- 三级分类根据二级分类联动，有默认值（部分可切换）
- 四级分类根据前三级组合动态显示选项列表
- 选择上级分类变化时，下级分类自动重置为默认值或清空

### FR-2: 持仓天数自动递增
- 资产录入后，持仓天数从录入日起每日自动 +1
- 若用户手动修改持仓天数，则以修改后的数值为基准继续递增
- 列表和详情页显示的天数为实时计算值

### FR-3: 图片识别导入确认按钮
- 新增资产弹窗中，上传图片识别后，识别结果校验区域底部显示"确认导入"按钮
- 点击后将识别出的数据填充到新增表单对应字段中
- 按钮文案："确认导入"，样式与主按钮一致

## Non-Functional Requirements
- **NFR-1**: 分类联动响应延迟 < 100ms（纯前端计算）
- **NFR-2**: 持仓天数计算准确，支持跨月、跨年、闰年
- **NFR-3**: 保持现有 localStorage 自定义分类选项的兼容性

## Constraints
- **Technical**: React + Vite + Tailwind CSS 前端，Node.js 后端
- **Business**: 仅覆盖国内市场的分类联动规则
- **Dependencies**: 无外部 API 依赖，纯前端逻辑

## Assumptions
- 用户录入资产时，持仓天数的"起始日"默认为录入当天
- 用户可在新增时手动设置持仓天数（相当于设置起始日 = 今天 - 天数）
- "黄金"、"白银"、"原油"是 3 种独立的资产类型（用户 11~14 条已澄清）
- 保险/房产/实体投资的"三级分类"不再是场内/场外，而是具体业务类型

## Acceptance Criteria

### AC-1: 股票类型分类联动正确
- **Given**: 市场选择"国内市场"，资产类型选择"股票"
- **When**: 查看资产分类选项
- **Then**: 一级分类显示"权益类、分红类"，默认选中权益类；二级分类默认"A股"；三级分类默认"场内"；选择权益类时四级分类显示"长期、短期"，选择分红类时四级分类显示"吃息"
- **Verification**: `human-judgment`

### AC-2: 基金类型分类联动正确
- **Given**: 市场选择"国内市场"，资产类型选择"基金"
- **When**: 查看资产分类选项
- **Then**: 一级分类默认"权益类"；二级分类默认"A股"；三级分类可选"场内、场外"；选场内时四级分类显示"长期、短期"；选场外时四级分类显示"长期、短期"
- **Verification**: `human-judgment`

### AC-3: 债券类型分类联动正确

- **Then**: 一级分类默认"债权类"；二级分类默认"A股"；三级分类可选"场内、场外"；场内时四级显示"国债、可转债"；场外时四级显示"纯债、混合债、地方债、企业债、固收+"

### AC-4: 现金类型分类联动正确

- **When**: 切换二级分类和三级分类
- **Then**: 一级分类默认"现金类"；二级可选"活期存款、定期存款"；三级可选"场内、场外"；活期+场内时四级显示"货币基金、短融"；定期+场外时四级显示"货币基金、银行理财、定期存款、短期存款"
- **Verification**: `human-judgment`

- **Then**: 一级分类默认"权益类"；二级分类默认"A股"；三级分类默认"场内"；四级分类显示"博弈、对冲"

- **Then**: 保险→一级默认"分红类"，二级默认"A股"，三级可选"分红险、储蓄险"；房产→一级默认"分红类"，二级默认"固定投资"，三级选"房租"；实体投资→一级默认"分红类"，二级默认"固定投资"，三级选"营业收益"
- **Verification**: `human-judgment`

- **Given**: 市场选择"国内市场"，资产类型选择"黄金"
- **When**: 切换三级分类
- **Then**: 一级分类默认"商品类"；二级分类默认"A股"；三级可选"场内、场外"；场内时四级显示"黄金股、黄金ETF/LOF"；场外时四级显示"实物黄金、银行积存金、纸黄金"

### AC-9: 白银类型分类联动正确
- **Given**: 市场选择"国内市场"，资产类型选择"白银"
- **When**: 查看资产分类选项
- **Then**: 一级分类默认"商品类"；二级分类默认"A股"；三级分类默认"场内"；四级分类显示"白银股、白银ETF/LOF"
- **Verification**: `human-judgment`

### AC-10: 原油类型分类联动正确
- **Given**: 市场选择"国内市场"，资产类型选择"原油"
- **When**: 查看资产分类选项
- **Then**: 一级分类默认"商品类"；二级分类默认"A股"；三级分类默认"场内"；四级分类显示"原油股、原油ETF/LOF"

### AC-11: 持仓天数自动递增
- **Given**: 一条资产记录，持仓天数已录入为 N 天，录入日期为 D
- **When**: 打开页面或刷新，当前日期 > D
- **Then**: 显示的持仓天数 = N + (当前日期 - D 的天数差)
- **Verification**: `programmatic`

### AC-12: 图片识别导入有确认按钮
- **Given**: 新增资产弹窗中上传了图片并完成识别
- **When**: 显示识别结果校验区域
- **Then**: 区域底部有"确认导入"按钮，点击后识别数据填充到表单
- **Verification**: `human-judgment`
