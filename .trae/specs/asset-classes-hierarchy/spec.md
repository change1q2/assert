# 资产分类模块层级结构改造 - 产品需求文档

## Overview
- **Summary**: 将资产分类模块从当前的一级+二级展开模式，改造为可点击进入的三级层级结构模式。一级分类卡片可点击进入详情页，展示二级分类；二级分类可展开显示三级分类；数据采用逐级汇总模式。
- **Purpose**: 解决当前资产分类模块层级展示不够清晰、无法支持三级分类的问题，提供更好的分类管理体验。
- **Target Users**: 资产管理用户，需要对资产进行多级分类管理的用户。

## Goals
- 一级分类卡片可点击，进入详情页展示二级分类
- 支持三级分类结构（一级→二级→三级）
- 一级分类数据自动汇总所有二级分类数据
- 二级分类数据自动汇总所有三级分类数据
- 取消当前在一级卡片下方直接展开二级分类的方式

## Non-Goals (Out of Scope)
- 不修改图表展示逻辑
- 不修改统计卡片逻辑
- 不修改筛选搜索功能
- 不修改颜色设置功能

## Background & Context
- 当前资产分类模块采用展开式设计，点击展开按钮后在一级卡片下方直接显示二级分类
- 二级分类数据结构仅支持简单的name/value/openingValue字段
- 用户需要更清晰的层级展示和支持三级分类的能力

## Functional Requirements
- **FR-1**: 一级分类卡片设置为可点击，点击后进入详情页
- **FR-2**: 详情页展示该一级分类下的所有二级分类
- **FR-3**: 二级分类支持展开/收起，显示三级分类
- **FR-4**: 一级分类的价值、盈亏等数据自动汇总所有二级分类
- **FR-5**: 二级分类的价值、盈亏等数据自动汇总所有三级分类
- **FR-6**: 支持添加/编辑/删除三级分类
- **FR-7**: 详情页提供返回按钮，回到一级分类列表

## Non-Functional Requirements
- **NFR-1**: 保持界面风格与现有系统一致
- **NFR-2**: 响应式设计，适配不同屏幕尺寸
- **NFR-3**: 数据汇总计算性能良好，不超过100ms

## Constraints
- **Technical**: React框架，使用现有状态管理机制
- **Dependencies**: 依赖现有的fetchState/saveState API

## Assumptions
- 用户数据中已有的二级分类会自动转换为支持三级分类的结构
- 汇总逻辑在前端计算，不依赖后端

## Acceptance Criteria

### AC-1: 一级分类卡片可点击进入详情页
- **Given**: 用户在资产分类列表页面
- **When**: 点击一级分类卡片（非操作按钮区域）
- **Then**: 进入该一级分类的详情页，展示二级分类列表
- **Verification**: `human-judgment`

### AC-2: 一级分类数据自动汇总二级分类
- **Given**: 一级分类下有多个二级分类
- **When**: 查看一级分类卡片或详情页
- **Then**: 一级分类的价值、盈亏等数据等于所有二级分类的总和
- **Verification**: `programmatic`

### AC-3: 二级分类支持三级分类
- **Given**: 用户在一级分类详情页
- **When**: 点击二级分类的展开按钮
- **Then**: 显示该二级分类下的三级分类列表
- **Verification**: `human-judgment`

### AC-4: 二级分类数据自动汇总三级分类
- **Given**: 二级分类下有多个三级分类
- **When**: 查看二级分类数据
- **Then**: 二级分类的价值、盈亏等数据等于所有三级分类的总和
- **Verification**: `programmatic`

### AC-5: 支持管理三级分类
- **Given**: 用户在一级分类详情页
- **When**: 在二级分类下添加/编辑/删除三级分类
- **Then**: 操作成功，数据正确保存
- **Verification**: `human-judgment`

### AC-6: 详情页可返回列表页
- **Given**: 用户在一级分类详情页
- **When**: 点击返回按钮
- **Then**: 回到一级分类列表页面
- **Verification**: `human-judgment`

### AC-7: 取消一级卡片直接展开二级分类
- **Given**: 用户在资产分类列表页面
- **When**: 查看一级分类卡片
- **Then**: 卡片上不再直接显示二级分类列表，仅显示汇总数据
- **Verification**: `human-judgment`
