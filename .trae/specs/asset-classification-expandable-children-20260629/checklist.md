# 资产分类卡片展开二级分类 - 验证清单

## 卡片展开/收起
- [x] 分类卡片右上角有展开/收起按钮
- [x] 点击展开按钮，卡片下方出现展开区域
- [x] 点击收起按钮，展开区域隐藏
- [x] 展开状态用向上箭头表示，收起状态用向下箭头
- [x] 支持同时展开多个分类卡片

## 二级分类列表展示
- [x] 展开区域内显示该主分类的所有二级分类
- [x] 每个二级分类显示：名称、当前价值、期初价值、盈亏额、盈亏率
- [x] 每个二级分类右侧有编辑和删除按钮
- [x] 空二级分类列表时显示「暂无二级分类」提示

## 添加二级分类
- [x] 展开区域内有「添加二级分类」按钮
- [x] 点击后显示输入框
- [x] 输入名称后保存，二级分类出现在列表中
- [x] 刷新后新增的二级分类仍然存在

## 编辑和删除二级分类
- [x] 点击编辑按钮，二级分类名称变为可编辑
- [x] 保存后名称更新成功
- [x] 点击删除按钮，弹出确认框
- [x] 确认后二级分类被移除
- [x] 所有操作后数据持久化

## 主分类价值汇总
- [x] 当主分类有二级分类时，价值显示正确汇总
- [x] 图表数据包含所有分类的价值

## UI/UX
- [x] 展开区域有明显的视觉区分
- [x] 展开区域内容过多时有滚动条
- [x] 深色/浅色主题下显示正常
- [x] 展开/收起不影响筛选和其他功能

## 边界处理
- [x] 大量二级分类时渲染正常
- [x] 快速多次点击展开/收起无异常
