# 统计分析页面优化 - Product Requirement Document

## Overview
- **Summary**: 对统计分析页面的年统计视图进行多项优化，包括时间筛选、柱状图标签、热力图移除、收支对比、支出占比切换、数据列表数据源等。
- **Purpose**: 提升统计分析页面的数据展示能力和用户交互体验，使年统计功能更完整易用。
- **Target Users**: 所有使用统计分析功能的用户

## Goals
- 年统计时间筛选增加"所有"选项
- 收支统计柱状图显示金额标签
- 移除收支热力图模块
- 收支对比支持一级分类/全部切换（与收支分析保持一致）
- 支出占比饼图支持收入/支出切换，显示所有分类标签
- 支出数据列表使用收支分析的类别数据
- 标签占比和标签数据列表使用收支分析的标签数据

## Non-Goals (Out of Scope)
- 不修改月统计和日常视图
- 不修改数据聚合的核心逻辑
- 不增加新的图表类型

## Background & Context
- 当前统计分析页面有日常、月统计、年统计、自定义四个视图
- 年统计视图包含：收支统计、收支热力日历、资产走势、收支对比、支出占比、标签占比、支出数据列表、标签数据列表、报表统计、年度总结
- 收支分析页面（Records.jsx）已有成熟的类别聚合和饼图实现
- 收支对比当前已有一级分类/全部切换，但需要确认数据源与收支分析一致

## Functional Requirements

### FR-1: 年统计时间筛选增加"所有"按钮
- 点击年统计时，年份选择器左侧增加"所有"按钮
- 点击"所有"显示全部年份的汇总数据
- "所有"和年份按钮互斥，选中状态高亮

### FR-2: 收支统计柱状图显示金额标签
- 每个柱状图柱子顶部显示对应金额
- 金额格式与 Tooltip 一致（带货币符号）
- 文字大小适中，不遮挡柱子

### FR-3: 移除收支热力图模块
- 删除年统计视图中的"收支热力日历"模块
- 不影响月统计和日常视图的热力图

### FR-4: 收支对比同步收支分析的分类视图
- 一级分类视图：按大类（收支类型/一级分类）展示
- 全部视图：展示所有二级分类明细
- 与 Records.jsx 中的分类逻辑保持一致
- 年统计视图使用 yearCategoryView 状态

### FR-5: 支出占比饼图支持收入/支出切换
- 饼图标题旁增加切换按钮（"切换到收入"/"切换到支出"）
- 点击切换饼图显示的是收入数据还是支出数据
- 每个扇区都显示对应的类别名称（标签）
- 饼图样式与收支分析页面一致（空心环形）

### FR-6: 支出数据列表使用收支分析的类别数据
- 数据来源与支出占比饼图一致（categoryData.expense）
- 显示类别名称、占比、金额
- 支持一级分类/全部视图切换

### FR-7: 标签占比和标签数据列表使用收支分析的标签数据
- 标签数据来源与收支分析一致
- 标签占比饼图显示所有标签分类
- 标签数据列表显示所有标签的金额和占比

## Non-Functional Requirements
- **NFR-1**: 保持现有 UI 风格一致（Tailwind CSS + Recharts）
- **NFR-2**: 构建无错误

## Constraints
- **Technical**: React + Recharts，Tailwind CSS
- **Dependencies**: 依赖现有的 records 数据和 categories 数据结构

## Assumptions
- 年统计视图有独立的状态变量（yearCategoryView, yearChartType 等）
- 全部年份数据通过过滤所有记录的年份来聚合
- 支出/收入切换的饼图共用同一套分类数据

## Acceptance Criteria

### AC-1: 年统计时间筛选有"所有"按钮
- **Given**: 用户在统计分析页面，点击年统计
- **When**: 查看年份筛选区域
- **Then**: 年份选择器左侧有"所有"按钮，点击后显示全部数据
- **Verification**: `human-judgment`

### AC-2: 柱状图顶部显示金额
- **Given**: 用户在年统计页面查看收支统计
- **When**: 查看柱状图
- **Then**: 每个柱子顶部有金额标签
- **Verification**: `human-judgment`

### AC-3: 收支热力图已移除
- **Given**: 用户在年统计页面
- **When**: 滚动页面
- **Then**: 看不到收支热力日历模块
- **Verification**: `human-judgment`

### AC-4: 收支对比支持分类视图切换
- **Given**: 用户在年统计页面查看收支对比
- **When**: 点击一级分类/全部
- **Then**: 图表数据相应切换
- **Verification**: `human-judgment`

### AC-5: 支出占比支持收入/支出切换
- **Given**: 用户在年统计页面查看支出占比
- **When**: 点击"切换到收入"按钮
- **Then**: 饼图切换为收入数据，按钮变为"切换到支出"，所有扇区有标签
- **Verification**: `human-judgment`

### AC-6: 支出数据列表数据正确
- **Given**: 用户在年统计页面查看支出数据列表
- **When**: 切换一级分类/全部
- **Then**: 列表数据与饼图数据一致
- **Verification**: `human-judgment`

### AC-7: 标签数据正确
- **Given**: 用户在年统计页面查看标签占比和标签数据列表
- **When**: 查看数据
- **Then**: 标签数据与收支分析中的标签数据一致
- **Verification**: `human-judgment`

### AC-8: 构建成功
- **Given**: 修改完成
- **When**: 运行 npm run build
- **Then**: 构建成功，无错误
- **Verification**: `programmatic`
