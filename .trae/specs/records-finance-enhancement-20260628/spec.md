# 收支分析功能增强 - Product Requirement Document

## Overview
- **Summary**: 对收支分析页面进行全面功能增强，包括账本显示修复、日月年统计筛选Tab、自定义标签功能、分类图标自定义、后端数据库表结构改造、高级图表库引入、多币种统计等核心功能
- **Purpose**: 提升用户在收支分析页面的使用体验，提供更丰富的数据筛选维度、更灵活的分类管理、更专业的图表展示和多币种支持
- **Target Users**: Wealth OS 个人资产管理系统的所有用户

## Goals
- 修复账本新增后页面不显示的问题
- 实现日月年统计 Tab 筛选，参考参考图片样式，数据真实计算
- 新增收支记录标签字段，支持自定义标签的增删改查
- 为一级分类和二级分类添加图标，支持用户自定义选择图标
- 后端数据库表结构改造，新增标签表、分类图标字段、账本表等
- 引入专业图表库（如 recharts/echarts）替换原生 SVG 方案
- 实现多币种统计功能，支持不同币种的收支记录和汇总换算

## Non-Goals (Out of Scope)
- 不涉及移动端适配优化
- 不实现加密货币实时行情对接

## Background & Context
当前项目基于 React + Vite + TailwindCSS 架构，前端页面在 `assert_WEB/src/pages/Records.jsx` 中实现。后端通过 `/api/state` 接口保存和加载用户状态数据，数据库使用 MySQL。

现有问题：
1. 账本功能存在但新增后页面显示有问题
2. 时间筛选只有简单的日常/月统计/年统计/自定义 Tab，月统计下只有固定几个月份按钮，年统计下没有具体年份筛选
3. 记录没有标签字段，无法按标签分类统计
4. 分类只有文字，没有图标，视觉体验较差
5. 图表使用原生 SVG，功能有限，交互性差
6. 不支持多币种记录和统计

## Functional Requirements

### FR-1: 账本显示修复
- 新增账本后，收支分析页面的账本下拉选择器能立即显示新账本
- 账本切换后，页面数据能正确过滤并刷新
- 账本列表与后端数据库保持同步

### FR-2: 日月年统计筛选 Tab
- **日常 Tab**: 日历视图显示每日收支，支持日期选择
- **月统计 Tab**: 
  - 顶部显示年份选择（可切换年份）
  - 月份快捷按钮（本月、上月、前5个月）
  - 月支出/月收入/月结余三大指标卡片
  - 日均支出/日均收入/日均结余
  - 转账、还款、收款等特殊类型统计
  - 应付/借入、应收/借出、手续费
  - 报销、报销到账、待报销
  - 退款、退款收入、退款支出
  - 支出优惠、收入优惠
- **年统计 Tab**:
  - 年份选择器
  - 年度总支出/总收入/总结余
  - 各月份收支柱状对比图
  - 年度收支趋势折线图
  - 年度分类占比饼图
- **自定义 Tab**: 支持选择起止日期范围

### FR-3: 收支统计模块增强
- 收支趋势统计图（柱状图，支持支出/收入/结余切换）
- 资产走势图（折线面积图）
- 支出/收入占比环形图
- 分类排行列表（带图标、笔数、金额、环比同比）
- 报表统计表格（日期、收入、支出、结余）

### FR-4: 自定义标签功能
- 新增记录弹窗中增加标签字段
- 支持创建自定义标签（标签名称、标签颜色）
- 支持编辑标签名称和颜色
- 支持删除标签
- 记录可以选择多个标签
- 收支分析支持按标签筛选
- 标签数据持久化到后端数据库

### FR-5: 分类图标功能
- 每个一级分类和二级分类都有对应的图标
- 内置一套默认图标库（lucide-react 图标）
- 用户可以为每个分类自定义选择图标
- 图标在分类选择器、统计图表、记录列表中显示
- 图标设置持久化到后端数据库

### FR-6: 后端数据库表结构改造
- 新增 `books` 表：账本表（id, name, user_id, icon, color, sort_order, created_at）
- 新增 `tags` 表：标签表（id, name, color, user_id, sort_order, created_at）
- 新增 `record_tags` 表：记录-标签关联表（record_id, tag_id, user_id）
- `records` 表增加 `book_id` 字段
- `custom_record_categories` 表增加 `icon` 字段
- 数据迁移脚本确保现有数据平滑升级

### FR-7: 高级图表库引入
- 引入 recharts 或 echarts 图表库
- 柱状图：支持堆叠、多系列、交互提示
- 折线图：支持面积填充、多系列、缩放
- 饼图/环形图：支持交互高亮、图例联动
- 图表支持响应式布局
- 图表支持导出图片（可选）

### FR-8: 多币种统计功能
- 记录支持选择币种
- 各币种独立统计
- 支持设置汇率，自动换算为基准币种
- 统计页面支持切换显示币种
- 多币种汇总显示（按基准币种换算）
- 汇率数据持久化

## Non-Functional Requirements
- **NFR-1**: 页面加载时间不超过 2 秒（1000 条记录以内）
- **NFR-2**: 筛选切换响应时间不超过 300ms
- **NFR-3**: 所有状态变更自动保存到后端，刷新页面不丢失
- **NFR-4**: 保持深色/浅色主题兼容
- **NFR-5**: 代码风格与现有代码保持一致
- **NFR-6**: 数据库迁移脚本支持向前兼容，不丢失现有数据

## Constraints
- **Technical**: React 18 + Vite 5 + TailwindCSS 3 + MySQL
- **Business**: 不破坏现有数据结构，向后兼容，提供数据迁移
- **Dependencies**: 引入 recharts 或 echarts 作为图表库，lucide-react 作为图标库

## Assumptions
- 用户最多创建 50 个自定义标签
- 分类数量不超过 50 个一级分类，每个一级分类下不超过 20 个二级分类
- 图标使用 lucide-react 提供的图标，用户从图标选择器中选择
- 图表库选择 recharts（React 友好，体积适中）
- 基准币种默认为 CNY，用户可自定义
- 汇率数据由用户手动维护

## Acceptance Criteria

### AC-1: 账本新增后立即显示
- **Given**: 用户在账本管理中新增了一个账本
- **When**: 用户返回收支分析页面并打开账本选择器
- **Then**: 新增加的账本立即出现在下拉列表中
- **Verification**: `programmatic`

### AC-2: 月统计页面数据正确
- **Given**: 用户有若干条收支记录
- **When**: 用户切换到月统计 Tab 并选择某个月份
- **Then**: 月支出、月收入、月结余、日均数据等所有统计数据计算正确，与记录数据一致
- **Verification**: `programmatic`

### AC-3: 年统计页面数据正确
- **Given**: 用户有跨年度的收支记录
- **When**: 用户切换到年统计 Tab 并选择某个年份
- **Then**: 年度总收支、各月份对比、年度趋势等数据计算正确
- **Verification**: `programmatic`

### AC-4: 自定义标签 CRUD
- **Given**: 用户在标签管理界面
- **When**: 用户创建、编辑、删除标签
- **Then**: 标签列表实时更新，数据持久化到数据库，刷新页面后仍然存在
- **Verification**: `programmatic`

### AC-5: 记录可选择标签
- **Given**: 用户在新增记录弹窗中
- **When**: 用户选择一个或多个标签并保存记录
- **Then**: 记录成功保存，标签与记录关联（record_tags 表），在记录列表中显示标签
- **Verification**: `programmatic`

### AC-6: 按标签筛选
- **Given**: 用户有多条带不同标签的记录
- **When**: 用户在收支分析页面按标签筛选
- **Then**: 只显示包含选中标签的记录，统计数据相应更新
- **Verification**: `programmatic`

### AC-7: 分类图标显示
- **Given**: 系统中有若干分类
- **When**: 用户查看分类选择器、统计图表、记录列表
- **Then**: 每个分类都显示对应的图标
- **Verification**: `human-judgment`

### AC-8: 自定义分类图标
- **Given**: 用户在分类管理界面
- **When**: 用户为某个分类选择或更换图标
- **Then**: 图标立即更新，所有显示该分类的地方都使用新图标，持久化到数据库
- **Verification**: `programmatic`

### AC-9: 数据持久化
- **Given**: 用户进行了标签管理或图标设置操作
- **When**: 用户刷新页面
- **Then**: 所有设置和数据保持不变
- **Verification**: `programmatic`

### AC-10: UI 样式符合参考图
- **Given**: 用户打开收支分析页面
- **When**: 查看各统计模块的布局和样式
- **Then**: 整体布局和视觉风格与参考图片一致
- **Verification**: `human-judgment`

### AC-11: 数据库迁移成功
- **Given**: 升级前有历史数据
- **When**: 执行数据库迁移脚本
- **Then**: 所有现有数据保留，新增字段和表结构正确创建
- **Verification**: `programmatic`

### AC-12: 图表库正常工作
- **Given**: 用户打开收支分析页面
- **When**: 查看柱状图、折线图、饼图等图表
- **Then**: 图表使用图表库渲染，交互流畅（hover提示、点击高亮等）
- **Verification**: `human-judgment`

### AC-13: 多币种记录
- **Given**: 用户新增记录时
- **When**: 选择不同币种并保存
- **Then**: 记录保存正确的币种信息，在列表中显示币种符号
- **Verification**: `programmatic`

### AC-14: 多币种统计换算
- **Given**: 用户有多币种记录并设置了汇率
- **When**: 查看统计数据
- **Then**: 统计数据支持按基准币种换算显示，也支持分币种查看
- **Verification**: `programmatic`
