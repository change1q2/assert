# 资产总览收益与盈亏增强 Spec

## Why
当前资产总览页面的"收益与盈亏"卡片仅展示基础资产（assets 表）的市值/投入/分类盈亏，未将理财模块（financeAssets）和独立资产模块（independentAssets）的盈亏纳入综合现金流计算。用户需要更全面的收益与盈亏视图，将理财盈亏和独立资产盈亏统一计入总流入/总流出，并新增饼图展示各组成部分的占比，同时资产配置需拆分为理财/独立/综合三张饼图。

## What Changes
- **理财总资产卡片**：标题下方新增"理财总盈亏"行，显示盈亏金额和收益率
- **独立总资产卡片**：标题下方新增"独立资产总盈亏"行，显示盈亏金额和收益率
- **收益与盈亏卡片重构**：
  - 移除原有"市值/投入/分类盈亏"展示
  - 新增"总流入/总流出/综合现金流"三个指标
  - 计算公式将理财盈亏和独立资产盈亏纳入
- **新增流入构成饼图卡片**：展示总收入、理财正盈亏、独立资产正盈亏的占比
- **新增流出构成饼图卡片**：展示总支出、理财负盈亏（绝对值）、独立资产负盈亏（绝对值）、总负债的占比
- **新增资产负债图标**：在总负债卡片标题处增加图标
- **资产配置区域重构**：
  - 原"资产配置"标题改为"理财资产配置"
  - 新增"独立资产配置"饼图卡片
  - 新增"综合资产配置"饼图卡片（理财资产 vs 独立资产）

## Impact
- Affected code: `assert_WEB/src/pages/Overview.jsx`
- Affected data: `financeAssets`（理财模块数据）、`independentAssets`（独立资产数据）、`records`（收支记录）、`debts`（债务数据）

## ADDED Requirements

### Requirement: 理财总资产卡片显示总盈亏
系统 SHALL 在理财总资产卡片的总资产金额下方，新增一行显示理财总盈亏。

#### Scenario: 显示理财总盈亏
- **WHEN** 页面加载且 financeAssets 有数据
- **THEN** 计算理财总盈亏 = 理财总市值 - 理财总成本
- **AND** 计算理财总收益率 = 理财总盈亏 / 理财总成本 × 100%
- **AND** 在理财总资产金额下方显示盈亏金额和收益率
- **AND** 盈利时显示绿色，亏损时显示红色

### Requirement: 独立总资产卡片显示总盈亏
系统 SHALL 在独立总资产卡片的总资产金额下方，新增一行显示独立资产总盈亏。

#### Scenario: 显示独立资产总盈亏
- **WHEN** 页面加载且 independentAssets 有数据
- **THEN** 计算独立资产总盈亏 = 独立总资产市值 - 独立总资产成本
- **AND** 计算独立资产总收益率 = 独立资产总盈亏 / 独立总资产成本 × 100%
- **AND** 在独立总资产金额下方显示盈亏金额和收益率
- **AND** 盈利时显示绿色，亏损时显示红色

### Requirement: 收益与盈亏卡片展示综合现金流
系统 SHALL 重构"收益与盈亏"卡片，展示总流入、总流出和综合现金流三个核心指标。

#### Scenario: 计算总流入
- **WHEN** 计算总流入时
- **THEN** 总流入 = 总收入 + 理财正盈亏 + 独立资产正盈亏
- **AND** 理财正盈亏 = max(理财总盈亏, 0)
- **AND** 独立资产正盈亏 = max(独立资产总盈亏, 0)

#### Scenario: 计算总流出
- **WHEN** 计算总流出时
- **THEN** 总流出 = 总支出 + 理财负盈亏绝对值 + 独立资产负盈亏绝对值 - 总负债
- **AND** 理财负盈亏绝对值 = max(-理财总盈亏, 0)
- **AND** 独立资产负盈亏绝对值 = max(-独立资产总盈亏, 0)
- **AND** 总负债从 computeLiabilities 获取

#### Scenario: 计算综合现金流
- **WHEN** 计算综合现金流时
- **THEN** 综合现金流 = 总流入 - 总流出

#### Scenario: 卡片展示
- **WHEN** 收益与盈亏卡片渲染时
- **THEN** 顶部显示"总流入"、"总流出"、"综合现金流"三个大字指标
- **AND** 每个指标下方显示对应金额
- **AND** 综合现金流为正显示绿色，为负显示红色
- **AND** 下方保留分类盈亏列表（现有逻辑不变）

### Requirement: 新增流入构成饼图卡片
系统 SHALL 在收益与盈亏区域下方或旁边新增一张饼图卡片，展示总流入的各组成部分占比。

#### Scenario: 流入构成饼图数据
- **WHEN** 计算流入构成数据时
- **THEN** 数据包含：
  - 总收入（来自 records 的 income）
  - 理财正盈亏（max(理财总盈亏, 0)）
  - 独立资产正盈亏（max(独立资产总盈亏, 0)）
- **AND** 使用 Recharts PieChart 渲染饼图
- **AND** 饼图显示各组成部分的名称、金额和占比百分比

### Requirement: 新增流出构成饼图卡片
系统 SHALL 在流入构成饼图旁边新增一张饼图卡片，展示总流出的各组成部分占比。

#### Scenario: 流出构成饼图数据
- **WHEN** 计算流出构成数据时
- **THEN** 数据包含：
  - 总支出（来自 records 的 expense）
  - 理财负盈亏绝对值（max(-理财总盈亏, 0)）
  - 独立资产负盈亏绝对值（max(-独立资产总盈亏, 0)）
  - 总负债
- **AND** 使用 Recharts PieChart 渲染饼图
- **AND** 饼图显示各组成部分的名称、金额和占比百分比

### Requirement: 新增资产负债图标
系统 SHALL 在总负债卡片的标题区域增加一个资产负债相关的图标。

#### Scenario: 显示图标
- **WHEN** 总负债卡片渲染时
- **THEN** 标题右侧显示一个 Scale 或 Balance 图标（来自 lucide-react）
- **AND** 图标颜色为红色系，与卡片主题一致

### Requirement: 理财资产配置饼图
系统 SHALL 将原有的"资产配置"标题改为"理财资产配置"，并确保饼图仅展示理财资产（financeAssets）的分类占比。

#### Scenario: 理财资产配置数据
- **WHEN** 计算理财资产配置数据时
- **THEN** 仅使用 financeAssets 的数据
- **AND** 按资产 kind 或 category 分组统计 currentValue
- **AND** 保留现有 PieChart 渲染逻辑

### Requirement: 独立资产配置饼图
系统 SHALL 在理财资产配置旁边新增"独立资产配置"饼图卡片。

#### Scenario: 独立资产配置数据
- **WHEN** 计算独立资产配置数据时
- **THEN** 使用 independentAssets 的数据
- **AND** 按资产类型（保险、房产、车辆、固定投资、股权、定期资产）分组统计市值
- **AND** 使用 Recharts PieChart 渲染饼图
- **AND** 饼图显示类型名称、金额和占比百分比

### Requirement: 综合资产配置饼图
系统 SHALL 在独立资产配置旁边新增"综合资产配置"饼图卡片，展示理财资产和独立资产的总体占比。

#### Scenario: 综合资产配置数据
- **WHEN** 计算综合资产配置数据时
- **THEN** 数据仅包含两项：
  - 理财资产（financeTotalValue）
  - 独立资产（independentTotalValue）
- **AND** 使用 Recharts PieChart 渲染饼图
- **AND** 饼图显示名称、金额和占比百分比

## MODIFIED Requirements

### Requirement: 收益与盈亏卡片展示内容
原需求：展示当年收益率、市值/投入进度条、分类盈亏列表。
现修改为：展示总流入、总流出、综合现金流三个指标，下方保留分类盈亏列表。

### Requirement: 资产配置标题
原需求：标题为"资产配置"，展示所有资产（含理财和独立资产）的分类占比。
现修改为：标题为"理财资产配置"，仅展示理财资产的分类占比。

## REMOVED Requirements
无
