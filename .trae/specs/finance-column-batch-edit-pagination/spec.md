# 理财模块列名调整、批量编辑与分页优化 - Product Requirement Document

## Overview
- **Summary**: 调整理财模块列表列名（当前价值→当前市值），优化列设置浮窗显示，新增批量编辑功能，并将分页逻辑统一为收支分析模块的样式。
- **Purpose**: 统一列命名规范，提升列设置浮窗可用性，支持批量编辑持仓属性，统一分页体验。
- **Target Users**: 理财模块用户（持仓管理者）

## Goals
- 当前价值列改为当前市值
- 列设置浮窗优先完整显示，不被遮挡
- 新增批量编辑按钮，点击后显示勾选框进行批量编辑
- 批量编辑支持字段：市场、货币单位、资产类型、所属账户、资产分类（一/二/三级）、持仓分组、持仓分类、标签
- 分页逻辑改为收支分析模块样式（显示"共X条记录"、下拉选择页大小、上一页/下一页按钮、可输入页码跳转）

## Non-Goals (Out of Scope)
- 不涉及后端 API 或数据库结构变更
- 不涉及其他模块的分页逻辑修改
- 不涉及筛选汇总卡片的调整

## Background & Context
- 当前 Finance.jsx 的分页组件为自定义的 Pagination 组件，使用箭头图标和简单的页码显示
- 收支分析模块（Records.jsx）的分页样式更完整：显示总记录数、下拉选择页大小、上一页/下一页按钮、可输入页码跳转
- 当前列表已显示勾选框，但未提供批量编辑功能
- 当前列设置浮窗使用 `absolute right-0` 定位，可能被表格内容遮挡

## Functional Requirements
- **FR-1**: 列表"当前价值"列名改为"当前市值"
- **FR-2**: 列设置浮窗优先完整显示（向上展开或调整定位），不被表格内容遮挡
- **FR-3**: 列表右上角新增"批量编辑"按钮，位于"新增"按钮左侧
- **FR-4**: 点击"批量编辑"按钮后，列表显示勾选框；再次点击隐藏勾选框
- **FR-5**: 勾选后显示"编辑选中"按钮，点击弹出批量编辑弹窗
- **FR-6**: 批量编辑弹窗支持编辑以下字段：市场、货币单位、资产类型、所属账户、资产分类（一级）、资产分类二级、资产分类三级、持仓分组、持仓分类、标签
- **FR-7**: 分页逻辑改为收支分析模块样式：左侧显示"共X条记录"，右侧显示页大小下拉、上一页按钮、页码输入框、下一页按钮

## Non-Functional Requirements
- **NFR-1**: 保持现有数据结构和后端 API 不变
- **NFR-2**: 批量编辑弹窗布局清晰，字段分组合理
- **NFR-3**: 分页组件支持键盘操作（回车键跳转页码）
- **NFR-4**: 所有修改保持响应式设计

## Constraints
- **Technical**: 仅修改前端 assert_WEB/src/pages/Finance.jsx
- **Business**: 保持现有数据结构和后端 API 不变

## Assumptions
- 用户资产代码格式符合现有 tencentCodeFor 的识别规则
- 后端服务运行正常，能够获取实时行情数据

## Acceptance Criteria

### AC-1: 当前价值列名改为当前市值
- **Given**: 用户进入理财模块，查看持仓明细列表
- **When**: 查看列表表头
- **Then**: "当前价值"列显示为"当前市值"
- **Verification**: `human-judgment`

### AC-2: 列设置浮窗完整显示
- **Given**: 用户点击"列设置"按钮
- **When**: 弹窗展开
- **Then**: 弹窗完整显示，不被表格内容遮挡（向上展开或调整位置）
- **Verification**: `human-judgment`

### AC-3: 批量编辑按钮显示
- **Given**: 用户进入理财模块，查看持仓明细列表
- **When**: 查看列表右上角
- **Then**: "新增"按钮左侧显示"批量编辑"按钮
- **Verification**: `human-judgment`

### AC-4: 批量编辑模式切换
- **Given**: 用户点击"批量编辑"按钮
- **When**: 进入批量编辑模式
- **Then**: 列表显示勾选框（第一列）；再次点击"批量编辑"按钮，勾选框隐藏
- **Verification**: `human-judgment`

### AC-5: 批量编辑弹窗
- **Given**: 用户勾选多条记录后，点击"编辑选中"按钮
- **When**: 弹窗打开
- **Then**: 弹窗显示可编辑字段：市场、货币单位、资产类型、所属账户、资产分类（一/二/三级）、持仓分组、持仓分类、标签
- **Verification**: `human-judgment`

### AC-6: 批量编辑保存
- **Given**: 用户在批量编辑弹窗中修改字段值
- **When**: 点击"保存"按钮
- **Then**: 所有选中记录的对应字段更新为新值
- **Verification**: `human-judgment`

### AC-7: 分页样式统一
- **Given**: 用户进入理财模块，查看持仓明细列表底部
- **When**: 查看分页区域
- **Then**: 左侧显示"共X条记录"，右侧显示页大小下拉、上一页按钮、页码输入框、下一页按钮（与收支分析模块一致）
- **Verification**: `human-judgment`

### AC-8: 页码跳转功能
- **Given**: 用户在分页区域的页码输入框中输入页码并按回车
- **When**: 确认输入
- **Then**: 页面跳转到指定页码
- **Verification**: `human-judgment`

### AC-9: 构建验证
- **Given**: 代码修改完成
- **When**: 运行 npm run build
- **Then**: 构建成功，无错误
- **Verification**: `programmatic`

## Open Questions
- [ ] 列设置浮窗向上展开还是向下展开？（建议：检测剩余空间，优先向下，空间不足时向上）
- [ ] 批量编辑弹窗中标签字段是多选还是单选？（建议：多选，使用标签选择器）
