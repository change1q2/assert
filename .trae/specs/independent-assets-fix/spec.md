# 独立资产功能修复与增强 - 产品需求文档

## Overview
- **Summary**: 修复独立资产数据无法保存的问题，增强定期资产列表的收益率显示，并修正定期资产账户本的计算逻辑，确保只有关联了资产的账户本才显示在上方。
- **Purpose**: 解决用户反馈的独立资产数据丢失问题，提供更完整的定期资产收益率信息，确保账户本显示逻辑正确。
- **Target Users**: 所有使用独立资产功能的用户。

## Goals
- 修复独立资产数据保存问题，确保新增/编辑/删除操作能正确持久化
- 定期资产列表增加预期收益率和实际收益率列
- 修正定期资产账户本的计算逻辑（市值、成本、现值、盈亏、收益率）
- 确保只有关联了资产的账户本才在上方账户本区域显示

## Non-Goals (Out of Scope)
- 其他类型资产（保险、房产、车辆等）的收益率计算逻辑修改
- 后端数据库结构变更
- 其他页面的账户本显示逻辑

## Background & Context
当前独立资产页面存在以下问题：
1. 数据保存时通过 `saveState` 发送到后端 `/state` 接口，但可能存在数据格式问题导致保存失败
2. 定期资产列表缺少收益率字段展示
3. 定期资产的账户本计算逻辑不正确，未包含实际收益
4. 账户本显示逻辑需要确保只有关联了资产的账户才显示

## Functional Requirements
- **FR-1**: 独立资产数据（定期资产等）保存后刷新页面仍能显示
- **FR-2**: 定期资产列表新增"预期收益率"和"实际收益率"列
- **FR-3**: 定期资产账户本计算逻辑修正：
  - 当前市值 = 金额 + 实际收益
  - 持有成本 = 金额
  - 实际现价 = 当前市值
  - 持有盈亏 = 实际收益
  - 收益率 = 实际收益 / 持有成本 * 100%
- **FR-4**: 只有关联了资产的账户本才在上方显示

## Non-Functional Requirements
- **NFR-1**: 数据保存响应时间 < 500ms
- **NFR-2**: 页面加载响应时间 < 1000ms

## Constraints
- **Technical**: 仅修改前端代码，不修改后端接口
- **Dependencies**: 依赖 `/api/state` 接口的 GET 和 PUT 操作

## Assumptions
- 用户已登录并拥有有效的认证 token
- 后端 `/api/state` 接口正常工作
- 数据库中已有账户本数据

## Acceptance Criteria

### AC-1: 独立资产数据保存成功
- **Given**: 用户在定期资产页面新增一条定期资产数据并保存
- **When**: 刷新页面后重新进入独立资产页面
- **Then**: 新添加的定期资产数据仍然存在
- **Verification**: `programmatic`

### AC-2: 定期资产列表显示收益率
- **Given**: 用户进入独立资产页面的定期资产标签页
- **When**: 页面加载完成
- **Then**: 表格中包含"预期收益"、"预期收益率"、"实际收益"、"实际收益率"列
- **Verification**: `human-judgment`

### AC-3: 定期资产账户本计算正确
- **Given**: 用户在定期资产页面添加一条金额10000元、实际收益500元的定期资产，并关联到某个账户本
- **When**: 查看上方账户本区域
- **Then**: 该账户本显示：当前市值10500元，持有成本10000元，实际现价10500元，持有盈亏500元，收益率5%
- **Verification**: `programmatic`

### AC-4: 未关联资产的账户本不显示
- **Given**: 用户有5个账户本，但只有3个关联了独立资产
- **When**: 进入独立资产页面
- **Then**: 上方账户本区域只显示3个关联了资产的账户本
- **Verification**: `human-judgment`
