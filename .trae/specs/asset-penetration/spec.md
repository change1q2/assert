# 资产穿透页面 - Product Requirement Document

## Overview
- **Summary**: 在理财模块顶部总资产数字旁边添加"场内穿透"切换按钮，点击后跳转到资产穿透页面，按照券商APP模式设计多个数据分析板块
- **Purpose**: 提供类似券商APP的资产穿透分析视图，让用户能够从多个维度直观地查看和分析持仓资产
- **Target Users**: 使用理财模块进行资产管理的用户

## Goals
- 在理财模块顶部总资产数字旁边添加"场内穿透"切换按钮
- 点击按钮跳转到资产穿透页面
- 资产穿透页面按照券商风格设计多个数据展示板块
- 提供资产总览、持仓分布、涨跌幅排行、账户分布、收益分析等分析维度

## Non-Goals (Out of Scope)
- 不修改现有理财模块的核心功能
- 不添加交易功能
- 不添加实时行情推送
- 不新增后端API，复用现有数据

## Background & Context
- 当前理财模块已有账户本和持仓明细两个主要视图
- 用户希望有更直观的资产穿透分析视图，参考券商APP设计
- 资产穿透页面已创建基础版本，包含多个分析板块
- App.jsx中已配置路由和状态管理

## Functional Requirements
- **FR-1**: 理财模块顶部总资产右侧添加"场内穿透"切换按钮
- **FR-2**: 点击按钮跳转到资产穿透页面，页面有返回按钮可回到理财模块
- **FR-3**: 资产穿透页面 - 资产总览板块（总资产、总盈亏、当日盈亏）
- **FR-4**: 资产穿透页面 - 持仓分布板块（一级分类分布、二级分类分布）
- **FR-5**: 资产穿透页面 - 涨跌幅排行板块（按日涨跌幅排序的持仓列表）
- **FR-6**: 资产穿透页面 - 账户分布板块（按账户展示资产分布）
- **FR-7**: 资产穿透页面 - 收益分析板块（盈利/亏损数量、最佳/最差表现）

## Non-Functional Requirements
- **NFR-1**: 页面响应式布局，适配不同屏幕宽度
- **NFR-2**: 数据计算与理财模块保持一致
- **NFR-3**: 与现有设计风格保持一致，使用渐变色和卡片式布局
- **NFR-4**: 红涨绿跌的颜色风格（与A股习惯一致）

## Constraints
- **Technical**: React + Tailwind CSS，复用现有组件和工具函数
- **Business**: 展示类功能，不涉及交易操作
- **Dependencies**: 复用现有的 financeAssets 数据

## Assumptions
- "场内穿透"指穿透式查看所有持仓资产的多维度分析
- 券商模式参考常见券商APP的资产分析页面布局
- 数据来源与理财模块一致，使用本地存储的持仓数据
- 红涨绿跌的配色方案（A股习惯）

## Acceptance Criteria

### AC-1: 理财模块顶部添加场内穿透按钮
- **Given**: 用户在理财模块页面
- **When**: 查看顶部资产区域
- **Then**: 在总资产数字右侧显示"场内穿透"切换按钮
- **Verification**: `human-judgment`

### AC-2: 点击按钮跳转到资产穿透页面
- **Given**: 用户在理财模块页面
- **When**: 点击"场内穿透"按钮
- **Then**: 页面跳转到资产穿透页面，显示完整的分析内容
- **Verification**: `human-judgment`

### AC-3: 资产穿透页面有返回按钮
- **Given**: 用户在资产穿透页面
- **When**: 点击左上角返回按钮
- **Then**: 返回到理财模块页面
- **Verification**: `human-judgment`

### AC-4: 资产总览板块
- **Given**: 用户在资产穿透页面
- **When**: 查看页面顶部
- **Then**: 显示总资产、总盈亏、当日盈亏等核心指标，使用渐变背景
- **Verification**: `human-judgment`

### AC-5: 持仓分布板块
- **Given**: 用户在资产穿透页面
- **When**: 查看持仓分布区域
- **Then**: 显示按一级分类和二级分类的资产分布占比，使用进度条可视化
- **Verification**: `human-judgment`

### AC-6: 涨跌幅排行板块
- **Given**: 用户在资产穿透页面
- **When**: 查看涨跌幅排行区域
- **Then**: 显示按日涨跌幅从高到低排序的持仓列表，前三名特殊标识
- **Verification**: `human-judgment`

### AC-7: 账户分布板块
- **Given**: 用户在资产穿透页面
- **When**: 查看账户分布区域
- **Then**: 显示按账户的资产分布情况，包含市值和收益率
- **Verification**: `human-judgment`

### AC-8: 收益分析板块
- **Given**: 用户在资产穿透页面
- **When**: 查看收益分析区域
- **Then**: 显示盈利/亏损数量统计、最佳表现和最差表现
- **Verification**: `human-judgment`

### AC-9: 数据一致性
- **Given**: 用户在资产穿透页面
- **When**: 对比理财模块数据
- **Then**: 所有数据计算结果与理财模块保持一致
- **Verification**: `programmatic`
