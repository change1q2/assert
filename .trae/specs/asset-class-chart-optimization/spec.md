# 资产分类图表优化 - 产品需求文档

## Overview
- **Summary**: 优化资产分类模块的图表展示，包括饼图数据过滤、新增独立资产占比饼图、饼图中心显示优化、增长趋势和柱状图显示所有分类
- **Purpose**: 提升数据可视化效果，确保图表展示完整准确的分类信息
- **Target Users**: 资产管理系统用户

## Goals
- 饼图过滤0%数据，避免无效展示
- 标签自动延伸避免重叠
- 新增独立资产占比饼图
- 饼图中心总资产使用"万"单位显示
- 增长趋势图显示所有7个标准分类
- 分类金额柱状图显示所有7个标准分类

## Non-Goals (Out of Scope)
- 不修改其他页面的图表逻辑
- 不改变现有数据结构和API

## Background & Context
- 当前DEFAULT_CLASSES定义了7个标准分类：权益类、债权类、现金类、商品类、分红类、固收类、另类投资
- 当前增长趋势和柱状图只显示有数据的分类，导致分类不完整
- 用户要求显示8类，但系统实际只有7个标准分类

## Functional Requirements
- **FR-1**: 资产分类占比饼图过滤0%数据，标签重叠时自动延伸
- **FR-2**: 海内外资产占比饼图过滤0%数据，标签重叠时自动延伸
- **FR-3**: 新增独立资产占比饼图，展示保险、房产、车辆等类别
- **FR-4**: 饼图中心总资产使用"万"单位显示
- **FR-5**: 资产分类增长趋势显示所有7个标准分类（含0值分类）
- **FR-6**: 分类金额柱状图显示所有7个标准分类（含0值分类）

## Non-Functional Requirements
- **NFR-1**: 图表加载性能不低于当前水平
- **NFR-2**: 响应式布局保持正常

## Constraints
- **Technical**: React + Recharts图表库
- **Dependencies**: 现有数据结构和分类定义

## Assumptions
- 标准分类为7个（权益类、债权类、现金类、商品类、分红类、固收类、另类投资）
- 用户提到的"8类"实际应为7个标准分类

## Acceptance Criteria

### AC-1: 饼图过滤0%数据
- **Given**: 某分类金额为0
- **When**: 查看饼图
- **Then**: 该分类不在饼图中显示
- **Verification**: `programmatic`

### AC-2: 标签自动延伸
- **Given**: 饼图标签存在重叠
- **When**: 查看饼图
- **Then**: 标签自动延伸到空白区域，不重叠
- **Verification**: `human-judgment`

### AC-3: 独立资产占比饼图
- **Given**: 独立资产模块有数据
- **When**: 查看资产分类页面
- **Then**: 显示独立资产占比饼图，包含保险、房产、车辆等类别
- **Verification**: `human-judgment`

### AC-4: 饼图中心显示优化
- **Given**: 总资产金额较大
- **When**: 查看饼图
- **Then**: 中心显示使用"万"单位，不覆盖饼图区域
- **Verification**: `human-judgment`

### AC-5: 增长趋势显示所有分类
- **Given**: 部分分类金额为0
- **When**: 查看资产分类增长趋势图
- **Then**: 显示所有7个标准分类，0值分类显示为0
- **Verification**: `programmatic`

### AC-6: 分类金额柱状图显示所有分类
- **Given**: 部分分类金额为0
- **When**: 查看分类金额柱状图
- **Then**: 显示所有7个标准分类，0值分类显示为0
- **Verification**: `programmatic`
