# 统计分析页面重构V2 - 产品需求文档

## Overview
- **Summary**: 根据用户提供的4张设计图片（12.jpg自定义、14.jpg年统计、15.jpg月统计、16.jpg日常），精确重构统计分析页面的收支分析模块
- **Purpose**: 按照设计图片精确实现专业的数据可视化分析页面，包含多种图表类型和数据统计卡片
- **Target Users**: 需要对收支进行详细分析和管理的用户

## Goals
- 精确按照设计图片实现日常/月统计/年统计/自定义四种模式页面
- 日常模式：本周统计柱状图、资产汇总环形图、预算占比环形图、标签数据列表
- 月统计模式：年月选择器、月度收支卡片、收支统计柱状图、资产走势面积图、收支对比桑基图、支出占比环形图、支出数据列表、报表统计表格、标签占比环形图、标签数据列表、本月总结
- 年统计模式：年份选择器、年度收支卡片、收支统计柱状图、收支热力日历、资产走势面积图、收支对比桑基图、支出占比环形图、支出数据列表、报表统计表格、标签占比环形图、标签数据列表、年度总结
- 自定义模式：日期范围选择器、总收支卡片、收支走势折线图、资产走势面积图、收支对比桑基图、支出占比环形图、支出数据列表、标签占比环形图、标签数据列表
- 实现预算和目标功能、账本下拉多选、模块设置功能

## Non-Goals (Out of Scope)
- 不修改理财分析和债务分析模块
- 不修改数据存储结构
- 不添加新的后端API

## Background & Context
- 用户提供了4张详细的设计图片，包含日常、月统计、年统计、自定义四种模式
- 需要实现多种图表类型：折线图、面积图、桑基图、环形图、柱状图、日历热力图
- 需要实现预算管理、资产汇总、标签统计等功能

## Functional Requirements

### FR-1: 时间周期切换
- **FR-1.1**: 页面顶部添加日常/月统计/年统计/自定义四个切换按钮，样式与设计图片一致
- **FR-1.2**: 右上角添加更多操作按钮（三个点）

### FR-2: 日常模式页面（参考16.jpg）
- **FR-2.1**: 本周统计卡片：柱状图显示周一到周日支出，支持支出/收入切换，显示总支出、日均支出、总收入、日均收入
- **FR-2.2**: 资产汇总卡片：环形图显示各账户资产分布，显示资产金额，有"过滤占比小于1%的资产"复选框，"查看资产分布"链接
- **FR-2.3**: 预算占比卡片：环形图显示各分类预算分配，"查看详情"链接
- **FR-2.4**: 标签数据卡片：列表显示标签，包含笔数、支出金额、收入金额

### FR-3: 月统计模式页面（参考15.jpg）
- **FR-3.1**: 年份选择器 + 月份选择器（本月、上月、具体月份）
- **FR-3.2**: 月支出/月收入/月结余统计卡片（蓝色背景）
- **FR-3.3**: 收支统计柱状图（按日统计，支持支出/收入/结余切换）
- **FR-3.4**: 资产走势面积图
- **FR-3.5**: 收支对比桑基图（流向图，支持一级分类/全部切换）
- **FR-3.6**: 支出占比环形图（支持一级分类/全部切换）
- **FR-3.7**: 支出数据列表（显示分类、笔数、金额、占比、同比上月变化）
- **FR-3.8**: 报表统计表（日期、收入、支出、结余）
- **FR-3.9**: 标签占比环形图
- **FR-3.10**: 标签数据列表
- **FR-3.11**: 本月总结输入区域

### FR-4: 年统计模式页面（参考14.jpg）
- **FR-4.1**: 年份选择器（今年、去年、更早年份）
- **FR-4.2**: 年支出/年收入/年结余统计卡片（蓝色背景）
- **FR-4.3**: 收支统计柱状图（按月统计）
- **FR-4.4**: 收支热力日历图（显示每月收支热度）
- **FR-4.5**: 资产走势面积图
- **FR-4.6**: 收支对比桑基图
- **FR-4.7**: 支出占比环形图
- **FR-4.8**: 支出数据列表
- **FR-4.9**: 报表统计表（月份、收入、支出、结余）
- **FR-4.10**: 标签占比环形图
- **FR-4.11**: 标签数据列表
- **FR-4.12**: 年度总结输入区域

### FR-5: 自定义模式页面（参考12.jpg）
- **FR-5.1**: 日期范围选择器（显示格式：YYYY-MM-DD — YYYY-MM-DD）
- **FR-5.2**: 总支出/总收入/总结余统计卡片（蓝色背景）
- **FR-5.3**: 收支走势折线图（支出红色、收入绿色）
- **FR-5.4**: 资产走势面积图
- **FR-5.5**: 收支对比桑基图
- **FR-5.6**: 支出占比环形图
- **FR-5.7**: 支出数据列表（显示分类、笔数、金额、占比）
- **FR-5.8**: 标签占比环形图
- **FR-5.9**: 标签数据列表

### FR-6: 预算和目标功能
- **FR-6.1**: 预算占比卡片（显示各分类预算分配环形图）
- **FR-6.2**: 支持按分类设置月度/年度预算目标
- **FR-6.3**: 显示预算执行进度和剩余额度

### FR-7: 账本选择优化
- **FR-7.1**: 将账本多选改为下拉多选样式
- **FR-7.2**: 下拉框显示已选账本数量，支持全选/取消全选

### FR-8: 模块设置功能
- **FR-8.1**: 新增模块设置按钮，点击打开设置面板
- **FR-8.2**: 设置面板支持勾选/取消勾选显示的卡片
- **FR-8.3**: 设置结果保存到localStorage

## Non-Functional Requirements
- **NFR-1**: 界面风格与设计图片完全一致
- **NFR-2**: 响应式设计，适配不同屏幕尺寸
- **NFR-3**: 图表渲染流畅，数据加载性能良好

## Constraints
- **Technical**: React框架，使用recharts图表库
- **Dependencies**: 依赖现有的fetchState API

## Assumptions
- 用户提供的设计图片是最终界面标准
- 预算数据和模块设置存储在localStorage中
