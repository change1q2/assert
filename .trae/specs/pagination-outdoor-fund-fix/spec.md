# 分页样式改造与场外基金数据修复 - 产品需求文档

## 概述
- **摘要**：本次需求包含两个部分：(1) 将交易记录和持仓明细的分页组件改造为"共X条记录 + 每页条数选择 + 上一页/第X/X页/下一页"的统一样式；(2) 修复场外基金明细弹窗中昨日收益、持仓收益等数据无法正确显示的问题。
- **目的**：统一分页交互体验，确保场外基金净值数据（含前一交易日净值）能正确获取并用于收益计算。
- **目标用户**：理财模块使用者

## 目标
1. 交易记录分页和持仓明细分页统一显示"共X条记录"统计信息
2. 交易记录分页支持每页条数下拉选择（参考持仓明细的现有实现）
3. 场外基金明细弹窗正确显示昨日收益、持仓收益、日涨幅、持有收益等数据
4. 数据获取时间正确显示"同步天天基金网 MM月DD日"

## 非目标（不在范围内）
- 不修改场外基金数据计算公式（公式已确认正确）
- 不修改币种切换逻辑
- 不修改账户本/顶栏统计卡片的显示逻辑

## 背景与上下文
- 当前交易记录分页仅有"上一页/第X/X页/下一页"，缺少记录总数统计和每页条数选择
- 当前持仓明细分页（CategoryTable）有每页条数选择，但缺少记录总数统计
- 场外基金（categoryL3 === '场外'）的净值数据通过 `loadFundNav` 从天天基金网获取，包含当日净值(nav)和前一交易日净值(prevNav)
- 用户反馈 prevPrice（前一交易日净值）为 0，导致所有依赖 prevPrice 的计算（昨日收益、日涨幅）都返回 0
- 数据获取时间(priceDate)显示逻辑已存在，但需确认能正确显示

## 功能需求
- **FR-1**：交易记录分页组件增加"共X条记录"左侧统计文字
- **FR-2**：交易记录分页组件增加每页条数下拉选择（5/10/20/50条选项）
- **FR-3**：持仓明细（CategoryTable）分页组件增加"共X条记录"左侧统计文字
- **FR-4**：分页样式统一为图片所示的简洁样式（记录数在左，页码控件在右）
- **FR-5**：`loadFundNav` 正确获取并保存前一交易日净值到 `stateData.financeAssets[i].prevPrice`
- **FR-6**：`DetailModal` 中场外基金的昨日收益、持仓收益、日涨幅、持有收益等数据基于正确的 `prevPrice` 和 `currentPrice` 计算显示
- **FR-7**：数据获取时间在净值区域下方正确显示"同步天天基金网 MM月DD日"

## 非功能需求
- **NFR-1**：分页切换保持流畅，无闪烁
- **NFR-2**：场外基金数据加载失败时静默处理，不影响其他功能

## 约束
- **技术**：React + Vite + Tailwind CSS，Node.js/Koa 后端
- **依赖**：天天基金网 API（ Eastmoney API ）获取基金净值数据

## 假设
- 天天基金网 API 返回的数据包含至少2条历史净值记录（当日和前一日）
- 用户资产的 `categoryL3` 字段正确标记为"场外"

## 验收标准

### AC-1: 交易记录分页显示记录总数
- **Given**：明细弹窗中交易记录有若干条
- **When**：打开明细弹窗查看交易记录
- **Then**：分页区域左侧显示"共X条记录"（X为实际记录数）
- **Verification**：human-judgment

### AC-2: 交易记录分页支持每页条数选择
- **Given**：明细弹窗中交易记录超过5条
- **When**：用户点击每页条数下拉
- **Then**：可选择 5/10/20/50 条/页，切换后分页和列表正确更新
- **Verification**：human-judgment

### AC-3: 持仓明细分页显示记录总数
- **Given**：理财模块持仓明细表格有若干条记录
- **When**：查看表格底部分页区域
- **Then**：左侧显示"共X条记录"，且每页条数下拉正常工作
- **Verification**：human-judgment

### AC-4: 场外基金 prevPrice 正确保存
- **Given**：有一个场外基金资产（如110017）
- **When**：页面加载时 `loadFundNav` 执行
- **Then**：`stateData.financeAssets` 中对应资产的 `prevPrice` 字段被设置为前一交易日净值（非0）
- **Verification**：programmatic

### AC-5: 场外基金昨日收益正确显示
- **Given**：场外基金资产的 `prevPrice > 0` 且 `currentPrice > 0`
- **When**：打开该资产的明细弹窗
- **Then**：昨日收益显示为 份额 × (currentPrice - prevPrice)，不为0
- **Verification**：human-judgment

### AC-6: 场外基金数据获取时间正确显示
- **Given**：场外基金资产的 `priceDate` 有值（如"2026-07-14"）
- **When**：打开该资产的明细弹窗查看净值区域
- **Then**："最新净值"下方显示"数据获取时间: 同步天天基金网 07月14日"
- **Verification**：human-judgment

### AC-7: 构建成功
- **Given**：代码修改完成
- **When**：执行 `npm run build`
- **Then**：构建成功无错误
- **Verification**：programmatic
