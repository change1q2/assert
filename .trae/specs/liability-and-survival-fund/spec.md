# 负债资产显示 + 生存资金独立化 - 需求规格

## 概述
- **摘要**: 两个独立功能改造。（1）账户列表和账户详情页的负债类型账户需从债务模块获取完整数据，正确显示负债金额、已还金额、剩余本金等；（2）将生存资金从独立资产模块中独立出来，创建全新页面，包含总览卡片、自由现金流计算、账户本列表和生存资金列表。
- **目的**: 完善账户管理的负债数据展示；提供更专业的生存资金规划和管理界面。
- **目标用户**: 使用 Wealth OS 管理个人资产的用户。

## 目标
- 负债账户在账户列表中正确显示从债务模块聚合的负债数据
- 负债账户详情页显示完整的债务明细（含还款计划）
- 生存资金拥有独立侧边栏入口
- 生存资金页面提供自由现金流计算功能
- 生存资金页面展示账户本（关联账户余额汇总）

## 非目标
- 不改变债务模块本身的功能
- 不改变独立资产模块的其他分类（保险/房产/车辆等）
- 不改变理财模块的功能
- 不实现真实的自动还款提醒推送

## 背景与上下文

### 当前负债处理现状
- `Accounts.jsx` 中 `accountStats` 已从 `debts` 聚合数据（第576-586行），但仅累加 `debt.amount` 到 marketValue、`debt.principal` 到 holdingCost
- 账户列表对负债类型账户显示「当前市值 = 0」「持有成本 = 0」的问题，原因可能是债务记录未正确关联到负债账户
- 账户详情页（`AccountDetailModal`）对负债类型账户缺乏专门的债务明细展示

### 当前生存资金现状
- `IndependentAssets.jsx` 中生存资金作为一个 tab 存在
- 仅有简单的表格展示（名称/币种/金额/账户本/操作）
- 无总览卡片、自由现金流计算等功能

## 功能需求

### FR-1: 负债账户数据聚合
- 账户列表中，负债类型账户的「当前市值」应显示该账户下所有债务的**剩余未还金额**
- 「持有成本」应显示**债务本金总额**
- 「盈亏额」应显示 **剩余本金 - 原始本金**（反映已还部分）
- 「余额」应显示该负债账户关联的现金余额（如有）

### FR-2: 负债账户详情展示
- 点击负债账户的「明细」或「编辑」时，显示完整的债务明细
- 包含：债务名称、本金、利率、已还金额、剩余金额、还款方式、还款计划摘要

### FR-3: 生存资金侧边栏入口
- 在左侧导航栏「理财模块」上方添加「生存资金」入口
- 图标使用 PiggyBank 或 Wallet 图标
- 入口 ID 为 `survival-funds`

### FR-4: 生存资金页面 - 第一行 总览卡片
- 总价值（所有生存资金当前金额之和，多币种折算）
- 总成本（原始投入金额之和）
- 总收益（总价值 - 总成本）
- 总收益率（总收益 / 总成本 × 100%）

### FR-5: 生存资金页面 - 第二行 自由度计算
- 显示日/周/月/年四个自由额度
- 自由额度 = 自由现金流列表中对应周期的预算合计
- 实际现金流 = 对应周期已发生金额
- 自由度 = 实际现金流 / 预算现金流 × 100%
- 自由现金流列表：可新增预算项
  - 字段：自由名称（自定义下拉选项：必要消费-住房/基础生活，非必要消费-旅行/娱乐）、预算周期（日/周/月/年）、预计金额、实际金额
  - 最下方显示合计行

### FR-6: 生存资金页面 - 第三行 账户本
- 显示关联到生存资金的所有账户
- 每个账户卡片显示：账户名、当前余额、收益率
- 底部显示合计余额

### FR-7: 生存资金页面 - 第四行 生存资金列表
- 字段：名称、类型、币种、金额、账户本、操作
- 支持新增/编辑/删除
- 类型下拉：应急储备、日常开支、长期储备、投资本金
- 最下方显示合计行

### FR-8: 独立资产模块清理
- 从独立资产的 tabs 中移除「生存资金」选项
- 保留现有生存资金数据在 `independentAssets.survivalfund` 中
- 数据迁移：如有必要，将现有 survivalfund 数据迁移到新的 state 路径

## 非功能需求

### NFR-1: 数据一致性
- 负债账户显示的数据必须与债务模块中的数据实时一致
- 生存资金数据的增删改查必须持久化到后端数据库

### NFR-2: 响应式设计
- 生存资金页面在桌面端以多列网格布局展示
- 在窄屏上自动切换为单列堆叠

### NFR-3: 性能
- 负债数据聚合计算使用 useMemo，避免不必要的重计算
- 生存资金总览卡片计算使用 useMemo

### NFR-4: 可维护性
- 新页面文件命名为 `SurvivalFunds.jsx`
- 数据结构与现有 stateData 保持兼容
- 所有组件使用 TypeScript 类型或 JSDoc 注释

## 约束

### 技术约束
- 前端：React + Tailwind CSS
- 后端：Node.js + MySQL（state-service.js）
- 状态管理：全局 stateData（通过 fetchState/saveState）
- 路由：React Router

### 业务约束
- 负债账户的盈亏计算逻辑：盈亏 = -(市值 - 成本)，因为负债是"负资产"
- 生存资金的币种转换使用统一的 exchangeRates
- 自由度计算需处理除以零的边界情况

### 依赖
- `stateData.debts`：债务模块数据
- `stateData.accounts`：账户数据
- `stateData.independentAssets.survivalfund`：现有生存资金数据
- `exchangeRates`：汇率数据

## 假设
- 负债账户通过 `account.type === '负债'` 或 `account.liability === true` 标识
- 债务记录通过 `debt.account` 字段关联到账户（id 或 name）
- 生存资金的新 state 路径为 `stateData.survivalFunds`
- 自由现金流预算数据存储在 `stateData.freedomBudgets` 中
- 账户本关联通过 `survivalFund.accountId` 字段

## 验收标准

### AC-1: 负债账户列表数据正确
- **类型**: `rule`
- **给定**: 存在负债类型账户，且债务模块中有关联的债务记录
- **当**: 打开账户管理页面
- **则**: 该负债账户的「当前市值」显示所有关联债务的剩余未还金额，「持有成本」显示本金总额
- **通过条件**: 负债账户的市值和成本非零，且数值与债务模块一致
- **证据**: 账户列表页面截图 + 债务模块截图对比

### AC-2: 负债账户详情展示
- **类型**: `rule`
- **给定**: 选中一个负债类型账户
- **当**: 点击「明细」按钮
- **则**: 详情页显示该账户关联的所有债务记录摘要
- **通过条件**: 详情弹窗中可见债务名称、本金、已还、剩余等字段
- **证据**: 详情弹窗截图

### AC-3: 生存资金侧边栏入口
- **类型**: `rule`
- **给定**: 用户已登录
- **当**: 查看左侧导航栏
- **则**: 在「理财模块」上方可见「生存资金」入口
- **通过条件**: 侧边栏存在 id='survival-funds' 的菜单项
- **证据**: 侧边栏截图

### AC-4: 生存资金总览卡片
- **类型**: `rule`
- **给定**: 生存资金页面有数据
- **当**: 切换到生存资金页面
- **则**: 第一行显示总价值、总成本、总收益、总收益率四张卡片
- **通过条件**: 四张卡片均显示正确计算的数值
- **证据**: 页面截图 + 手动计算对比

### AC-5: 自由现金流自由度计算
- **类型**: `rule`
- **给定**: 已添加自由现金流预算项
- **当**: 生存资金页面加载
- **则**: 第二行显示日/周/月/年四个周期的自由度
- **通过条件**: 自由度 = 实际/预算 的比值计算正确
- **证据**: 页面截图 + 手动计算对比

### AC-6: 自由现金流列表
- **类型**: `rule`
- **给定**: 自由现金流列表有数据
- **当**: 查看自由现金流区域
- **则**: 显示每条预算项及其合计行
- **通过条件**: 列表正确显示所有已添加的预算项
- **证据**: 列表截图

### AC-7: 账户本展示
- **类型**: `rule`
- **给定**: 生存资金关联了账户
- **当**: 查看账户本区域
- **则**: 显示关联账户的余额卡片和合计
- **通过条件**: 账户卡片显示正确的余额数据
- **证据**: 账户本截图

### AC-8: 生存资金列表
- **类型**: `rule`
- **给定**: 生存资金有数据
- **当**: 查看生存资金列表
- **则**: 正确显示名称/类型/币种/金额/账户本/操作，底部有合计行
- **通过条件**: 列表与合计行数据一致
- **证据**: 列表截图

### AC-9: 独立资产模块清理
- **类型**: `rule`
- **给定**: 独立资产模块
- **当**: 查看 tabs
- **则**: tabs 中不再包含「生存资金」选项
- **通过条件**: tabs 只有保险/房产/车辆/固定投资/股权/定期资产
- **证据**: 独立资产页面截图

### AC-10: 数据持久化
- **类型**: `rule`
- **给定**: 新增/编辑生存资金或自由现金流
- **当**: 执行保存操作
- **则**: 数据通过 saveState 持久化到后端 MySQL
- **通过条件**: 刷新页面后数据仍然存在
- **证据**: 刷新前后截图对比 + 数据库查询

### AC-11: 页面体验
- **类型**: `rubric`
- **维度**: 视觉一致性与交互流畅性
- **规模**: 1-5
- **锚点**: 1=布局混乱/无响应式；3=基本可用/样式与现有一致；5=完美适配/交互流畅/响应式优秀
- **通过阈值**: >= 4
- **证据**: 多尺寸屏幕截图 + 交互录屏
