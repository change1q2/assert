# 理财模块持仓明细功能增强 - 产品需求文档

## Overview
- **Summary**: 对理财模块的持仓明细功能进行全面增强，包括持仓分类动态选项、场内/场外不同交易记录表单、图片识别导入功能、数据录入修复等
- **Purpose**: 提供更完善的理财资产管理体验，支持股票/基金等不同资产类型的差异化交易记录管理
- **Target Users**: 使用理财模块管理资产的个人用户

## Goals
- 实现持仓分类根据资产类型动态显示不同选项
- 实现场内/场外资产差异化的交易记录表单
- 完善图片识别导入功能，支持人工确认后导入
- 修复新增资产时数据无法录入的问题
- 完善场外基金明细弹窗的信息展示

## Non-Goals (Out of Scope)
- 后端API修改（本次仅修改前端逻辑）
- 其他模块功能变更
- 移动端适配优化

## Background & Context
- 当前持仓分类选项固定，不区分资产类型
- 场内（股票）和场外（基金）资产的交易记录字段不同，但当前表单统一
- 图片识别功能已存在，但缺少导入确认机制
- 新增资产时存在数据录入问题

## Functional Requirements

### FR-1: 持仓分类动态选项
- 当资产类型为"股票"时，持仓分类下拉选项为：成长股、价值股、周期股、消费股
- 其他资产类型保持原有选项

### FR-2: 场内资产交易记录表单
- 市场为国内市场且三级分类为"场内"时，新增记录弹窗字段：
  - 类型（建仓/买入/卖出/分红）
  - 日期（年月日）+ 时间（时分）
  - 价格
  - 数量
  - 金额（自动计算：价格*数量）
  - 费用

### FR-3: 场内资产图片识别
- 图片识别结果展示字段与场内表单一致
- 需要人工确认识别结果
- 确认无误后右上角有"导入"按钮，点击导入交易记录

### FR-4: 数据录入修复
- 修复新增资产时数据无法录入的问题
- 确保所有必填字段正确提交

### FR-5: 场外资产交易记录表单
- 市场为国内市场且三级分类为"场外"时，新增记录弹窗字段：
  - 类型（建仓/买入/卖出/分红）
  - 日期（年月日）+ 时间（时分）
  - 确认金额
  - 确认份额
  - 确认净值
  - 手续费

### FR-6: 场外资产明细弹窗展示
- 上方显示：资产、昨日收益、持仓收益、持仓收益率
- 中间显示字段：最新净值（天天基金单位净值）、净值日期、日涨幅、持仓成本单价、累计收益、全部份额、可用份额、持有收益、持有收益率
- 下方交易记录显示新增记录字段（与FR-5一致）

### FR-7: 场外资产图片识别
- 图片识别结果展示字段与场外表单一致（确认金额、确认份额、确认净值、手续费）
- 需要人工确认识别结果
- 确认无误后右上角有"导入"按钮，点击导入交易记录

## Non-Functional Requirements
- **NFR-1**: 表单字段联动，金额自动计算
- **NFR-2**: 表单验证，必填字段检查
- **NFR-3**: 响应式设计，适配不同屏幕

## Constraints
- **Technical**: React + Vite + Tailwind CSS
- **Dependencies**: 现有Finance.jsx组件结构

## Assumptions
- 后端API接口不变
- 数据结构保持兼容

## Acceptance Criteria

### AC-1: 股票持仓分类选项
- **Given**: 用户在新增/编辑持仓资产时，资产类型选择"股票"
- **When**: 查看持仓分类下拉选项
- **Then**: 显示选项为：成长股、价值股、周期股、消费股
- **Verification**: `human-judgment`

### AC-2: 场内交易记录表单
- **Given**: 资产为国内市场、三级分类为场内
- **When**: 点击操作下的"新增记录"
- **Then**: 弹窗显示字段：类型、日期、时间、价格、数量、金额（自动计算）、费用
- **Verification**: `human-judgment`

### AC-3: 场内图片识别导入
- **Given**: 上传图片进行识别
- **When**: 识别完成后显示结果列表
- **Then**: 显示可编辑的识别结果，右上角有"导入"按钮，点击后导入交易记录
- **Verification**: `human-judgment`

### AC-4: 新增资产数据录入
- **Given**: 用户填写完整的新增资产表单
- **When**: 点击保存
- **Then**: 数据成功保存到数据库并显示在列表中
- **Verification**: `human-judgment`

### AC-5: 场外交易记录表单
- **Given**: 资产为国内市场、三级分类为场外
- **When**: 点击操作下的"新增记录"
- **Then**: 弹窗显示字段：类型、日期、时间、确认金额、确认份额、确认净值、手续费
- **Verification**: `human-judgment`

### AC-6: 场外明细弹窗展示
- **Given**: 打开场外基金的明细弹窗
- **When**: 查看弹窗内容
- **Then**: 上方显示资产、昨日收益、持仓收益、持仓收益率；中间显示最新净值、日期、日涨幅等字段；下方显示交易记录
- **Verification**: `human-judgment`

### AC-7: 场外图片识别导入
- **Given**: 上传图片进行识别
- **When**: 识别完成后显示结果列表
- **Then**: 显示可编辑的识别结果（确认金额、确认份额、确认净值、手续费），右上角有"导入"按钮，点击后导入交易记录
- **Verification**: `human-judgment`
