# 债务模块增强 - 自动计算与数据同步修复

## Overview
- **Summary**: 修复债务模块的两个核心问题：1) 自动计算的总金额（本金+利息）需要自动填入表单金额字段；2) 前后端数据结构不一致导致保存后数据不显示的问题
- **Purpose**: 提升用户体验，确保债务数据正确保存和显示
- **Target Users**: 使用债务模块的所有用户

## Goals
- 自动计算的总金额（本金+利息）自动填入到表单金额字段，下方保留自动计算结果的本金和利息显示
- 修复前后端数据结构不一致问题，确保保存后数据正确显示在列表中
- 确保全局前后端数据联调一致，后端负责存储和处理数据，前端负责显示

## Non-Goals (Out of Scope)
- 修改数据库表结构（保持现有结构，调整字段映射）
- 新增其他债务模块功能
- 修改后端 API 接口

## Background & Context
- 当前债务新增/编辑弹窗中，自动计算的总金额仅显示在提示文字中，没有自动填入金额输入框
- 前端保存时发送的数据字段与后端加载时返回的字段不一致，导致保存后数据不显示
- 需要参考收支分析模块的成功联调经验，统一前后端数据结构

## Functional Requirements
- **FR-1**: 当用户输入本金、利率、还款日期和还款方式后，自动计算总金额并填入金额字段
- **FR-2**: 在金额字段下方保留自动计算结果的本金和利息显示
- **FR-3**: 确保前端保存的债务数据字段与后端期望的字段一致
- **FR-4**: 确保后端加载的债务数据字段与前端期望的字段一致

## Non-Functional Requirements
- **NFR-1**: 页面响应时间 < 2秒
- **NFR-2**: 表单操作流畅，无卡顿
- **NFR-3**: 界面美观，符合现有设计风格

## Constraints
- **Technical**: React + Vite + TailwindCSS，后端 Node.js + MySQL
- **Dependencies**: 使用现有的 `/api/state` 接口进行数据同步

## Assumptions
- 用户已登录，能正常访问 API
- MySQL 数据库已配置运行

## Acceptance Criteria

### AC-1: 自动计算总金额填入金额字段
- **Given**: 用户在新增债务弹窗中输入本金、利率、还款日期和还款方式
- **When**: 表单数据满足计算条件（本金>0，利率>0，有日期）
- **Then**: 金额字段自动填入计算后的总金额（本金+利息）
- **Verification**: `human-judgment`

### AC-2: 显示自动计算结果详情
- **Given**: 用户在新增债务弹窗中输入计算所需数据
- **When**: 自动计算触发
- **Then**: 金额字段下方显示自动计算结果，包含本金和利息明细
- **Verification**: `human-judgment`

### AC-3: 保存后数据正确显示
- **Given**: 用户保存一条债务记录
- **When**: 页面刷新后重新加载数据
- **Then**: 债务记录正确显示在列表中，包含所有字段
- **Verification**: `human-judgment`

### AC-4: 前后端数据结构统一
- **Given**: 用户执行保存和加载操作
- **When**: 查看数据库和前端状态
- **Then**: 前后端数据字段映射一致，无缺失
- **Verification**: `programmatic`
