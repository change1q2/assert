# 资产穿透页面功能增强 - 产品需求文档

## Overview
- **Summary**: 资产穿透页面需要增强多项功能，包括自定义时间区间选择、指数曲线图/K线图数据获取、增加纳斯达克和标普500指数、仓位分析饼图、日历收益显示优化等。
- **Purpose**: 提升用户在资产穿透页面的数据可视化和分析能力，使投资分析更加直观和全面。
- **Target Users**: 个人投资者，使用资产穿透页面进行投资组合分析的用户。

## Goals
- 实现自定义时间区间选择，提供常用时间段快速选择
- 修复指数曲线图和K线图显示问题，接入中证指数官网数据源
- 添加纳斯达克和标普500指数数据，支持美股指数对比
- 实现仓位分析饼图，支持三级分类钻取
- 优化日历收益显示，支持收益率/收益金额切换，正确显示红绿色
- 实现月收益、年收益、阶段收益的正确展示格式
- 日收益日历单元格整框变色，优化视觉效果
- 柱状图优化：统一正方向显示，不同颜色区分，支持横向滚动
- 我的资产模块重构：移除资产分类占比，新增持仓分组/分类饼图和一至四级分类饼图，支持双饼图并排显示和层级钻取

## Non-Goals (Out of Scope)
- 实现真实交易功能
- 添加更多复杂的技术指标
- 实现用户注册/登录功能
- 移动端适配优化

## Background & Context
- 当前资产穿透页面位于 `assert_WEB/src/pages/AssetPenetration.jsx`
- 后端API位于 `assert_PLATFORM/server/routes/finance.js`
- 当前指数数据源使用新浪财经接口，K线图数据未正确显示
- 当前日历收益数据为模拟生成，需要优化显示逻辑

## Functional Requirements
- **FR-1**: 自定义时间区间选择 - 点击"自定义"按钮后显示时间区间选择器，提供常用时间段选项（近一周、近一月、近三月、近半年、近一年）
- **FR-2**: 指数曲线图/K线图数据 - 接入中证指数官网(https://www.csindex.com.cn)获取指数数据，修复图表显示问题
- **FR-3**: 增加纳斯达克和标普500指数 - 从百度财经(https://finance.baidu.com/index/us-IXIC)获取美股指数数据
- **FR-4**: 仓位分析饼图 - 勾选"仓位分析"后显示饼图，展示一级分类仓位占比，支持点击一级分类查看二级分类，再点击查看三级分类
- **FR-5**: 日历收益日收益显示 - 日收益为正数时日历单元格显示红色，负数时显示蓝色；支持收益率/收益金额切换，切换时日历显示相应数据
- **FR-6**: 月收益显示 - 按图片格式展示月收益数据，显示12个月的收益情况，正数红色，负数蓝色
- **FR-7**: 年收益显示 - 按图片格式展示年收益数据，显示多年的收益情况，正数红色，负数蓝色
- **FR-8**: 阶段收益显示 - 按图片格式展示阶段收益数据，包括本周、本月、近半年、马年以来、最大盈利区间、最大回撤区间、自定义区间
- **FR-9**: 日收益日历整框变色 - 日收益日历单元格整个背景颜色随收益变化，正数红色背景，负数蓝色背景，日期数字和收益数据清晰显示在色块上
- **FR-10**: 柱状图优化 - 所有柱状图统一正方向向上显示，盈利和亏损用不同颜色区分，每个柱子上方显示金额（正数显示正金额，负数显示负金额），数据过多时支持横向滚动拖动
- **FR-11**: 我的资产模块重构 - 移除"资产分类收益占比"模块，新增分类选择功能，支持一行显示2个饼图（持仓分组/持仓分类饼图 + 一至四级分类饼图），两个饼图为层级关系，点击一级分类中的某一项进入二级分类，依次类推至四级

## Non-Functional Requirements
- **NFR-1**: API响应时间<3秒
- **NFR-2**: 图表加载动画流畅
- **NFR-3**: 数据展示实时性，点击刷新时重新获取数据

## Constraints
- **Technical**: Vue 3 + JavaScript, Vite, 使用fetch获取外部数据
- **Dependencies**: 依赖外部API（中证指数官网、百度财经）
- **Business**: 仅展示数据，不进行交易操作

## Assumptions
- 用户已安装现代浏览器（Chrome/Firefox/Edge）
- 外部API接口稳定可用
- 用户网络连接正常

## Acceptance Criteria

### AC-1: 自定义时间区间选择
- **Given**: 用户在资产穿透页面
- **When**: 用户点击"自定义"按钮
- **Then**: 显示时间区间选择器，包含常用时间段选项（近一周、近一月、近三月、近半年、近一年），点击选项后更新时间范围
- **Verification**: `human-judgment`

### AC-2: 指数曲线图数据显示
- **Given**: 用户选择了某个指数（如上证50）
- **When**: 用户查看曲线图
- **Then**: 曲线显示完整的指数数据，数据来源于中证指数官网，与官网数据一致
- **Verification**: `human-judgment`

### AC-3: 指数K线图数据显示
- **Given**: 用户选择了某个指数
- **When**: 用户切换到K线视图
- **Then**: K线图正确显示开盘价、收盘价、最高价、最低价数据
- **Verification**: `human-judgment`

### AC-4: 纳斯达克和标普500指数显示
- **Given**: 用户在指数选择区域
- **When**: 用户查看指数列表
- **Then**: 列表中包含纳斯达克和标普500指数，点击后显示对应指数数据
- **Verification**: `human-judgment`

### AC-5: 仓位分析饼图一级分类
- **Given**: 用户勾选"仓位分析"选项
- **When**: 页面加载完成
- **Then**: 显示一级分类仓位饼图，展示各分类占比
- **Verification**: `human-judgment`

### AC-6: 仓位分析饼图二级分类钻取
- **Given**: 用户已看到一级分类饼图
- **When**: 用户点击某个一级分类
- **Then**: 饼图切换为该一级分类下的二级分类数据
- **Verification**: `human-judgment`

### AC-7: 仓位分析饼图三级分类钻取
- **Given**: 用户已看到二级分类饼图
- **When**: 用户点击某个二级分类
- **Then**: 饼图切换为该二级分类下的三级分类数据
- **Verification**: `human-judgment`

### AC-8: 日历收益日收益颜色显示
- **Given**: 用户在日历收益模块，选择"日收益"视图
- **When**: 查看日历数据
- **Then**: 日收益为正数的日期显示红色，负数显示蓝色
- **Verification**: `human-judgment`

### AC-9: 日历收益收益率/金额切换
- **Given**: 用户在日历收益模块
- **When**: 用户点击"收益率"或"收益金额"按钮
- **Then**: 日历单元格显示对应的数据（收益率百分比或金额数值）
- **Verification**: `human-judgment`

### AC-10: 月收益显示格式
- **Given**: 用户选择"月收益"视图
- **When**: 页面加载完成
- **Then**: 按图片格式显示12个月收益，正数红色背景，负数蓝色背景，显示收益金额
- **Verification**: `human-judgment`

### AC-11: 年收益显示格式
- **Given**: 用户选择"年收益"视图
- **When**: 页面加载完成
- **Then**: 按图片格式显示多年收益，正数红色背景，负数蓝色背景，显示收益金额，底部显示全部总收益和同期上证
- **Verification**: `human-judgment`

### AC-12: 阶段收益显示格式
- **Given**: 用户选择"阶段收益"视图
- **When**: 页面加载完成
- **Then**: 按图片格式显示各阶段收益表格，包含阶段、收益、收益率、同期上证列
- **Verification**: `human-judgment`

### AC-13: 日收益日历整框变色
- **Given**: 用户在日历收益模块，选择"日收益"视图和"日历图"
- **When**: 查看日历数据
- **Then**: 每个日期单元格整个背景填充颜色，正数红色背景，负数蓝色背景，日期数字和收益数据显示在色块上，清晰可读
- **Verification**: `human-judgment`

### AC-14: 柱状图优化显示
- **Given**: 用户在日历收益模块，选择"柱状图"视图
- **When**: 查看柱状图数据
- **Then**: 所有柱子统一向上正方向显示，盈利用红色，亏损用蓝色，每个柱子顶部显示金额数值，负数显示负号，数据超出时可横向滚动查看
- **Verification**: `human-judgment`

### AC-15: 我的资产模块双饼图显示
- **Given**: 用户在"我的资产"区域
- **When**: 查看资产分类
- **Then**: 一行显示2个饼图，左侧为持仓分组/持仓分类饼图，右侧为一至四级分类饼图，提供分类方式选择按钮
- **Verification**: `human-judgment`

### AC-16: 分类饼图层级钻取
- **Given**: 用户看到一级分类饼图
- **When**: 用户点击某个一级分类
- **Then**: 饼图切换到该分类的二级分类；继续点击可进入三级、四级分类，支持返回上一级
- **Verification**: `human-judgment`
