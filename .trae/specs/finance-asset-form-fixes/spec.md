# 持仓资产表单功能完善 - 产品需求文档

## Overview
- **Summary**: 修复持仓资产表单中的多项功能问题，包括场内基金盈亏计算、三级分类必填、市场与二级分类联动、筛选条件保存、账户余额显示、货币转换等
- **Purpose**: 解决用户反馈的10个功能缺陷，提升持仓资产管理的准确性和用户体验
- **Target Users**: 资产平台的普通用户和管理员

## Goals
1. 修复基金场内分类下持仓盈亏和盈亏率显示为0的问题
2. 场内分类资产统一使用股票场内的输入逻辑，不显示盈亏/市值输入框
3. 实现持仓明细筛选条件的历史保存和自定义组合功能
4. 修复账户管理中余额数据未显示的问题
5. 将三级分类设为必填项
6. 实现市场选择与资产二级分类的联动（港股→港股，美股→美股，国内→A股/港股通）
7. 实现账户管理的货币转换显示功能
8. 实现资产分类一级与资产类型的联动

## Non-Goals (Out of Scope)
- 不修改数据库表结构
- 不添加新的API接口
- 不修改后端服务逻辑
- 不调整现有的数据统计计算逻辑

## Background & Context
当前Finance.jsx组件包含了持仓资产的表单逻辑，存在以下问题：
1. 基金场内分类的盈亏计算逻辑与股票场内不一致
2. 三级分类不是必填项
3. 市场选择与二级分类没有联动
4. 筛选条件没有保存功能
5. 账户管理的余额没有正确显示
6. 账户货币选择没有影响显示

## Functional Requirements
- **FR-1**: 基金场内分类使用与股票场内相同的盈亏计算逻辑
- **FR-2**: 场内分类资产不显示持仓盈亏、盈亏率、当前市值输入框（自动计算）
- **FR-3**: 支持保存历史筛选条件，可自定义组合名称，下次直接点击筛选
- **FR-4**: 账户管理列表显示正确的余额数据
- **FR-5**: 三级分类设为必填项
- **FR-6**: 市场选择港股时，二级分类只显示"港股"选项
- **FR-7**: 市场选择美股时，二级分类只显示"美股"选项
- **FR-8**: 市场选择国内市场时，二级分类显示"A股"和"港股通"选项
- **FR-9**: 账户管理中选择货币后，账户余额按汇率转换显示
- **FR-10**: 资产分类一级与资产类型联动，选择一级分类后只显示对应资产类型选项

## Non-Functional Requirements
- **NFR-1**: 所有修改不影响现有功能的稳定性
- **NFR-2**: 前端构建必须通过，无编译错误
- **NFR-3**: 界面交互流畅，无明显卡顿

## Constraints
- **Technical**: 使用React + Vite构建，依赖现有组件结构
- **Business**: 保持现有UI风格和交互习惯
- **Dependencies**: 依赖后端API和本地存储

## Assumptions
- 现有汇率API可用
- 本地存储(localStorage)可正常使用
- 现有数据结构支持所需字段

## Acceptance Criteria

### AC-1: 基金场内盈亏计算修复
- **Given**: 用户选择资产类型为基金，三级分类为场内
- **When**: 输入持仓成本和数量后
- **Then**: 持仓盈亏和盈亏率自动计算并显示正确数值（与股票场内逻辑一致）
- **Verification**: `human-judgment`

### AC-2: 场内分类不显示手动输入盈亏字段
- **Given**: 用户选择三级分类为场内（股票或基金）
- **When**: 进入资产详情表单
- **Then**: 不显示持仓盈亏、盈亏率、当前市值输入框，这些值自动计算
- **Verification**: `human-judgment`

### AC-3: 筛选条件历史保存
- **Given**: 用户在持仓明细页面设置筛选条件
- **When**: 用户点击保存筛选条件并命名
- **Then**: 筛选条件保存到本地，下次可直接点击使用
- **Verification**: `human-judgment`

### AC-4: 账户余额显示修复
- **Given**: 用户进入账户管理页面
- **When**: 查看账户列表
- **Then**: 每个账户显示正确的余额数据
- **Verification**: `human-judgment`

### AC-5: 三级分类必填
- **Given**: 用户填写新增持仓资产表单
- **When**: 未选择三级分类点击保存
- **Then**: 表单验证提示三级分类为必填项
- **Verification**: `human-judgment`

### AC-6: 市场与二级分类联动（港股）
- **Given**: 用户选择市场为港股市场
- **When**: 查看资产二级分类下拉选项
- **Then**: 只显示"港股"选项
- **Verification**: `human-judgment`

### AC-7: 市场与二级分类联动（美股）
- **Given**: 用户选择市场为美股市场
- **When**: 查看资产二级分类下拉选项
- **Then**: 只显示"美股"选项
- **Verification**: `human-judgment`

### AC-8: 市场与二级分类联动（国内）
- **Given**: 用户选择市场为国内市场
- **When**: 查看资产二级分类下拉选项
- **Then**: 显示"A股"和"港股通"选项
- **Verification**: `human-judgment`

### AC-9: 账户货币转换显示
- **Given**: 用户在账户管理中选择不同货币
- **When**: 查看账户余额
- **Then**: 余额按汇率转换为所选货币显示
- **Verification**: `human-judgment`

### AC-10: 资产分类一级与类型联动
- **Given**: 用户选择资产分类一级
- **When**: 查看资产类型下拉选项
- **Then**: 只显示与该一级分类关联的资产类型
- **Verification**: `human-judgment`
