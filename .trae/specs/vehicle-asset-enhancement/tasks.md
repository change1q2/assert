## [ ] Task 2: 修改车辆列表展示
- **Priority**: high
- **Depends On**: None
- **Description**:
  - 修改 `renderVehicleTable` 方法
  - 表头新增"折损价格"和"收益率"列
  - 折损价格 = 购买价格 - 二手价格（实时计算）
  - 收益率 = (二手价格 - 购买价格) / 购买价格 × 100%（实时计算）
  - 收益率正数为绿色，负数为红色
  - 空数据时 colspan 调整为 9
- **Acceptance Criteria Addressed**: 折损价格展示、收益率展示

## [ ] Task 3: 重构车辆表单为 Combobox 模式
- **Priority**: high
- **Depends On**: Task 1
- **Description**:
  - 修改 `renderVehicleForm` 方法
  - "类型"字段：从 select 改为 input[type="text"] + datalist，使用 VEHICLE_TYPES 作为选项
  - "厂商"字段：从 input 改为 input[type="text"] + datalist，根据 formData.vehicleType 过滤 VEHICLE_BRANDS
  - "型号"字段：从 input 改为 input[type="text"] + datalist，根据 formData.manufacturer 过滤 VEHICLE_MODELS
  - 当类型改变时，清空厂商和型号
  - 当厂商改变时，清空型号
  - 三个字段都支持用户自定义输入（不在列表中的值也可以保存）
- **Acceptance Criteria Addressed**: 表单字段 Combobox 交互
