# 房产资产增强 - Product Requirement Document

## Overview
- **Summary**: 增强独立资产的房产模块功能，包括自用房产价格字段、出租时间字段、出租明细计划管理、列表字段优化等
- **Purpose**: 用户需要更完善的房产资产管理，包括自用房产的折损率计算、出租租期管理、交租状态追踪等功能
- **Target Users**: 拥有多套房产的资产管理者

## Goals
- 自用房产增加购买价、二手价字段，计算折损率
- 出租房产增加起租时间、到期时间字段
- 增加出租明细计划功能（期数、开始/结束时间、交租状态、退租状态）
- 优化列表字段展示顺序和内容
- 明细计划自动按30天一期生成（12期）

## Non-Goals (Out of Scope)
- 不做租金催款提醒
- 不做财务报表汇总
- 不修改后端数据库schema

## Background & Context
- 当前房产模块只有基础的位置信息和简单出租信息
- 保险模块已有明细计划功能可参考
- 用户已有多套自用和出租房产需要管理

## Functional Requirements
- **FR-1**: 自用房产增加购买价和二手价字段
- **FR-2**: 房产列表增加折损率字段，折损率 = (二手价 - 购买价) / 购买价 * 100%
- **FR-3**: 表单字段顺序调整：是否出租放在出租方式之前
- **FR-4**: 修复列表出租方式未显示的问题
- **FR-5**: 出租房产增加起租时间和到期时间字段（年月日）
- **FR-6**: 房产列表操作列增加"明细"按钮
- **FR-7**: 出租明细弹窗，包含表格：期数、开始时间、结束时间、是否交租、是否退租
- **FR-8**: 是否交租三个状态：已交租（绿色）、未交租（灰色）、已逾期（红色）
- **FR-9**: 是否退租两个状态：是、否
- **FR-10**: 明细计划自动按30天一期计算，有12期就排12行
- **FR-11**: 列表增加"出租状态"列：空闲中、已出租

## Non-Functional Requirements
- **NFR-1**: 暗色模式兼容
- **NFR-2**: UI风格与保险明细计划保持一致
- **NFR-3**: 向后兼容旧数据

## Constraints
- **Technical**: React + Vite + Tailwind CSS
- **Storage**: 数据存储在 state JSON 中

## Assumptions
- 明细计划的开始时间从起租时间开始计算
- 每30天为一期，共12期（一年）
- 已逾期的判断：当前日期超过结束时间且未交租

## Acceptance Criteria

### AC-1: 自用房产价格字段
- **Given**: 用户新增/编辑房产，方式选择"自用"
- **When**: 查看表单
- **Then**: 显示购买价和二手价输入字段
- **Verification**: `human-judgment`

### AC-2: 折损率计算
- **Given**: 自用房产有购买价和二手价
- **When**: 查看列表
- **Then**: 显示折损率，公式为 (二手价 - 购买价) / 购买价 * 100%，保留2位小数带%号
- **Verification**: `human-judgment`

### AC-3: 表单字段顺序
- **Given**: 方式选择"出租"
- **When**: 查看出租相关字段
- **Then**: 是否出租字段在出租方式字段之前
- **Verification**: `human-judgment`

### AC-4: 出租方式列表显示
- **Given**: 房产有出租方式数据
- **When**: 查看房产列表
- **Then**: 出租方式列正确显示数据
- **Verification**: `human-judgment`

### AC-5: 起租时间和到期时间
- **Given**: 方式选择"出租"
- **When**: 查看表单
- **Then**: 显示起租时间和到期时间两个日期选择字段
- **Verification**: `human-judgment`

### AC-6: 明细按钮
- **Given**: 查看房产列表
- **When**: 查看操作列
- **Then**: 有"明细"按钮，点击打开明细弹窗
- **Verification**: `human-judgment`

### AC-7: 明细弹窗表格
- **Given**: 点击明细按钮
- **When**: 查看明细弹窗
- **Then**: 表格包含列：期数、开始时间、结束时间、是否交租、是否退租、操作
- **Verification**: `human-judgment`

### AC-8: 交租状态颜色
- **Given**: 明细中有不同交租状态
- **When**: 查看表格
- **Then**: 已交租显示绿色、未交租显示灰色、已逾期显示红色
- **Verification**: `human-judgment`

### AC-9: 自动生成期数
- **Given**: 设置了起租时间
- **When**: 打开明细弹窗
- **Then**: 自动按30天一期生成12期数据，开始时间从起租时间开始
- **Verification**: `human-judgment`

### AC-10: 出租状态列表列
- **Given**: 查看房产列表
- **When**: 查看表头
- **Then**: 有"出租状态"列，显示"空闲中"或"已出租"
- **Verification**: `human-judgment`

### AC-11: 是否退租字段
- **Given**: 查看明细弹窗
- **When**: 查看每行数据
- **Then**: 有"是否退租"字段，可选"是"或"否"
- **Verification**: `human-judgment`

## Open Questions
- 明细计划是固定12期还是可以增减？（按用户描述"有12期就排12行"，推测固定12期）
- 已逾期是自动判断还是手动设置？（推测自动判断：当前日期超过结束时间且状态为未交租则显示已逾期）
