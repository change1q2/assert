# 资产穿透页面升级 - Product Requirement Document

## Overview
- **Summary**: 将资产穿透页面重新设计为券商APP风格，包含多维度收益分析、指数对比、日历收益、个股盈亏、操作分析等板块，支持时间区间切换和多种视图模式
- **Purpose**: 提供类似同花顺等券商APP的专业资产分析视图，让用户能够全面了解投资收益情况和对比分析
- **Target Users**: 使用理财模块进行资产管理和投资分析的用户

## Goals
- 重新设计资产穿透页面为券商风格，包含8个核心板块
- 支持时间区间切换（当日/本月/近三月/今年/全部/自定义）
- 支持指数对比功能，可切换不同指数获取网络数据
- 支持多种视图切换（图表/列表、日历图/柱状图、曲线/K线）
- 全局数据根据筛选条件自动更新

## Non-Goals (Out of Scope)
- 不新增后端API，复用现有数据和公开指数接口
- 不添加交易功能
- 不添加实时行情推送
- 不修改理财模块核心功能

## Background & Context
- 当前资产穿透页面已有基础版本，包含资产总览、持仓分布、涨跌幅排行、账户分布、收益分析
- 用户希望升级为券商APP风格，参考同花顺资产分析页面设计
- 参考图片显示了券商风格的多个分析板块和交互模式

## Functional Requirements
- **FR-1**: 盈亏总览模块 - 显示当前时间区间的盈亏金额和收益率，支持当日/本月/近三月/今年/全部/自定义时间切换
- **FR-2**: 收益率曲线模块 - 显示收益率曲线图，支持曲线收益率/K线收益率切换，显示用户收益线和指数对比线（上证/深证/创业板/上证50/沪深300/中证500），支持自定义指数
- **FR-3**: 收益分析模块 - 显示收益分析数据，支持收益率/盈亏金额/总资产三种维度切换
- **FR-4**: 指数对比模块 - 显示用户收益率与选中指数的对比，显示跑赢/跑输状态和差值百分比
- **FR-5**: 日历收益模块 - 支持日收益/月收益/年收益/阶段收益筛选，支持日历图/柱状图切换，日历图显示每日盈亏，支持收益率/收益金额切换
- **FR-6**: 个股盈亏模块 - 显示各持仓资产的盈亏排名，支持图表/列表两种视图切换
- **FR-7**: 操作分析和我的资产模块 - 显示交易统计和账户资金流向
- **FR-8**: 资产分类收益占比模块 - 饼图显示各资产分类的收益占比和收益金额

## Non-Functional Requirements
- **NFR-1**: 页面响应式布局，适配不同屏幕宽度
- **NFR-2**: 数据计算与理财模块保持一致
- **NFR-3**: 与现有设计风格保持一致，绿涨红跌配色
- **NFR-4**: 时间区间切换时全局数据自动更新
- **NFR-5**: 指数数据从网络获取，支持常见A股指数

## Constraints
- **Technical**: React + Tailwind CSS，复用现有组件和工具函数
- **Business**: 展示类功能，不涉及交易操作
- **Dependencies**: 复用现有的 financeAssets 数据，公开指数接口获取指数数据

## Assumptions
- 指数数据可通过公开API获取（如东方财富、新浪财经）
- 历史收益数据通过现有持仓数据和净值历史计算
- 绿涨红跌配色方案（A股习惯）
- 自定义时间区间支持选择起始和结束日期

## Acceptance Criteria

### AC-1: 盈亏总览模块
- **Given**: 用户在资产穿透页面
- **When**: 查看顶部区域
- **Then**: 显示当前时间区间的盈亏金额和收益率，下方有当日/本月/近三月/今年/全部/自定义切换按钮
- **Verification**: `human-judgment`

### AC-2: 时间区间切换
- **Given**: 用户在资产穿透页面
- **When**: 点击不同时间区间按钮（当日/本月/近三月/今年/全部/自定义）
- **Then**: 页面所有数据根据所选时间区间自动更新
- **Verification**: `human-judgment`

### AC-3: 收益率曲线模块
- **Given**: 用户在资产穿透页面
- **When**: 查看收益率曲线区域
- **Then**: 显示用户收益线和指数对比线，支持曲线/K线切换，上方有指数选择标签
- **Verification**: `human-judgment`

### AC-4: 指数选择
- **Given**: 用户在资产穿透页面
- **When**: 点击不同指数标签（上证/深证/创业板等）
- **Then**: 曲线区域显示所选指数的对比线，指数对比模块数据更新
- **Verification**: `human-judgment`

### AC-5: 收益分析模块
- **Given**: 用户在资产穿透页面
- **When**: 查看收益分析区域
- **Then**: 显示收益分析数据，支持收益率/盈亏金额/总资产切换
- **Verification**: `human-judgment`

### AC-6: 指数对比模块
- **Given**: 用户在资产穿透页面
- **When**: 查看指数对比区域
- **Then**: 显示"本月跑赢/跑输上证指数"，对比用户和各指数收益率
- **Verification**: `human-judgment`

### AC-7: 日历收益模块
- **Given**: 用户在资产穿透页面
- **When**: 查看日历收益区域
- **Then**: 显示日历图，支持日收益/月收益/年收益/阶段收益筛选，支持日历图/柱状图切换
- **Verification**: `human-judgment`

### AC-8: 个股盈亏模块
- **Given**: 用户在资产穿透页面
- **When**: 查看个股盈亏区域
- **Then**: 显示各持仓资产盈亏排名，支持图表/列表视图切换
- **Verification**: `human-judgment`

### AC-9: 操作分析和我的资产模块
- **Given**: 用户在资产穿透页面
- **When**: 查看操作分析和我的资产区域
- **Then**: 显示交易股票数、平均持仓天数、建清仓次数、交易成功率、平均仓位、资金周转率等操作统计，以及银证转入/转出、期初/期末资产、净流入、账户盈亏等资金流向数据
- **Verification**: `human-judgment`

### AC-10: 资产分类收益占比模块
- **Given**: 用户在资产穿透页面
- **When**: 查看资产分类收益占比区域
- **Then**: 显示饼图展示各资产分类的收益占比，以及各分类的收益金额
- **Verification**: `human-judgment`

### AC-11: 全局数据一致性
- **Given**: 用户切换时间区间或指数
- **When**: 查看页面各板块数据
- **Then**: 所有板块数据根据筛选条件同步更新，计算逻辑与理财模块一致
- **Verification**: `programmatic`
