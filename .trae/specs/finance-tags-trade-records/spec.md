# 财务页面优化 - 产品需求文档

## Overview
- **Summary**: 修复标签选择问题，优化详情弹窗交易记录功能，增加交易统计汇总，修改仓位占比显示和详情按钮样式
- **Purpose**: 提升用户体验，完善交易记录管理功能
- **Target Users**: 财务持仓管理用户

## Goals
- 修复标签筛选下拉框无法选择新增标签的问题
- 仓位占比显示去掉前导符号
- 详情弹窗交易税费自动计算交易记录费用总和
- 交易记录支持新增买入/卖出/分红操作
- 详情弹窗增加交易统计汇总（买入总金额、卖出总金额等）
- 列表详情按钮从眼睛图标改为文字"明细"

## Non-Goals (Out of Scope)
- 交易记录的数据持久化（仅前端展示）
- 复杂的交易计算逻辑（如成本分摊等）

## Background & Context
- 当前标签筛选下拉框只显示持仓数据中的标签，新增标签未同步到筛选下拉
- 仓位占比显示使用了 pnlSign 函数添加符号，不符合预期
- 详情弹窗交易记录为静态模拟数据，需要支持动态新增
- 详情按钮使用 Eye 图标，用户希望改为文字"明细"

## Functional Requirements
- **FR-1**: 标签筛选下拉框应显示系统中所有标签（包括新增的标签），而不仅仅是持仓数据中的标签
- **FR-2**: 仓位占比字段显示格式调整为纯数字百分比，不显示正负号
- **FR-3**: 详情弹窗交易税费自动计算为所有交易记录费用字段的总和
- **FR-4**: 交易记录支持新增买入/卖出/分红操作，包含类型下拉、日期、数量、金额、费用字段
- **FR-5**: 详情弹窗在持仓天数下方增加交易统计汇总：买入总金额、卖出总金额、买入总数、卖出总数、交易总费用、分红收益
- **FR-6**: 交易记录列表中买入/卖出类型旁边显示具体的时间（年月日时分）
- **FR-7**: 列表操作列详情按钮从 Eye 图标改为文字"明细"

## Non-Functional Requirements
- **NFR-1**: 新增交易记录后页面自动更新统计数据
- **NFR-2**: 操作流畅无卡顿

## Constraints
- **Technical**: React + Tailwind CSS，localStorage 数据持久化
- **Dependencies**: 现有 Finance.jsx 页面结构

## Assumptions
- 交易记录数据结构包含：type(买入/卖出/分红)、date(日期)、time(时间)、price(价格)、quantity(数量)、amount(金额)、fee(费用)
- 标签数据存储在 books 数组中的 tags 字段

## Acceptance Criteria

### AC-1: 标签筛选下拉框显示所有标签
- **Given**: 用户在标签管理中添加了新标签
- **When**: 用户打开筛选栏的标签下拉框
- **Then**: 下拉框中应包含所有已添加的标签，可选择筛选
- **Verification**: `human-judgment`

### AC-2: 仓位占比不显示正负号
- **Given**: 用户查看持仓列表
- **When**: 列表显示仓位占比列
- **Then**: 仓位占比显示为纯数字百分比（如 66.67%），不显示正号或负号
- **Verification**: `human-judgment`

### AC-3: 交易税费自动计算
- **Given**: 详情弹窗中存在多条交易记录
- **When**: 查看交易税费字段
- **Then**: 交易税费显示为所有交易记录费用的总和
- **Verification**: `human-judgment`

### AC-4: 交易记录支持新增
- **Given**: 用户打开持仓详情弹窗
- **When**: 用户点击新增交易记录按钮
- **Then**: 显示新增表单，包含类型下拉（买入/卖出/分红）、日期选择、时间选择、数量输入、金额输入、费用输入
- **Verification**: `human-judgment`

### AC-5: 交易统计汇总显示
- **Given**: 详情弹窗中存在交易记录
- **When**: 查看详情弹窗
- **Then**: 在持仓天数下方显示统计卡片：买入总金额、卖出总金额、买入总数、卖出总数、交易总费用、分红收益
- **Verification**: `human-judgment`

### AC-6: 交易记录显示具体时间
- **Given**: 交易记录包含时间信息
- **When**: 查看交易记录列表
- **Then**: 买入/卖出/分红类型旁边显示具体时间（格式：YYYY-MM-DD HH:mm）
- **Verification**: `human-judgment`

### AC-7: 详情按钮改为文字
- **Given**: 用户查看持仓列表操作列
- **When**: 查看详情按钮
- **Then**: 按钮显示为文字"明细"而非 Eye 图标
- **Verification**: `human-judgment`
