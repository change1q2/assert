# 债务模块优化 Spec

## Why
当前债务模块仅包含简单的3张统计卡片和一个基础新增弹窗，字段不完整且不支持附件图片上传与预览。用户需要更完善的债务管理体验，包括完整的弹窗字段、图片附件支持，以及多维度的数据统计卡片展示。

## What Changes
- 扩展新增/编辑债务弹窗字段，与截图设计对齐（大类、类型、双方名称、本金、利息、金额、日期、还款方式、已还金额、附件、备注等）
- 新增弹窗支持附件图片上传、缩略图预览、点击放大查看
- 债务列表页扩展为多维度统计卡片布局（应付/借入、应收/借出、净债务）
- 新增还款计划计算展示（期数、总金额、总利息、每期金额、剩余金额）
- 债务列表拆分为应付/借入与应收/借出两个分区
- 产品版本号由 V1.0.0 更新为 V1.0.1

## Impact
- Affected pages: Debts.jsx
- Affected api: createDebt, saveState（通过前端 state 保存附件）
- Affected styles: Tailwind CSS 卡片与弹窗样式

## ADDED Requirements

### Requirement: 弹窗图片附件
The system SHALL 在新增/编辑债务弹窗中提供图片附件上传功能。

#### Scenario: 上传图片
- **WHEN** 用户点击"选择文件"
- **THEN** 打开系统文件选择器，仅允许图片类型
- **AND** 选择后以 Base64 存储于表单状态
- **AND** 在弹窗内显示缩略图预览

#### Scenario: 预览放大
- **WHEN** 用户点击已上传的缩略图
- **THEN** 弹出图片放大查看层（遮罩层 + 原图居中显示）
- **AND** 点击遮罩层或关闭按钮可关闭放大弹窗

### Requirement: 还款计划计算展示
The system SHALL 在弹窗底部根据本金、利率、还款方式自动计算并展示还款计划。

#### Scenario: 展示还款计划
- **WHEN** 弹窗中填写了本金、利率、还款方式
- **THEN** 底部显示期数、还款方式、总金额、总利息、每期金额、剩余金额
- **AND** 使用等额本息或等额本金公式计算

### Requirement: 多维度统计卡片
The system SHALL 在债务列表页顶部展示3行统计卡片。

#### Scenario: 应付/借入卡片行
- **WHEN** 页面加载完成
- **THEN** 显示第一行7张卡片：应付/借入总额、总本金、总利息、总债务利率、日利率、月利率、年利率
- **AND** 数值为红色系

#### Scenario: 应收/借出卡片行
- **WHEN** 页面加载完成
- **THEN** 显示第二行3张卡片：应收/借出总额、总本金、总利息
- **AND** 数值为绿色系

#### Scenario: 净债务卡片行
- **WHEN** 页面加载完成
- **THEN** 显示第三行3张卡片：净债务、净本金、净利息
- **AND** 根据正负显示红/绿色

## MODIFIED Requirements

### Requirement: 债务弹窗字段
The system SHALL 将现有新增债务弹窗扩展为完整的编辑债务弹窗。

#### Scenario: 字段完整性
- **GIVEN** 用户打开新增或编辑弹窗
- **THEN** 包含以下字段：大类（应付/借入、应收/借出）、类型、债权人/借款人、债务人/付款人、本金、利息（年化%）、金额、借入日期、还款日期、还款方式（下拉）、已还金额、剩余金额（自动计算）、附件、备注
- **AND** 必填项带红色星号标记
- **AND** 金额、剩余金额自动计算并格式化

### Requirement: 债务列表分区
The system SHALL 将单一债务列表拆分为两个分区。

#### Scenario: 分区展示
- **WHEN** 有债务数据
- **THEN** 下方分别展示"应付 / 借入"与"应收款 / 借出"两个卡片区域
- **AND** 每个区域显示笔数和列表
- **AND** 空状态提示"暂无记录，点击新增债务添加"

## REMOVED Requirements

### Requirement: 旧版简单卡片
**Reason**: 替换为更完整的多维度统计卡片布局
**Migration**: 新卡片已覆盖原有债务总额、本金、利息的展示需求
