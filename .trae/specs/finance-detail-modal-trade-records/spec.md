# 理财模块 - 详情弹窗与交易记录优化 PRD

## Overview
- **Summary**: 对理财模块进行多项优化，包括修复四级分类筛选白屏问题、调整新增弹窗资产分类联动、优化详情弹窗卡片显示、升级交易记录字段、添加定投功能等。
- **Purpose**: 完善理财模块的功能完整性和用户体验，支持场外基金和债券类资产的精细化管理。
- **Target Users**: 个人资产管理者，特别是持有场外基金和债券类资产的用户。

## Goals
- 修复筛选设置四级分类导致白屏的 bug
- 完善债权类资产的二级分类选项
- 将四级分类改为下拉选项并支持自定义，建立与一级分类的关联关系
- 优化详情弹窗卡片显示，根据资产类型动态调整
- 升级交易记录字段，支持建仓类型和场外基金字段
- 添加定投功能，支持按金额/份额定投及多种周期

## Non-Goals (Out of Scope)
- 实现真正的图片OCR识别（仍使用模拟数据）
- 接入支付宝、天天基金网真实API
- 修改后端数据库结构
- 实现自动定投提醒功能

## Background & Context
- 当前理财模块已实现基本的持仓管理、交易记录、图片识别导入等功能
- 用户反馈了多个功能缺陷和优化需求
- 资产分类体系包括四级：一级分类（权益类、商品类、债权类、现金类）、二级分类、三级分类（场内/场外）、四级分类（自定义）

## Functional Requirements
- **FR-1**: 修复筛选设置中四级分类导致白屏的问题
- **FR-2**: 新增弹窗中，当资产分类为债权类时，二级分类下拉选项显示"中债"、"美债"
- **FR-3**: 将四级分类从输入框改为下拉选项，支持自定义添加，且与一级分类关联（在特定一级分类下添加的四级分类，只在选择该一级分类时显示）
- **FR-4**: 当一级分类是债券类且三级分类是场外时，详情弹窗卡片标题改为"资产"，显示昨日收益、持仓收益、持仓收益率等字段（参考图片101.jpg）
- **FR-5**: 交易记录类型新增"建仓"，记录显示调整为：类型+日期在右侧，下方显示确认金额、确认份额、确认净值、手续费
- **FR-6**: 在图片识别按钮右侧增加定投开关按钮，支持按金额定投/按份额定投切换，支持每日/每周/每两周/每月周期选择
- **FR-7**: 图片识别导入改为场外基金模式，识别弹窗字段与交易记录保持一致（确认金额、确认份额、确认净值、手续费）

## Non-Functional Requirements
- **NFR-1**: 所有修改必须通过 `npm run build` 构建验证
- **NFR-2**: 页面响应时间 < 200ms
- **NFR-3**: 数据持久化到 localStorage

## Constraints
- **Technical**: React + Vite + Tailwind CSS，现有代码结构约束
- **Dependencies**: 前端代理配置已指向后端端口3000

## Assumptions
- 用户已了解理财模块的基本操作
- 当前模拟数据足够验证功能
- 四级分类的关联关系存储在 localStorage

## Acceptance Criteria

### AC-1: 四级分类筛选白屏修复
- **Given**: 用户打开筛选设置面板
- **When**: 勾选并显示四级分类筛选
- **Then**: 页面正常显示，四级分类下拉框正常工作
- **Verification**: `human-judgment`

### AC-2: 债权类二级分类选项
- **Given**: 用户打开新增资产弹窗，选择资产分类为"债权类"
- **When**: 查看二级分类下拉框
- **Then**: 显示"中债"、"美债"选项
- **Verification**: `human-judgment`

### AC-3: 四级分类下拉选项与关联
- **Given**: 用户在一级分类为"权益类"时添加了四级分类"科技股"
- **When**: 切换一级分类为"债权类"，查看四级分类下拉框
- **Then**: "科技股"选项不显示；切换回"权益类"时，"科技股"显示
- **Verification**: `human-judgment`

### AC-4: 债券类场外资产详情弹窗
- **Given**: 用户打开详情弹窗，资产的一级分类为"债券类"且三级分类为"场外"
- **When**: 查看卡片区域
- **Then**: 卡片标题显示"资产"，包含昨日收益、持仓收益、持仓收益率等字段
- **Verification**: `human-judgment`

### AC-5: 交易记录字段升级
- **Given**: 用户查看交易记录
- **When**: 查看单条记录
- **Then**: 显示类型（建仓/买入/卖出/分红）+ 日期在右侧，下方显示确认金额、确认份额、确认净值、手续费
- **Verification**: `human-judgment`

### AC-6: 定投功能
- **Given**: 用户在交易记录区域
- **When**: 点击定投开关按钮
- **Then**: 弹出定投设置面板，可选择按金额/份额定投，选择每日/每周/每两周/每月周期
- **Verification**: `human-judgment`

### AC-7: 图片识别场外基金模式
- **Given**: 用户点击图片识别上传
- **When**: 查看识别结果校验弹窗
- **Then**: 弹窗字段为确认金额、确认份额、确认净值、手续费，与交易记录一致
- **Verification**: `human-judgment`
