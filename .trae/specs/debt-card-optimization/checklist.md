# 债务模块卡片样式优化 - 验证检查列表

## 功能验证

- [ ] Checkpoint 1: 债务卡片显示所有字段（债权人、债务人、本金、利率、总金额、已还金额、借入日期、还款日期、还款方式、备注）
- [ ] Checkpoint 2: 分期还款明细正确计算并显示（期数、还款日期、本金、利息、总还款额）
- [ ] Checkpoint 3: 四种还款方式（等额本息、等额本金、先息后本、到期一次性）计算逻辑正确
- [ ] Checkpoint 4: 点击还款项状态能在已还/未还之间切换
- [ ] Checkpoint 5: 标记已还后已还金额正确累加，剩余金额正确计算
- [ ] Checkpoint 6: 还款状态切换后刷新页面保持不变
- [ ] Checkpoint 7: 债务列表按分类分组显示，每个债务为独立卡片

## 样式验证

- [ ] Checkpoint 8: 卡片布局清晰，信息层次分明
- [ ] Checkpoint 9: 深色/浅色主题样式正确
- [ ] Checkpoint 10: 已还状态显示绿色标记，未还状态显示灰色标记
- [ ] Checkpoint 11: 卡片视觉效果美观，符合整体设计风格

## 数据验证

- [ ] Checkpoint 12: 后端正确存储还款状态（payments 字段）
- [ ] Checkpoint 13: 后端加载时正确恢复还款状态
- [ ] Checkpoint 14: 新增债务后卡片能正确显示

## 性能验证

- [ ] Checkpoint 15: 还款状态切换响应迅速（<500ms）
- [ ] Checkpoint 16: 多个债务记录时页面渲染流畅
