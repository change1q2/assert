# 理财模块筛选汇总增强与实时行情 - Verification Checklist

- [x] 筛选汇总卡片按2行显示：第一行（当前总市值、持仓总成本、持仓总盈亏），第二行（持仓总收益率、当日总盈亏、当日总收益率）
- [x] 持仓总成本 = Σ(持仓成本 × 数量)，即每行持仓成本乘以数量后的总和
- [x] 持仓总收益率 = (当前总市值 − 持仓总成本) / 持仓总成本 × 100%（带 +/- 号，2位小数）
- [x] 当日总收益率 = 当日总盈亏 / 当前总市值 × 100%（带 +/- 号，2位小数）
- [x] 当前市值为0时，当日总收益率显示"—"或"0.00%"
- [x] 持仓总成本为0时，持仓总收益率显示"—"或"0.00%"
- [x] 盈亏颜色正确：正数绿色，负数红色
- [x] 列表现价使用实时数据（线上获取）
- [x] 现价高于昨日收盘价显示绿色
- [x] 现价低于昨日收盘价显示红色
- [x] 现价等于昨日收盘价显示默认颜色（灰色/黑色）
- [x] 当日盈亏 = (现价 - 昨日收盘价) × 数量（使用实时数据计算）
- [x] 无实时数据时降级使用本地数据
