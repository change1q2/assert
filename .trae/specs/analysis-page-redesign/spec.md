# 统计分析页面重构 - 产品需求文档

## Overview
- **Summary**: 参考用户提供的设计图片，重构统计分析页面的收支分析模块，实现日常/月统计/年统计三种时间周期的完整数据分析展示
- **Purpose**: 按照设计图片实现专业的数据可视化分析页面，包含多种图表类型和数据统计卡片
- **Target Users**: 需要对收支进行详细分析和管理的用户

## Goals
- 实现日常/月统计/年统计三种时间周期的完整页面
- 参考设计图片实现所有图表和卡片功能
- 新增预算和目标功能
- 实现账本下拉多选和模块设置功能
- 使用专业图表组件展示数据

## Non-Goals (Out of Scope)
- 不修改理财分析和债务分析模块
- 不修改数据存储结构
- 不添加新的后端API

## Background & Context
- 用户提供了详细的设计图片，包含日常、月统计、年统计三种模式
- 需要实现多种图表类型：折线图、面积图、桑基图、空心饼图、柱状图、日历热力图
- 需要实现预算管理、资产汇总、标签统计等功能

## Functional Requirements

### FR-1: 时间周期切换
- **FR-1.1**: 页面顶部添加日常/月统计/年统计/自定义四个切换按钮
- **FR-1.2**: 每个时间周期显示对应的统计卡片和图表

### FR-2: 日常模式页面
- **FR-2.1**: 日期范围选择器（默认最近7天）
- **FR-2.2**: 总支出/总收入/总结余统计卡片
- **FR-2.3**: 收支走势折线图（支出红色、收入绿色）
- **FR-2.4**: 资产走势面积图
- **FR-2.5**: 收支对比桑基图（流向图）
- **FR-2.6**: 支出占比空心饼图（支持一级分类/全部切换）
- **FR-2.7**: 支出数据列表（按分类显示，可展开二级分类）
- **FR-2.8**: 标签占比空心饼图
- **FR-2.9**: 标签数据列表

### FR-3: 月统计模式页面
- **FR-3.1**: 年份选择器 + 月份选择器
- **FR-3.2**: 月支出/月收入/月结余统计卡片
- **FR-3.3**: 收支统计柱状图（按日统计）
- **FR-3.4**: 收支热力日历图（显示每日收支热度）
- **FR-3.5**: 资产走势面积图
- **FR-3.6**: 收支对比桑基图
- **FR-3.7**: 支出占比空心饼图
- **FR-3.8**: 支出数据列表
- **FR-3.9**: 报表统计表（日期、收入、支出、结余）
- **FR-3.10**: 标签占比空心饼图
- **FR-3.11**: 标签数据列表
- **FR-3.12**: 本月总结输入区域

### FR-4: 年统计模式页面
- **FR-4.1**: 年份选择器
- **FR-4.2**: 年支出/年收入/年结余统计卡片
- **FR-4.3**: 收支统计柱状图（按月统计）
- **FR-4.4**: 收支热力图
- **FR-4.5**: 资产走势面积图
- **FR-4.6**: 收支对比桑基图
- **FR-4.7**: 支出占比空心饼图
- **FR-4.8**: 支出数据列表
- **FR-4.9**: 报表统计表（月份、收入、支出、结余）
- **FR-4.10**: 标签占比空心饼图
- **FR-4.11**: 标签数据列表
- **FR-4.12**: 年度总结输入区域

### FR-5: 预算和目标功能
- **FR-5.1**: 预算占比卡片（显示各分类预算分配）
- **FR-5.2**: 支持按分类设置月度/年度预算目标
- **FR-5.3**: 显示预算执行进度和剩余额度
- **FR-5.4**: 支持预算预警

### FR-6: 账本选择优化
- **FR-6.1**: 将账本多选改为下拉多选样式
- **FR-6.2**: 下拉框显示已选账本数量，支持全选/取消全选

### FR-7: 模块设置功能
- **FR-7.1**: 新增模块设置按钮，点击打开设置面板
- **FR-7.2**: 设置面板支持勾选/取消勾选显示的卡片
- **FR-7.3**: 设置结果保存到localStorage

## Non-Functional Requirements
- **NFR-1**: 保持界面风格与设计图片一致
- **NFR-2**: 响应式设计，适配不同屏幕尺寸
- **NFR-3**: 图表渲染流畅，数据加载性能良好

## Constraints
- **Technical**: React框架，使用recharts图表库
- **Dependencies**: 依赖现有的fetchState API

## Assumptions
- 用户提供的设计图片是最终界面标准
- 预算数据和模块设置存储在localStorage中

## Acceptance Criteria

### AC-1: 日常模式页面
- **Given**: 用户选择"日常"切换按钮
- **When**: 查看页面
- **Then**: 显示日期范围选择器、总收支卡片、收支走势折线图、资产走势面积图、收支对比桑基图、支出占比饼图、支出数据列表、标签占比饼图、标签数据列表
- **Verification**: `human-judgment`

### AC-2: 月统计模式页面
- **Given**: 用户选择"月统计"切换按钮
- **When**: 查看页面
- **Then**: 显示年月选择器、月度收支卡片、收支统计柱状图、收支热力日历图、资产走势面积图、收支对比桑基图、支出占比饼图、支出数据列表、报表统计表、标签占比饼图、标签数据列表、本月总结
- **Verification**: `human-judgment`

### AC-3: 年统计模式页面
- **Given**: 用户选择"年统计"切换按钮
- **When**: 查看页面
- **Then**: 显示年份选择器、年度收支卡片、收支统计柱状图、收支热力图、资产走势面积图、收支对比桑基图、支出占比饼图、支出数据列表、报表统计表、标签占比饼图、标签数据列表、年度总结
- **Verification**: `human-judgment`

### AC-4: 预算和目标功能
- **Given**: 用户在日常模式查看预算占比卡片
- **When**: 添加预算并产生对应支出
- **Then**: 预算占比饼图正确显示各分类预算分配，剩余额度准确计算
- **Verification**: `human-judgment`

### AC-5: 账本下拉多选
- **Given**: 用户点击账本选择下拉框
- **When**: 选择多个账本
- **Then**: 页面数据根据选中账本实时更新
- **Verification**: `human-judgment`

### AC-6: 模块设置功能
- **Given**: 用户点击模块设置按钮
- **When**: 调整卡片显示设置
- **Then**: 页面卡片实时更新，刷新页面保持配置
- **Verification**: `human-judgment`
