# 资产分类模块功能增强 - Product Requirement Document

## Overview
- **Summary**: 增强资产分类模块，与理财模块深度集成，提供资产分类占比、海内外分布、资产增长趋势、分类柱状图等可视化功能，优化分类管理和权益类详情页。
- **Purpose**: 让用户能够更直观地查看资产配置情况，实现资产分类与理财模块的自动同步，提供更丰富的数据可视化和分析功能。
- **Target Users**: 个人财务管理用户、投资者

## Goals
- 资产分类占比饼图根据理财模块持仓明细实时展示
- 海内外资产分布饼图（国内/海外，海外再细分）
- 资产增长趋势折线图（按一级分类分线）
- 分类金额柱状图（带中文金额标注）
- 资产分类统计数据与理财模块同步（市值/成本/盈亏/收益率）
- 分类删除关联数据校验和提示
- 编辑时优先使用理财模块数据，当前价值自动计算不可编辑
- 权益类详情页增强（编辑功能、对比卡片、资产类型占比、海内外对比、持仓明细）

## Non-Goals (Out of Scope)
- 不涉及理财模块核心功能修改
- 不涉及后端API开发
- 不涉及多用户协作功能

## Background & Context
- 现有资产分类模块（AssetClasses.jsx）和理财模块（Finance.jsx）已存在基础功能
- 理财模块有完整的持仓明细列表、筛选、搜索、列设置功能
- 资产分类模块已有基础的分类管理和简单统计
- 需要将两个模块深度集成，资产分类数据优先从理财模块获取

## Functional Requirements

### FR-1: 资产分类占比饼图
- 资产分类模块顶部卡片显示资产分类占比饼图
- 数据来源：理财模块持仓明细列表中的一级分类
- 饼图按一级分类展示各分类金额和占比

### FR-2: 海内外分布饼图
- 海内外卡片显示饼图
- 数据来源：理财模块持仓明细列表中的市场
- 国内市场 vs 海外市场
- 海外市场再细分为：港股市场、美股市场、其他市场

### FR-3: 资产增长趋势图
- 资产增长趋势折线图
- 数据来源：理财模块持仓明细列表中的一级分类
- 有几类一级分类就显示几条线
- 横轴为时间，纵轴为金额

### FR-4: 分类柱状图
- 分类金额柱状图
- 数据来源：理财模块持仓明细列表中的一级分类
- 每个柱状图上方显示对应金额
- 金额用中文标识（如100.23万），保留2位小数

### FR-5: 资产分类统计数据同步
- 总资产市值 = 理财模块总市值
- 总资产成本 = 理财模块总成本
- 总盈亏 = 理财模块总盈亏
- 年度总收益 → 改名为总收益率 = 理财模块总收益率
- 删除年度总支出
- 平均期望收益率 = 分类表中所有期望收益率按市值权重的加权平均值

### FR-6: 分类删除关联校验
- 分类表删除分类时，如果相关类型有理财模块关联数据
- 提示用户先解除关联数据才能删除
- 当前点击删除无效的问题需要修复

### FR-7: 编辑时数据校验与同步
- 进行编辑修改时需要和理财模块进行校验对比
- 优先使用理财模块的数据
- 当前价值获取理财模块对应分类的数据
- 当前价值不可编辑，只能自动计算

### FR-8: 权益类详情页增强
1. 右上角新增资产类型按钮删除，改成编辑按钮
   - 可以编辑目标价值和期望收益率
2. 第二行加一个卡片对比
   - 当前价值和目标价值对比
   - 当前收益率和期望收益率对比
3. 第三个卡片资产类型占比
   - 获取理财模块一级分类为权益类的数据
   - 饼图展示资产类型
   - 各资产类型金额显示
4. 海内外资产对比
   - 获取理财模块一级分类为权益类的数据
   - 海外市场和国内市场饼图对比
5. 资产类型明细
   - 延用理财模块的持仓明细表单结构
   - 包括筛选、搜索、列设置
   - 只获取一级分类为权益类的数据

## Non-Functional Requirements
- **NFR-1**: 页面加载性能 - 图表渲染时间<500ms
- **NFR-2**: 数据一致性 - 资产分类数据与理财模块保持实时同步
- **NFR-3**: 响应式设计 - 适配移动端和桌面端
- **NFR-4**: 数据持久化 - 用户自定义配置保存到 localStorage

## Constraints
- **Technical**: React + Vite + Tailwind CSS + Recharts
- **Business**: 纯前端实现，数据存储在 localStorage
- **Dependencies**: 依赖理财模块（Finance.jsx）的数据结构

## Assumptions
- 理财模块持仓明细数据结构包含：categoryL1（一级分类）、market（市场）、currentValue（当前价值）、cost（成本）等字段
- 市场字段值包括：国内市场、港股市场、美股市场、其他市场
- 一级分类包括：权益类、债权类、现金类、商品类、分红类等

## Acceptance Criteria

### AC-1: 资产分类占比饼图
- **Given**: 用户打开资产分类页面
- **When**: 页面加载完成
- **Then**: 显示资产分类占比饼图，数据来自理财模块一级分类
- **Verification**: `human-judgment`

### AC-2: 海内外分布饼图
- **Given**: 用户打开资产分类页面
- **When**: 页面加载完成
- **Then**: 显示海内外分布饼图，国内市场和海外市场对比，海外再细分
- **Verification**: `human-judgment`

### AC-3: 资产增长趋势图
- **Given**: 用户打开资产分类页面
- **When**: 页面加载完成
- **Then**: 显示资产增长趋势折线图，每条线对应一个一级分类
- **Verification**: `human-judgment`

### AC-4: 分类柱状图
- **Given**: 用户打开资产分类页面
- **When**: 页面加载完成
- **Then**: 显示分类金额柱状图，柱顶显示中文金额（如100.23万）
- **Verification**: `human-judgment`

### AC-5: 统计数据同步
- **Given**: 用户打开资产分类页面
- **When**: 页面加载完成
- **Then**: 总资产市值、成本、盈亏、总收益率与理财模块一致，年度总支出已删除
- **Verification**: `human-judgment`

### AC-6: 分类删除校验
- **Given**: 用户尝试删除一个有关联数据的分类
- **When**: 点击删除按钮
- **Then**: 提示用户先解除关联数据才能删除，删除有效
- **Verification**: `human-judgment`

### AC-7: 编辑数据同步
- **Given**: 用户编辑分类数据
- **When**: 打开编辑弹窗
- **Then**: 当前价值从理财模块获取，不可编辑，自动计算
- **Verification**: `human-judgment`

### AC-8: 权益类详情页增强
- **Given**: 用户进入权益类详情页
- **When**: 页面加载完成
- **Then**: 显示编辑按钮、对比卡片、资产类型占比饼图、海内外对比饼图、持仓明细列表
- **Verification**: `human-judgment`
