# 资产穿透页面功能增强 - 验证清单

## 功能验证

### 自定义时间区间选择
- [x] 点击"自定义"按钮后显示时间区间选择器弹窗
- [x] 时间区间选择器包含常用时间段选项（近一周、近一月、近三月、近半年、近一年）
- [x] 选择时间段后，页面顶部盈亏数据更新为对应时间范围

### 指数曲线图和K线图
- [x] 收益率曲线显示完整的历史数据点
- [x] 指数曲线数据与中证指数官网数据一致
- [x] 点击"K线"按钮后显示K线图
- [x] K线正确显示开盘价、收盘价、最高价、最低价

### 纳斯达克和标普500指数
- [x] 指数选择区域显示纳斯达克和标普500选项
- [x] 点击纳斯达克后，指数对比区域显示纳斯达克数据
- [x] 点击标普500后，指数对比区域显示标普500数据

### 仓位分析饼图
- [x] 勾选"仓位分析"后显示一级分类饼图
- [x] 点击一级分类后切换到二级分类饼图
- [x] 点击二级分类后切换到三级分类饼图
- [x] 显示返回上一级按钮，点击后返回上一级

### 日历收益日收益
- [x] 日收益为正数的日期单元格显示红色
- [x] 日收益为负数的日期单元格显示蓝色
- [x] 点击"收益率"按钮后，日历显示百分比数据
- [x] 点击"收益金额"按钮后，日历显示金额数据

### 月收益显示
- [x] 月收益视图显示12个月的网格布局
- [x] 盈利月份显示红色背景，亏损月份显示蓝色背景
- [x] 显示收益金额和收益率
- [x] 底部显示年度收益和同期上证数据

### 年收益显示
- [x] 年收益视图显示多年的网格布局
- [x] 盈利年份显示红色背景，亏损年份显示蓝色背景
- [x] 显示收益金额和收益率
- [x] 底部显示全部总收益和同期上证数据

### 阶段收益显示
- [x] 阶段收益视图显示完整的表格，包含所有指定阶段
- [x] 表格包含阶段、收益、收益率、同期上证列
- [x] 收益为正数显示红色，负数显示蓝色
- [x] 显示本周、本月、近半年、马年以来、最大盈利区间、最大回撤区间、自定义区间
