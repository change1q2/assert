# 持仓明细列表整合与汇总卡片 - Product Requirement Document

## Overview
- **Summary**: 将当前按资产分类分组显示的持仓明细改为单一列表，所有持仓数据汇总到一个表格中，并在列表下方添加汇总卡片显示筛选后数据的总市值、总成本、总盈亏、总收益率、当日收益、当日收益率。
- **Purpose**: 简化持仓明细展示，方便用户查看所有资产的汇总信息，支持筛选后动态计算汇总数据。
- **Target Users**: 理财模块使用者，需要查看和管理持仓资产的用户。

## Goals
- 持仓明细改为单一列表，不再按资产分类分组显示
- 在持仓明细列表下方添加汇总卡片，显示筛选后数据的汇总统计
- 汇总卡片包含：总市值、总成本、总盈亏、总收益率、当日收益、当日收益率
- 筛选条件变化时，汇总卡片数据自动更新

## Non-Goals (Out of Scope)
- 不改变账户卡片的显示（账户本卡片保持不变）
- 不改变新增/编辑弹窗功能
- 不改变筛选功能本身（筛选条件保持不变）
- 不改变分页功能

## Background & Context
- 当前持仓明细按资产分类（权益类、债权类等）分组显示，每个分类有独立的表格和合计行
- 用户希望看到所有资产在一个列表中，并在列表下方有统一的汇总统计
- 汇总数据需要根据筛选条件动态计算

## Functional Requirements

- **FR-1**: 持仓明细改为单一列表
  - 移除按资产分类分组的显示逻辑
  - 所有持仓资产显示在一个表格中
  - 保留原有的筛选、搜索、分页、列设置功能
  - 保留原有的编辑和删除操作

- **FR-2**: 筛选后汇总卡片
  - 在持仓明细列表下方添加汇总卡片
  - 汇总卡片显示以下数据（基于筛选后的结果）：
    - 总市值：所有持仓当前价值之和
    - 总成本：所有持仓成本之和
    - 总盈亏：所有持仓盈亏之和
    - 总收益率：总盈亏 ÷ 总成本 × 100%
    - 当日收益：所有持仓当日盈亏之和
    - 当日收益率：当日收益 ÷ 总成本 × 100%
  - 汇总卡片样式参考账户卡片（圆角、浅色背景、网格布局）
  - 盈亏数字按正负显示不同颜色（绿色为正，红色为负）
  - 收益率显示为百分比格式

- **FR-3**: 汇总数据动态更新
  - 筛选条件变化时，汇总卡片数据自动重新计算
  - 分页不影响汇总数据（汇总所有符合筛选条件的数据，不受分页限制）
  - 新增/编辑/删除持仓后，汇总卡片数据自动更新

## Non-Functional Requirements

- **NFR-1**: 性能 - 汇总计算在筛选变化时即时响应
- **NFR-2**: 兼容性 - 保持与现有数据结构的向后兼容
- **NFR-3**: 构建验证 - 修改后 `npm run build` 必须通过

## Constraints
- **Technical**: React 前端 + Node.js 后端
- **Business**: 需保持现有数据结构兼容性

## Assumptions
- 汇总数据基于 computed.financeAccounts（已筛选的数据）
- 当前价值字段为 currentValue
- 成本字段为 cost（持仓成本 × 份额）
- 持仓盈亏字段为 holdingPnl
- 当日盈亏字段为 dailyPnl

## Acceptance Criteria

### AC-1: 持仓明细改为单一列表
- **Given**: 用户打开理财模块页面
- **When**: 用户查看持仓明细区域
- **Then**: 所有持仓资产显示在一个表格中，不再按资产分类分组
- **And**: 列表上方显示筛选条件和搜索框
- **Verification**: `human-judgment`

### AC-2: 汇总卡片显示位置和内容
- **Given**: 用户打开理财模块页面，且有持仓数据
- **When**: 用户查看持仓明细列表下方
- **Then**: 显示汇总卡片，包含总市值、总成本、总盈亏、总收益率、当日收益、当日收益率
- **And**: 卡片样式与账户卡片一致（圆角、浅色背景、网格布局）
- **Verification**: `human-judgment`

### AC-3: 汇总卡片数据计算正确
- **Given**: 用户有持仓数据
- **When**: 用户查看汇总卡片
- **Then**: 总市值 = 所有持仓 currentValue 之和
- **And**: 总成本 = 所有持仓 cost 之和
- **And**: 总盈亏 = 所有持仓 holdingPnl 之和
- **And**: 总收益率 = 总盈亏 ÷ 总成本 × 100%（显示为百分比）
- **And**: 当日收益 = 所有持仓 dailyPnl 之和
- **And**: 当日收益率 = 当日收益 ÷ 总成本 × 100%（显示为百分比）
- **Verification**: `human-judgment`

### AC-4: 汇总数据随筛选条件动态更新
- **Given**: 用户打开理财模块页面，且有持仓数据
- **When**: 用户应用筛选条件（如选择特定账户或资产分类）
- **Then**: 汇总卡片数据根据筛选结果重新计算并更新
- **And**: 分页不影响汇总数据（汇总所有符合条件的数据）
- **Verification**: `human-judgment`

### AC-5: 汇总卡片颜色显示正确
- **Given**: 用户查看汇总卡片
- **When**: 盈亏数据为正数
- **Then**: 显示绿色
- **When**: 盈亏数据为负数
- **Then**: 显示红色
- **Verification**: `human-judgment`

### AC-6: 构建成功
- **Given**: 代码修改完成
- **When**: 运行 `npm run build`
- **Then**: 构建成功，无报错
- **Verification**: `programmatic`
