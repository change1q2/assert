# 明细弹窗数据校验与功能修复 - 产品需求文档

## 概述
- **摘要**：本次需求包含6项修改：(1) DetailModal 中浮动盈亏和当日参考盈亏直接显示列表中的持仓盈亏和当日盈亏；(2) 增加交易记录与列表持仓成本的校验机制；(3) 列表增加平均买入成本字段；(4) 校验不一致时高亮显示供人工排查；(5) 修复交易记录点击编辑后弹窗消失的bug；(6) 图片识别时自动给无时间记录分配随机交易时间。
- **目的**：确保明细弹窗数据与列表数据一致，修复交互bug，提升数据录入体验。
- **目标用户**：理财模块使用者

## 目标
1. DetailModal 浮动盈亏、当日参考盈亏直接使用列表中的持仓盈亏、当日盈亏值
2. 交易记录买入总金额 - 卖出总金额 = 列表持仓成本，不一致时提示
3. 列表显示平均买入成本 = 持仓成本 / 数量
4. 校验不一致的地方明显标识出来
5. 交易记录点击编辑按钮正常打开编辑弹窗不消失
6. 图片识别无时间记录自动补随机时间（9:30-15:00），按时间倒序排列

## 非目标（不在范围内）
- 不修改持仓成本计算公式（保持现有逻辑）
- 不修改币种切换逻辑
- 不修改场外基金净值获取逻辑

## 背景与上下文
- DetailModal 中浮动盈亏和当日参考盈亏目前通过 `currentPrice`、`prevPrice`、`quantity` 等字段实时计算，但用户希望直接显示列表中已计算好的值（`holdingPnl`、`dailyPnl`）
- 交易记录中的买入/卖出金额与列表中的持仓成本可能存在不一致，需要校验机制
- 列表中缺少平均买入成本字段，用户需要人工计算
- 交易记录编辑按钮点击后弹窗消失，无法编辑
- 图片识别OCR结果可能缺少时间字段，需要自动补充

## 功能需求
- **FR-1**：DetailModal 中"浮动盈亏"显示 `latestData.holdingPnl`（列表中的持仓盈亏），"当日参考盈亏"显示 `latestData.dailyPnl`（列表中的当日盈亏）
- **FR-2**：DetailModal 中增加校验区域：计算交易记录中所有"买入"类型记录的金额总和 - 所有"卖出"类型记录的金额总和，与 `latestData.cost`（列表持仓成本）对比，不一致时显示差异
- **FR-3**：CategoryTable 列表中增加"平均买入成本"列（显示值 = cost / quantity），位置在成本列之后
- **FR-4**：当校验不一致时，在 DetailModal 中以醒目的样式（如红色背景或红色文字）高亮显示差异值
- **FR-5**：修复交易记录编辑按钮点击后 DetailModal 弹窗关闭的问题
- **FR-6**：图片识别导入交易记录时，如果记录没有时间字段，自动分配 9:30-15:00 之间的随机时间，且所有交易记录按时间倒序排列（最新的在最前面）

## 非功能需求
- **NFR-1**：校验计算不影响页面性能
- **NFR-2**：图片识别时间补充逻辑简单高效

## 约束
- **技术**：React + Vite + Tailwind CSS
- **数据**：交易记录类型包括：买入、卖出、分红、建仓、清仓等

## 假设
- 交易记录中"买入"类型包括：买入、建仓（方向为买入时）
- 交易记录中"卖出"类型包括：卖出、清仓（方向为卖出时）
- 分红类型不计入买入/卖出金额

## 验收标准

### AC-1: DetailModal 浮动盈亏显示列表值
- **Given**：打开某个资产的明细弹窗
- **When**：查看"浮动盈亏"区域
- **Then**：显示的值与列表中的"持仓盈亏"一致（直接使用 `latestData.holdingPnl`）
- **Verification**：human-judgment

### AC-2: DetailModal 当日参考盈亏显示列表值
- **Given**：打开某个资产的明细弹窗
- **When**：查看"当日参考盈亏"区域
- **Then**：显示的值与列表中的"当日盈亏"一致（直接使用 `latestData.dailyPnl`）
- **Verification**：human-judgment

### AC-3: 交易记录与持仓成本校验
- **Given**：明细弹窗中有若干交易记录
- **When**：系统计算买入总金额 - 卖出总金额
- **Then**：与 `latestData.cost` 对比，一致时显示"校验通过"，不一致时显示差异值
- **Verification**：human-judgment

### AC-4: 列表增加平均买入成本列
- **Given**：理财模块持仓明细列表
- **When**：查看表格列
- **Then**：可见"平均买入成本"列，值为 cost / quantity
- **Verification**：human-judgment

### AC-5: 校验不一致高亮显示
- **Given**：校验发现交易记录计算的持仓成本与列表不一致
- **When**：查看校验区域
- **Then**：差异值以红色醒目显示
- **Verification**：human-judgment

### AC-6: 交易记录编辑不关闭弹窗
- **Given**：明细弹窗中显示交易记录列表
- **When**：点击某条记录的编辑按钮
- **Then**：打开编辑弹窗，DetailModal 保持打开状态
- **Verification**：human-judgment

### AC-7: 图片识别自动补时间
- **Given**：使用图片识别导入交易记录
- **When**：识别结果中某条记录只有日期没有时间
- **Then**：自动补充 9:30-15:00 之间的随机时间，且记录按时间倒序排列
- **Verification**：human-judgment

### AC-8: 构建成功
- **Given**：代码修改完成
- **When**：执行 `npm run build`
- **Then**：构建成功无错误
- **Verification**：programmatic
