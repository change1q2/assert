# 收支分析模块增强 Spec

## Why
当前收支分析模块的分类仅为单级分类，无法满足精细化记账需求；且缺少多账本支持，无法按不同用途分开记账。需要升级为支持二级分类和多账本功能。

## What Changes
- 新增二级分类体系（一级分类 → 二级分类）
- 新增多账本功能（右上角账本选择器）
- 新增账户选择（下拉框）
- 列表新增账本名称列
- 支出金额自动存储为负数

## Impact
- Affected specs: 收支分析页面
- Affected code:
  - 前端: `Records.jsx`, `api/index.js`
  - 后端: `/api/state` 接口扩展

## ADDED Requirements

### Requirement: 二级分类体系
系统 SHALL 支持一级分类和二级分类的层级结构。

#### Scenario: 默认一级分类
- **WHEN** 用户打开新增弹窗
- **THEN** 显示默认一级分类选项：餐饮、交通、居住、购物、医疗、教育、娱乐、投资、工资、理财、其他收入、其他支出

#### Scenario: 二级分类联动
- **WHEN** 用户选择一级分类后
- **THEN** 二级分类下拉框显示该一级分类对应的二级分类

#### Scenario: 默认二级分类映射
| 一级分类 | 二级分类选项 |
|---------|-------------|
| 餐饮 | 早餐、午餐、晚餐、零食、饮料、水果 |
| 交通 | 公交、地铁、出租车、加油、停车 |
| 居住 | 房租、水电费、物业费 |
| 购物 | 日用品、服装、电子产品 |
| 医疗 | 门诊、药品 |
| 教育 | 学费、书籍、培训 |
| 娱乐 | 电影、游戏、旅游 |
| 投资 | 股票、基金、债券 |
| 工资 | 工资、奖金、补贴 |
| 理财 | 利息、分红 |
| 其他收入 | 红包、退款、其他 |
| 其他支出 | 捐赠、丢失、其他 |

#### Scenario: 自由增删分类
- **WHEN** 用户在分类输入框输入新值
- **THEN** 按回车或点击添加按钮可新增分类
- **AND** 分类显示删除图标，点击可删除自定义分类

#### Scenario: 支出金额自动负数
- **WHEN** 用户在支出类型下输入金额
- **THEN** 金额存储时自动转为负数

### Requirement: 多账本功能
系统 SHALL 支持创建和管理多个账本，按账本隔离数据。

#### Scenario: 账本选择器
- **WHEN** 用户在页面右上角点击账本选择器
- **THEN** 显示账本列表和"全部账本"选项
- **AND** 当前选中账本高亮显示

#### Scenario: 全部账本汇总
- **WHEN** 用户选择"全部账本"
- **THEN** 页面显示所有账本的数据总和

#### Scenario: 单账本筛选
- **WHEN** 用户选择特定账本
- **THEN** 页面仅显示该账本的记录

#### Scenario: 账本显示
- **WHEN** 页面加载时
- **THEN** 每条记录前显示对应账本名称

### Requirement: 账户选择
新增弹窗 SHALL 包含账户下拉选择框。

#### Scenario: 账户下拉
- **WHEN** 用户打开新增弹窗
- **THEN** 显示账户下拉框，列出所有账户
- **AND** 默认选中第一个账户

### Requirement: 列表账本列
收支记录列表 SHALL 显示账本名称列。

#### Scenario: 列表显示账本
- **WHEN** 页面渲染收支记录列表
- **THEN** 每条记录显示其所属账本名称

## MODIFIED Requirements

### Requirement: 新增收支记录
原要求保持，扩展字段：

| 字段 | 类型 | 说明 |
|-----|------|------|
| date | string | 日期 |
| type | string | income/expense |
| category | string | 一级分类 |
| subCategory | string | 二级分类 |
| amount | number | 金额（支出为负数） |
| account | string | 账户 |
| book | string | 账本 |
| note | string | 备注 |

### Requirement: 分类统计
收入支出占比 SHALL 按一级分类汇总。

## REMOVED Requirements
- 单级分类输入框（替换为二级下拉选择）

## 技术方案

### 数据结构扩展
```javascript
// 账本结构
{
  id: string,
  name: string,
  icon: string
}

// 分类结构
{
  income: {
    '工资': ['工资', '奖金', '补贴'],
    '理财': ['利息', '分红'],
    '其他收入': ['红包', '退款', '其他']
  },
  expense: {
    '餐饮': ['早餐', '午餐', '晚餐', '零食', '饮料', '水果'],
    '交通': ['公交', '地铁', '出租车', '加油', '停车'],
    '居住': ['房租', '水电费', '物业费'],
    '购物': ['日用品', '服装', '电子产品'],
    '医疗': ['门诊', '药品'],
    '教育': ['学费', '书籍', '培训'],
    '娱乐': ['电影', '游戏', '旅游'],
    '投资': ['股票', '基金', '债券'],
    '其他支出': ['捐赠', '丢失', '其他']
  }
}
```

### API 扩展
```javascript
// 获取账本列表
GET /api/books

// 创建账本
POST /api/books { name, icon }

// 删除账本
DELETE /api/books/:id

// 新增/修改记录时包含账本和二级分类
POST /api/records { date, type, category, subCategory, amount, account, book, note }
```

### 账本选择器 UI
```
[📖 全部账本 ▼]              收支分析    [+ 新增] [刷新]
```

### 新增收支弹窗字段
| 字段 | 控件类型 |
|-----|---------|
| 日期 | date picker |
| 类型 | 支出/收入 切换按钮 |
| 一级分类 | 下拉选择 + 可新增 |
| 二级分类 | 下拉选择 + 可新增 |

| 金额 | number input |
| 备注 | text input |
