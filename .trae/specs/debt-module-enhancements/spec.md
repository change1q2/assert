# 债务模块增强功能 - 产品需求文档

## Overview
- **Summary**: 对债务模块进行5项功能增强，包括移除版本号、调整罚息显示位置、状态可点击切换、还款计划左右拉伸、分页显示及自动定位
- **Purpose**: 提升债务模块的用户体验，使界面更简洁、交互更便捷
- **Target Users**: 债务模块使用者

## Goals
- 移除债务模块标题旁的版本号显示
- 将罚息字段移动到状态字段后面显示
- 支持点击状态标签切换逾期/正常状态
- 还款计划表格支持左右拉伸查看完整内容
- 还款期数超过12期时支持分页显示，自动定位到第一个未还数据

## Non-Goals (Out of Scope)
- 不修改后端API接口
- 不改变债务数据的存储结构（已有字段不变）
- 不添加新的统计卡片

## Background & Context
- 当前债务模块版本号显示在标题旁，影响视觉美观
- 罚息字段当前位置不够直观，需要调整到状态后面
- 状态切换需要进入编辑表单，操作繁琐
- 还款计划表格列较多时无法完全显示，需要左右滚动
- 长期贷款（如30年房贷）期数多达360期，当前只能滚动查看，效率低

## Functional Requirements
- **FR-1**: 移除债务模块标题旁的版本号（V1.0.2）
- **FR-2**: 将债务卡片中的罚息字段移动到状态字段后面
- **FR-3**: 支持点击状态标签（正常/逾期未还）切换债务状态
- **FR-4**: 还款计划表格支持左右拉伸（横向滚动）
- **FR-5**: 还款期数超过12期时显示分页控件，每次进入自动滚动/定位到第一个未还期数

## Non-Functional Requirements
- **NFR-1**: 状态切换操作需即时保存到后端，确保数据一致性
- **NFR-2**: 分页功能需支持上一页/下一页/跳转到指定页
- **NFR-3**: 自动定位到第一个未还期数需在页面加载完成后立即执行

## Constraints
- **Technical**: React + TailwindCSS，不引入新的UI库
- **Business**: 保持现有数据结构不变
- **Dependencies**: 依赖现有的saveState函数保存数据

## Assumptions
- 用户期望状态切换是一个简单的点击操作
- 分页每页显示12期是合理的默认值
- 自动定位到第一个未还期数有助于用户快速了解还款进度

## Acceptance Criteria

### AC-1: 移除版本号
- **Given**: 用户打开债务模块页面
- **When**: 查看页面顶部标题区域
- **Then**: 只显示"债务模块"标题，不显示版本号
- **Verification**: `human-judgment`

### AC-2: 罚息位置调整
- **Given**: 用户查看债务卡片详细信息
- **When**: 查看字段排列顺序
- **Then**: 字段顺序为：债务人、还款方式、状态、罚息、借入日期、还款日期
- **Verification**: `human-judgment`

### AC-3: 状态点击切换
- **Given**: 债务状态为"正常"
- **When**: 用户点击状态标签
- **Then**: 状态切换为"逾期未还"，显示红色字体，数据自动保存
- **Verification**: `human-judgment`

### AC-4: 还款计划左右拉伸
- **Given**: 还款计划表格列较多
- **When**: 用户水平拖动表格区域
- **Then**: 表格可以左右滚动，所有列都能完整显示
- **Verification**: `human-judgment`

### AC-5: 还款计划分页
- **Given**: 债务有372期还款计划
- **When**: 用户打开债务卡片的还款计划
- **Then**: 只显示12期，底部显示分页控件，页面自动滚动到第一个未还期数
- **Verification**: `human-judgment`
