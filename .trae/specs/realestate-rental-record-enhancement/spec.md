# 出租房产付款记录增强 Spec

## Why
用户需要对出租房产的付款记录进行更精细的管理，包括租赁状态跟踪、退租处理、按年折叠付款记录以及年度统计汇总。

## What Changes
- **新增**: 付款记录表格增加「出租状态」列（已出租/未出租），与「实收租金」并列
- **新增**: 付款记录表格增加「是否退租」列（已退租/未退租），可点击切换
- **新增**: 「是否退租」旁边增加「退款额」输入框，默认等于一个月租金，用户可手动填写
- **新增**: 付款记录按年折叠，当年显示在最上方展开，其他年份默认折叠
- **新增**: 折叠后的年份显示年度统计：当年总收入、总空闲（已退租后按月累计）、总退款（当年退款额总和）
- **联动**: 当「是否退租」变为「已退租」时，「出租状态」自动变为「未出租」

## Impact
- Affected specs: realestate-rental-detail-enhancement
- Affected code: IndependentAssets.jsx 中的 renderPropertyDetailModal

## ADDED Requirements

### Requirement: 付款记录增加出租状态和退租信息
The system SHALL 在付款记录表格中增加出租状态、是否退租、退款额三个字段。

#### Scenario: 付款记录显示
- **WHEN** 用户打开出租房产明细弹窗
- **THEN** 付款记录表格显示以下列：月份、应收租金、实收租金、出租状态、是否退租、退款额、状态（付款状态）、操作
- **THEN** 出租状态默认为「已出租」
- **THEN** 是否退租默认为「未退租」，可点击切换
- **THEN** 退款额默认为月租金金额，用户可手动修改

#### Scenario: 退租联动
- **WHEN** 用户将「是否退租」切换为「已退租」
- **THEN** 该记录的「出租状态」自动变为「未出租」
- **THEN** 退款额保持用户已填写的值

### Requirement: 付款记录按年折叠
The system SHALL 将付款记录按年份分组，当前年份默认展开，其他年份默认折叠。

#### Scenario: 按年折叠
- **WHEN** 用户查看付款记录
- **THEN** 记录按年份分组，如「2024年」「2025年」
- **THEN** 当前年份（系统时间所在年份）默认展开
- **THEN** 非当前年份默认折叠
- **THEN** 点击年份标题可展开/折叠该年的记录

#### Scenario: 年度统计
- **WHEN** 用户展开某年份
- **THEN** 在年份标题下方显示该年统计行：
  - 当年总收入 = 该年所有「已付款」记录的实收租金总和
  - 总空闲 = 该年「已退租」后的月份数 × 月租金（从退租当月开始累计）
  - 总退款 = 该年所有记录的退款额总和
- **THEN** 统计行样式区别于普通记录行

#### Scenario: 空闲计算规则
- **WHEN** 某月份记录标记为「已退租」
- **THEN** 从该月份起，后续月份均计入「总空闲」
- **THEN** 总空闲 = 退租后月份数 × 月租金
